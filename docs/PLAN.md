## 4. 원자료와 다르게 쓴 곳 (장마다 「정리」에도 표기)
- MATH-01: 원자료 1번 상자의 문장은 그대로 옮기고, 다섯 분야가 도감의 어느 장인지 덧붙였습니다.
- MATH-01: 원자료 "상수" 상자에 "가중치는 학습 중엔 변수, 예측할 땐 상수처럼 쓰인다"는 설명을 보탰습니다(원자료에는 없음).
- MATH-02: 원자료 6번 상자의 학생 데이터(키 1.2, 몸무게 3.4 등)는 실제 단위가 아닌 축소 예시라는 설명을 덧붙였습니다.
- MATH-02: 원자료 "Rows (m)" 그림의 행·열 화살표는 그대로 두고, "행을 먼저 읽는다"는 읽는 순서를 강조했습니다.
- MATH-03: 원자료의 각도 예([1 0]·[0 1])에 더해 [1 2 3]과 [4 5 6]의 각도(약 12.9°)를 검산해 넣었습니다.
- MATH-04: 원자료 4번 상자의 "Result matrix size = (m × n)"을 "(m × k)(k × n) = m × n"으로 풀어 썼습니다(가운데 k가 같아야 함을 명시).
- MATH-04: AB ≠ BA, 역행렬이 없는 예([[1 2],[2 4]])를 원자료에 덧붙였습니다.
- MATH-05: 원자료 5번 표의 "Unique Solution" 예시(x = 1, y = 2)는 조건 없이 값만 적혀 있어, 이 도감에서는 실제 식 2x + 3y = 7, x − y = 1의 해(x = 2, y = 1)로 설명했습니다.
- MATH-05: 원자료 7번 상자의 회귀 예에 대해 β₀ ≈ 0.333, β₁ = 1.5를 직접 계산해 넣었습니다.
- MATH-06: 원자료의 "rolling a dice"는 우리말로 "주사위 던지기"로 옮겼습니다.
- MATH-06: 원자료 7번(곱셈 법칙)에 "독립이 아니면 곱하면 안 된다"는 주의를 덧붙였습니다.
- MATH-07: 원자료 4번(문제 풀기) 예는 답만 있어, "쉬움·어려움이 반반"이라는 가정을 이 도감이 더해 전체 정답률(0.45)과 반대 방향 확률(약 0.333)을 계산했습니다.
- MATH-07: 원자료 6번의 "99% accurate"를 "민감도(진양성률) 99%"로 정확히 풀어 썼습니다.
- MATH-08: 원자료 4번의 분산은 n으로 나누는 모집단 분산입니다. 15장의 표본분산(n − 1)과 헷갈리지 않게 두 값을 함께 적었습니다.
- MATH-08: 원자료 5번 상자 그림의 왼쪽 글자 "RoI"는 이 도감에서 "최솟값(Min)"으로 읽었습니다.
- MATH-08: 원자료 6번 표의 "1, 2, 2, 3, 100"에 대해 이상치 판정 기준(IQR 규칙)을 덧붙였습니다.
- MATH-09: 원자료 3번(베르누이) 그래프의 막대 높이 0.4·0.6은 그대로 두고, 예의 "coin toss: P(Head) = 0.6"을 "앞면 확률이 0.6인 찌그러진 동전"으로 풀었습니다.
- MATH-09: 원자료 9번 표의 분포 여섯 개에 쓰임 예를 한 줄씩 보탰습니다.
- MATH-10: 원자료 2번 표의 "키와 신발 크기(관련 없을 수도)"를 공분산 0의 예로 쓰지 않고 "키와 생일 날짜"로 바꿨습니다. 키와 신발 크기는 실제로 양의 관계가 있는 경우가 많기 때문입니다.
- MATH-10: 원자료 7번 표에 "상관 ≠ 인과"와 "r = 0이어도 곡선 관계가 있을 수 있다"는 주의를 덧붙였습니다.
- MATH-11: 원자료 6번의 몫의 미분 예는 정리하지 않은 식으로 끝나, 이 도감에서 (x² − 2x − 1)/(x − 1)²로 정리했습니다.
- MATH-11: ReLU처럼 꺾인 함수의 미분, 수치 미분(경사 검사)을 덧붙였습니다.
- MATH-12: 원자료 3번의 "fxy = fyx (if function is continuous)"를 "2계 편미분들이 연속이면"으로 정확히 고쳐 썼습니다.
- MATH-12: 원자료 4번 3D 그림의 축 이름(x가 두 번 표기)은 이 도감 그림에서 x, y로 바로잡았습니다.
- MATH-13: 원자료 3번의 예 θ_new = θ(1 − 2α)에 "등비수열, |1 − 2α| < 1일 때 수렴"이라는 조건을 덧붙였습니다.
- MATH-13: 원자료 7번(선형 회귀)에 5장 데이터로 경사하강을 돌려 정규방정식과 같은 답이 나오는 것을 확인해 넣었습니다.
- MATH-14: 원자료 7번 예제의 "after standardization"은 실제로는 평균만 0으로 맞춘 중심화 데이터라서(각 특성 분산 2/3), 이 도감에서는 "중심화"라고 고쳐 썼습니다.
- MATH-14: 원자료 3번의 고유벡터 [1, λ − 4]에 숫자(≈ [1, 0.618])와 정규화 값([0.851, 0.526])을 덧붙였습니다.
- MATH-15: 원자료 5번의 편미분 예(x²y + 3xy²)는 12장 예(x²y + 3xy + y²)와 다른 함수입니다. 두 결과를 섞지 않게 각 장에 따로 적었습니다.
- MATH-15: 원자료 3번은 분산을 n − 1, 공분산을 n으로 나눠 적었습니다. 이 차이를 항목의 주의 상자에 밝혔습니다.
- MATH-15: 원자료 10번 ③(PCA) 예는 단계만 있어 이 도감에서 계산(λ ≈ 1.268, 0.066, 설명 비율 약 95.1%)을 마쳤습니다.
- MATH-15: 원자료 6번의 헤세 조건은 극소·극대의 충분조건이라는 설명을 덧붙였습니다.
