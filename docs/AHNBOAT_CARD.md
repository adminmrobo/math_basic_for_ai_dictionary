# ahnboat.xyz 홈페이지 카드 — 수리 도감

**놓을 곳:** 「좌표 첫걸음」 카드의 **왼쪽**(같은 줄 맨 앞). 순서: **수리 도감 → 좌표 첫걸음 → 최적화 첫걸음**.
(수리 도감 = 낱말 찾기, 좌표 첫걸음 = 나는 어디에 있는가, 최적화 첫걸음 = 어디로 가야 하나)

ahnboat.xyz는 WordPress라 이 저장소에서 직접 고칠 수 없습니다. WordPress 편집기에서 좌표 첫걸음 카드가 있는 블록을 열고, 그 카드 **바로 앞**에 아래 조각을 넣으세요. 기존 카드에 쓰는 블록(이미지 + 제목 + 설명 + 버튼)이 있다면 같은 블록을 복제해 아래 글과 주소만 바꾸는 쪽이 모양이 더 잘 맞습니다.
