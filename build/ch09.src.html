09-01

확률분포란 What is a Probability Distribution

확률변수가 가질 수 있는 값들과 각 값의 확률을 보여 주는 것.

말로 먼저 확률변수 X는 "실험 결과를 숫자로 바꾼 것"이에요. 동전 세 번에서 앞면 수 X는 0, 1, 2, 3 중 하나죠. 각 값의 확률(1/8, 3/8, 3/8, 1/8)을 모은 것이 분포입니다. 확률을 모두 더하면 언제나 1이에요.
숫자로 한 번 해 보기
  1. X = 동전 3번 중 앞면 수
  2. P(X=0) = 1/8, P(X=1) = 3/8, P(X=2) = 3/8, P(X=3) = 1/8
  3. 합 = 8/8 = 1 ✔
학교 수학으로 보면
고등 "확률변수와 확률분포".
AI에서는
모델이 "고양이 0.7, 개 0.2, 새 0.1"을 내면 그것이 정답에 대한 분포예요. 합이 1이 되게 만드는 함수가 소프트맥스(15장).
09-02

이산과 연속 Types of Probability Distributions

이산 = 셀 수 있는 값(베르누이·이항·포아송·기하·이산 균등), 연속 = 어떤 실수든(정규·균등·지수·감마·베타).

말로 먼저 주사위 눈, 오늘 온 전화 수는 0, 1, 2…처럼 셀 수 있어 이산이에요. 키, 기다린 시간은 170.3 cm, 2.71분처럼 어떤 값이든 될 수 있어 연속입니다. 연속 분포에서는 "정확히 170.000…cm일 확률"은 0이고, 구간의 넓이로 확률을 셉니다.
숫자로 한 번 해 보기
  1. 이산: P(X = 2)처럼 한 값의 확률(막대 높이)
  2. 연속: P(165 ≤ X ≤ 175)처럼 구간의 넓이
  3. 연속에서 P(X = 170) = 0
학교 수학으로 보면
고등 "이산확률변수·연속확률변수".
AI에서는
분류 = 이산 분포 예측, 회귀 = 연속값 예측. 손실 함수 선택이 여기서 갈립니다.
09-03

베르누이 분포 Bernoulli Distribution

성공(1) 또는 실패(0) 한 번. 모수 p. P(X = x) = pˣ(1−p)¹⁻ˣ.

말로 먼저 동전 한 번, 메일 한 통이 스팸인지 아닌지처럼 결과가 둘뿐인 시행이에요. 식은 x = 1이면 p, x = 0이면 1 − p를 한 줄로 쓴 것입니다.
숫자로 한 번 해 보기
  1. P(앞면) = 0.6인 동전
  2. P(X = 1) = 0.6¹ × 0.4⁰ = 0.6
  3. P(X = 0) = 0.6⁰ × 0.4¹ = 0.4
학교 수학으로 보면
고등 "독립시행"의 한 번.
AI에서는
이진 분류의 출력(로지스틱 회귀·시그모이드)이 베르누이 분포의 p예요. 손실은 이진 교차 엔트로피(15장).
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
P(X=x) = pˣ(1−p)¹⁻ˣ, x ∈ {0, 1}베르누이한 번의 성공·실패
09-04

이항 분포 Binomial Distribution

독립 베르누이 시행 n번 중 성공 횟수. P(X = k) = C(n,k)·pᵏ(1−p)ⁿ⁻ᵏ.

말로 먼저 동전 5번(p = 0.5) 중 앞면이 딱 2번일 확률: "어느 2번이 앞면인가"의 경우의 수 C(5, 2) = 10에, 한 가지 순서의 확률 0.5² × 0.5³을 곱해요.
숫자로 한 번 해 보기
  1. C(5, 2) = 5! / (2! × 3!) = 10
  2. 0.5² × 0.5³ = 0.03125
  3. P(X = 2) = 10 × 0.03125 = 0.3125
  4. 평균 np = 2.5
학교 수학으로 보면
고등 "이항분포", "조합".
AI에서는
"광고 100번 보여 줬을 때 클릭 수", "시험 문제 20개 중 맞힌 수"의 분포.
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
C(n,k) = n! / (k!(n−k)!)조합n개 중 k개 고르기
P(X=k) = C(n,k)pᵏ(1−p)ⁿ⁻ᵏ이항n번 중 k번 성공
평균 np, 분산 np(1−p)이항의 평균·분산
09-05

포아송 분포 Poisson Distribution

정해진 시간·공간에서 일어나는 사건 수. 모수 λ(평균 횟수). P(X = k) = e^−λ λᵏ / k!.

말로 먼저 시간당 평균 3통의 전화가 오는 콜센터에서 다음 한 시간에 딱 2통 올 확률을 계산합니다. 드물고 서로 독립적으로 일어나는 일의 "개수"에 잘 맞아요.
숫자로 한 번 해 보기
  1. λ = 3, k = 2
  2. e⁻³ ≈ 0.0498, 3² / 2! = 4.5
  3. P(X = 2) ≈ 0.0498 × 4.5 ≈ 0.2240
  4. 평균 = 분산 = λ = 3
학교 수학으로 보면
고등 이항분포의 확장(교과서 심화).
AI에서는
웹사이트 시간당 접속 수, 공장 불량 수, 사고 건수 예측. 개수 회귀(포아송 회귀)에 씁니다.
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
P(X=k) = e^(−λ) λᵏ / k!포아송평균 λ번 일어날 때 k번
09-06

정규(가우스) 분포 Normal (Gaussian) Distribution

가장 중요한 연속 분포. 평균 μ에서 가장 높은 좌우 대칭 종 모양. X ~ N(μ, σ²).

말로 먼저 키·몸무게·시험 점수처럼 작은 원인이 많이 더해진 값은 종 모양을 따르는 경우가 많아요. μ가 봉우리 위치, σ가 폭을 정합니다. 평균 ± 1σ 안에 약 68%, ± 2σ 안에 약 95%, ± 3σ 안에 약 99.7%가 들어와요.
숫자로 한 번 해 보기
  1. 학생 키 μ = 170 cm, σ = 10 cm
  2. 160~180 cm (± 1σ) → 약 68%
  3. 180 cm 이상 → z = 1 → 약 15.9%
  4. 150~190 cm (± 2σ) → 약 95%
학교 수학으로 보면
고등 "정규분포", "표준정규분포 z = (X − μ)/σ".
AI에서는
측정 오차, 가중치 초기값, 데이터 노이즈의 기본 가정. 회귀의 제곱 오차(MSE)는 "오차가 정규분포"라는 가정과 짝이에요.
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
f(x) = 1/(σ√(2π)) · e^(−(x−μ)²/(2σ²))정규 밀도종 모양 곡선
z = (x − μ) / σ표준화N(0, 1)로 옮기기
09-07

균등 분포 Uniform Distribution

범위 안 모든 값이 똑같이 그럴듯함. 연속 균등 U(a, b)의 밀도는 1/(b − a).

말로 먼저 0~10 사이 아무 실수나 똑같이 나온다면, 높이 1/10인 직사각형이 분포예요. 구간의 확률 = 구간 길이 × 높이. 주사위처럼 이산 균등 분포도 있어요.
숫자로 한 번 해 보기
  1. X ~ U(0, 10) → 높이 1/10
  2. P(2 ≤ X ≤ 8) = (8 − 2)/(10 − 0) = 0.6
  3. 평균 = (a + b)/2 = 5
학교 수학으로 보면
고등 "연속확률변수"의 가장 간단한 예.
AI에서는
무작위 초기값, 하이퍼파라미터 무작위 탐색, 데이터 섞기에 쓰여요.
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
f(x) = 1/(b − a), a ≤ x ≤ b균등 밀도직사각형

지수 분포 Exponential Distribution

포아송 과정에서 다음 사건까지 기다리는 시간. f(x) = λe^(−λx), x ≥ 0.

말로 먼저 버스가 평균 2분마다 무작위로 온다면(λ = 0.5), 다음 버스까지 기다리는 시간이 지수 분포예요. 짧게 기다릴 일이 가장 흔하고, 오래 기다릴 확률은 점점 줄어듭니다.
숫자로 한 번 해 보기
  1. λ = 0.5 → 평균 대기 1/λ = 2
  2. P(X > 3) = e^(−0.5 × 3) = e^(−1.5) ≈ 0.2231
  3. P(X ≤ 3) = 1 − 0.2231 ≈ 0.7769
학교 수학으로 보면
고등 지수함수 + 연속확률분포(심화).
AI에서는
서버 요청 사이 시간, 기계 고장까지의 시간(생존 분석) 모델.
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
f(x) = λe^(−λx)지수 밀도기다리는 시간
P(X > x) = e^(−λx)꼬리 확률x보다 오래 기다릴 확률

그 밖의 중요한 분포와 정리 Other Important Distributions

기하(첫 성공까지 시행 수), 감마(지수의 일반화), 베타(0~1 사이 확률 모델), t(작은 표본 추론), 카이제곱(분산·검정), F(분산 비교, ANOVA).

말로 먼저 정리: 분포는 값이 어떻게 퍼져 있는지 설명합니다. 이산은 베르누이·이항·포아송·기하, 연속은 정규·균등·지수 등. 정규분포가 실제 데이터와 ML에서 가장 널리 쓰이고, 데이터와 문제 종류에 맞는 분포를 고르는 것이 중요해요.
숫자로 한 번 해 보기
  1. 기하: 주사위로 6이 처음 나올 때까지 → 평균 6번
  2. 베타: "클릭률이 0.1쯤일 것"이라는 믿음을 0~1 위의 곡선으로
  3. t: 표본이 30개 안팎으로 적을 때 정규 대신
학교 수학으로 보면
고등 "통계적 추정"(t 분포는 대학 통계).
AI에서는
분류·회귀·베이지안 모델·가설 검정 등 많은 ML 알고리즘의 바탕. A/B 테스트에서 t·카이제곱 검정을 씁니다.

실험분포 진열장 — 모양을 바꾸며 확률 읽기

왜 이 방법을 쓰나
  1. 문제: 콜센터에 내일 몇 명을 배치해야 할지 정하려면 "전화가 10통 넘게 올 확률"을 알아야 합니다.
  2. 앞 방법의 한계: 평균(시간당 3통)만으로는 "많이 몰리는 날"이 얼마나 드문지 알 수 없습니다.
  3. 이 방법의 해법: 데이터에 맞는 분포(포아송 λ = 3)를 정하면, 어떤 개수든 그 확률을 식으로 바로 계산합니다.

쉽게 말하면 날씨 예보가 "평균 기온"만이 아니라 "영하로 떨어질 확률"까지 알려 주는 것.

연구원이 묻고, 조교 하루가 풀어 봅니다

X3이항 분포 식에 있는 C(n, k)는 왜 곱해요? 0.5² × 0.5³만 하면 안 돼요?

말로 먼저 0.5² × 0.5³은 "앞앞뒤뒤뒤"처럼 한 가지 순서의 확률이에요. 앞면 2번이 나오는 순서는 여러 가지(앞뒤앞뒤뒤 등)라서 그 가짓수를 곱해야 해요.

학교 수학으로 보면 고등 "조합" ⁿCₖ, 독립시행의 확률.

숫자로 한 번 해 보기
  1. 앞면 2번 자리 고르기: C(5, 2) = 10가지
  2. 한 순서의 확률: 0.03125
  3. 10 × 0.03125 = 0.3125
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
C(n,k)엔 씨 케이성공 자리 고르는 가짓수
pᵏ피의 케이 제곱성공 k번
(1−p)ⁿ⁻ᵏ실패 n − k번

조교 하루실험실에서 이항을 고르고 n = 5, p = 0.5, k = 2로 맞춰 보세요. 0.3125가 나와요.

박사의 정리

분포를 정한다는 것은 "이 데이터는 이런 방식으로 흩어진다"고 가정하는 일입니다. 가정이 맞으면 드문 일의 확률까지 계산할 수 있지만, 틀리면 계산이 정확해도 결론이 틀려요. 그래서 분포를 쓰기 전에 히스토그램(8장)으로 모양부터 확인합니다.

이 실험의 한계 진열장은 분포 여섯 개만 그립니다. 기하·감마·베타·t·카이제곱·F는 코랩 코드(scipy.stats)로 그려 볼 수 있어요.
AI 판단 코너주판봇의 "키 분포가 정규니까 키가 200 cm 넘을 확률은 0"

박사는 늘 두 가지를 묻습니다. "가정이 맞나? 숫자가 그럴듯한가?"

  1. 가정이 맞나? 정규분포 곡선은 어디까지 이어지나요? 꼬리가 0에 "닿나요"?
  2. 숫자가 그럴듯한가? μ = 170, σ = 10이면 200 cm는 몇 σ 떨어진 곳인가요?
확인해 보기 (먼저 스스로 따져 본 뒤 펼치세요)

정규분포의 꼬리는 0에 가까워질 뿐 0이 되지 않아요. 200 cm는 z = 3이라 P(X > 200) ≈ 0.0013, 약 0.13%입니다. 1만 명이면 13명쯤이에요. "아주 드물다"와 "불가능"은 다릅니다. 반대로, 정규분포는 키가 −50 cm일 확률도 아주 작게나마 주는데, 이건 모델(가정)이 현실과 어긋나는 곳이라는 점도 함께 기억하세요.

# %% 1. 다섯 가지 확률: 공식 vs scipy
import math
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

binom_formula = math.comb(5, 2) * 0.5**2 * 0.5**3
pois_formula = math.exp(-3) * 3**2 / math.factorial(2)
print(f"이항 P(X=2)      : 공식 {binom_formula:.4f} / scipy {stats.binom.pmf(2, 5, 0.5):.4f}")
print(f"포아송 P(X=2)    : 공식 {pois_formula:.4f} / scipy {stats.poisson.pmf(2, 3):.4f}")
print(f"균등 P(2<=X<=8)  : 공식 {(8-2)/(10-0):.4f} / scipy {stats.uniform(0, 10).cdf(8) - stats.uniform(0, 10).cdf(2):.4f}")
print(f"지수 P(X>3)      : 공식 {math.exp(-0.5*3):.4f} / scipy {stats.expon(scale=1/0.5).sf(3):.4f}  (scale = 1/λ)")
print(f"정규 P(X>180)    : scipy {stats.norm(170, 10).sf(180):.4f}  (z = 1)")
print(f"베르누이 P(X=1)  : {stats.bernoulli(0.6).pmf(1):.1f}")

# %% 2. 여섯 분포의 모양
fig, ax = plt.subplots(2, 3, figsize=(12, 6))
ax[0, 0].bar([0, 1], stats.bernoulli(0.6).pmf([0, 1]), color=["pink", "skyblue"]); ax[0, 0].set_title("Bernoulli p=0.6")
k = np.arange(0, 6); ax[0, 1].bar(k, stats.binom.pmf(k, 5, 0.5)); ax[0, 1].set_title("Binomial n=5, p=0.5")
k = np.arange(0, 11); ax[0, 2].bar(k, stats.poisson.pmf(k, 3), color="pink"); ax[0, 2].set_title("Poisson lambda=3")
x = np.linspace(130, 210, 300); ax[1, 0].plot(x, stats.norm(170, 10).pdf(x)); ax[1, 0].set_title("Normal mu=170, sigma=10")
x = np.linspace(-2, 12, 300); ax[1, 1].plot(x, stats.uniform(0, 10).pdf(x)); ax[1, 1].set_title("Uniform U(0,10)")
x = np.linspace(0, 10, 300); ax[1, 2].plot(x, stats.expon(scale=2).pdf(x), "r"); ax[1, 2].set_title("Exponential lambda=0.5")
plt.tight_layout(); plt.show()

# %% 3. 68-95-99.7 규칙
for s in [1, 2, 3]:
    print(f"평균 ± {s}σ 안: {stats.norm.cdf(s) - stats.norm.cdf(-s):.4f}")
print(f"키 200cm 초과(z=3): {stats.norm(170, 10).sf(200):.4f}")

# %% 4. 시뮬레이션 vs 이론 (이항 n=5, p=0.5)
rng = np.random.default_rng(3)
samples = rng.binomial(5, 0.5, size=100000)
print(" k | 실제 비율 | 이론 확률")
for kk in range(6):
    print(f" {kk} |  {np.mean(samples == kk):.4f}   |  {stats.binom.pmf(kk, 5, 0.5):.4f}")

정리 — 모르는 값의 모양에 이름을 붙인다

질문답 한 줄
확률분포란?확률변수가 가질 수 있는 값과 그 확률. 합은 1.
이산과 연속은?셀 수 있는 값(막대) vs 어떤 실수든(곡선, 넓이가 확률).
이항·포아송은?n번 중 성공 수(0.3125) / 정해진 시간의 사건 수(0.2240).
정규분포는?종 모양 N(μ, σ²). ±1σ 68%, ±2σ 95%, ±3σ 99.7%.
균등·지수는?모든 값이 똑같이(0.6) / 기다리는 시간(0.2231).

용어 대응 카드

확률분포란 = 확률변수가 가질 수 있는 값들과 각 값의 확률을 보여 주는 것.
이산과 연속 = 이산 = 셀 수 있는 값(베르누이·이항·포아송·기하·이산 균등), 연속 = 어떤 실수든(정규·균등·지수·감마·베타).
베르누이 분포 = 성공(1) 또는 실패(0) 한 번. 모수 p. P(X = x) = pˣ(1−p)¹⁻ˣ.
이항 분포 = 독립 베르누이 시행 n번 중 성공 횟수. P(X = k) = C(n,k)·pᵏ(1−p)ⁿ⁻ᵏ.
포아송 분포 = 정해진 시간·공간에서 일어나는 사건 수. 모수 λ(평균 횟수). P(X = k) = e^−λ λᵏ / k!.
정규(가우스) 분포 = 가장 중요한 연속 분포. 평균 μ에서 가장 높은 좌우 대칭 종 모양. X ~ N(μ, σ²).
균등 분포 = 범위 안 모든 값이 똑같이 그럴듯함. 연속 균등 U(a, b)의 밀도는 1/(b − a).
지수 분포 = 포아송 과정에서 다음 사건까지 기다리는 시간. f(x) = λe^(−λx), x ≥ 0.
그 밖의 중요한 분포와 정리 = 기하(첫 성공까지 시행 수), 감마(지수의 일반화), 베타(0~1 사이 확률 모델), t(작은 표본 추론), 카이제곱(분산·검정), F(분산 비교, ANOVA).
