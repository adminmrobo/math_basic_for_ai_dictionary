01장 수학 기초 — 변수·식·함수

인공지능은 왜 "수학으로 말한다"고 할까? 첫 단어 네 개 — 변수, 상수, 식, 함수 — 부터 펼쳐 봅니다.

AI 모델은 결국 "숫자를 넣으면 숫자가 나오는 아주 큰 함수"입니다. 이 장은 그 함수를 읽기 위한 첫 단어들을 도감 항목 8개로 모았습니다. 바뀌는 값(변수)과 고정된 값(상수), 둘이 같다는 문장(방정식)과 그냥 계산 덩어리(식), 입력을 출력으로 바꾸는 규칙(함수), 넣을 수 있는 값과 나올 수 있는 값(정의역·치역)까지.

01-01

ML에서 수학이란 Mathematics in ML

모델이 어떻게 움직이는지 설명하는 언어이자 도구.

말로 먼저 수학은 ① 데이터를 숫자로 적고(표현), ② 모델을 만들고(규칙), ③ 모델 속 숫자를 고치고(최적화), ④ 얼마나 잘했는지 재는(평가) 네 가지 일을 맡습니다. 주로 쓰는 분야는 선형대수·확률·통계·미적분·최적화 다섯이에요.
숫자로 한 번 해 보기

  2. "내일 비 올 확률 70%" → 확률
  3. 시험 점수 평균·흩어짐 → 통계
  4. 오차를 줄이는 방향 찾기 → 미적분·최적화

AI에서는
이 도감의 열다섯 장이 다섯 분야를 차례로 맡습니다: 2~5장 선형대수, 6~10장 확률·통계, 11~13장 미적분·최적화, 14장 응용(PCA), 15장 총정리.

말로 먼저 "x"는 숫자가 들어갈 상자의 이름표예요. 오늘은 10이 들어가고 내일은 7이 들어갈 수 있습니다. 이름표 덕분에 아직 모르는 값도 문장 속에 쓸 수 있어요.
숫자로 한 번 해 보기

상수 Constant

바뀌지 않는 고정된 값. π = 3.1416…, e = 2.718…, 5, 10 같은 수.

말로 먼저 상수는 문제를 푸는 동안 움직이지 않는 숫자예요. 원주율 π는 어떤 원에서든 둘레 ÷ 지름 = 3.14159…로 같습니다.
숫자로 한 번 해 보기
  1. 반지름 1인 원의 둘레 = 2 × π × 1 ≈ 6.283
  2. 반지름 2이면 2 × π × 2 ≈ 12.566 — π는 그대로
  3. e ≈ 2.718은 11장 지수함수에서 다시 만나요
학교 수학으로 보면

헷갈리기 쉬운 점 "상수냐 변수냐"는 숫자 자체가 아니라 그 숫자가 지금 바뀌는 역할인지로 정해집니다.

01-04

방정식과 식 Equation & Expression

방정식은 "두 식이 같다"는 문장, 식은 변수와 상수를 엮은 계산 덩어리.

말로 먼저 3x + 5는 "x에 3을 곱하고 5를 더한 값"이라는 계산 덩어리(식)일 뿐, 참·거짓이 없습니다. 등호(=)로 두 식을 이으면 2x + 3 = 11처럼 참·거짓이 있는 문장(방정식)이 되고, 참이 되게 하는 x를 찾는 것이 "방정식을 푼다"예요.
숫자로 한 번 해 보기
  1. 2x + 3 = 11 → 2x = 8 → x = 4
  2. 확인: 2 × 4 + 3 = 11 ✔
  3. 식의 예: 3x + 5, x² + y, 2(x + 1)
학교 수학으로 보면
중1 일차방정식, 중2 연립방정식(5장에서 다시).
AI에서는
"오차 = (정답 − 예측)²"은 식, "예측 = 정답"이 되게 하는 값을 찾는 것은 방정식 풀기와 같은 생각이에요. 5장 연립방정식, 13장 최적화로 이어집니다.
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
2x + 3 = 11이 x 더하기 삼은 십일방정식 — 참이 되는 x는 4
3x + 5삼 x 더하기 오식 — 값만 있고 참·거짓이 없음
01-05

함수 Function

입력 x 하나를 넣으면 출력 y 하나가 정해져 나오는 규칙. y = f(x).

말로 먼저 함수는 자판기와 같아요. 버튼(입력)을 누르면 정해진 음료(출력)가 나옵니다. 같은 버튼에서 매번 다른 음료가 나오면 고장 난 자판기, 즉 함수가 아니에요. f(x) = 2x + 3은 "넣은 수를 두 배 하고 3을 더해서 내보내라"는 규칙입니다.
숫자로 한 번 해 보기
  1. x = −2 → 2(−2) + 3 = −1
  2. x = 0 → 3, x = 1 → 5
  3. x = 2 → 7 (원자료 표와 같음)
학교 수학으로 보면

식으로 보면 (몰라도 됩니다)

ML에서 흔한 함수 네 종류 Types of Functions

일차(직선), 이차(그릇), 다항(구불구불), 비선형(sin, eˣ 등 곡선).

말로 먼저 ① 일차 f(x) = ax + b — 곧은 직선. ② 이차 f(x) = ax² + bx + c — 그릇 모양. ③ 다항 f(x) = aₙxⁿ + … + a₁x + a₀ — 여러 번 굽은 곡선. ④ 비선형 — sin x처럼 오르내리거나 eˣ처럼 폭발하는 곡선.
숫자로 한 번 해 보기
  1. 일차 2x + 3: x가 1 늘면 y는 늘 2씩 증가
  2. 이차 x²: x = −1, 0, 1에서 1, 0, 1 — 바닥이 0
  3. eˣ: x = 0, 1, 2에서 1, 2.718, 7.389
학교 수학으로 보면
중2 일차함수, 중3 이차함수, 고등 다항식·삼각함수·지수함수.
AI에서는
선형 회귀는 일차함수, 손실 함수는 흔히 이차함수 그릇, 다항 회귀는 다항함수, 신경망의 활성화 함수(시그모이드·ReLU)는 비선형 함수입니다.
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
f(x) = ax + b일차a 기울기, b 절편
f(x) = ax² + bx + c이차a > 0이면 아래로 볼록
aₙxⁿ + … + a₀다항n차까지 거듭제곱의 합
sin x, eˣ사인, 지수비선형
01-07

정의역과 치역 Domain & Range

정의역 = 넣을 수 있는 입력 전체, 치역 = 실제로 나올 수 있는 출력 전체.

말로 먼저 f(x) = √x는 음수를 넣을 수 없어요(제곱해서 음수가 되는 실수는 없으니까요). 그래서 정의역은 x ≥ 0, 나오는 값도 0 이상이라 치역은 y ≥ 0입니다.
숫자로 한 번 해 보기
  1. √0 = 0, √4 = 2, √9 = 3
  2. √(−4)는 실수 범위에서 없음 → 정의역 밖
  3. 출력이 음수인 경우가 없음 → 치역 y ≥ 0
학교 수학으로 보면
중1 함수의 정의역·공역·치역, 고1 함수 단원.
AI에서는
확률을 내는 함수는 치역이 0~1이어야 해요(시그모이드가 그렇게 만들어 줌). 로그 함수는 정의역이 x > 0이라 0을 넣으면 계산이 터집니다(코드에서 log(0) 오류).
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
f(x) = √x루트 x정의역 x ≥ 0, 치역 y ≥ 0
01-08

ML에서 왜 중요한가 Why it is Important in ML

데이터·모델 식 이해, 알고리즘 만들기, 최적화, 경사하강·PCA 같은 고급 주제의 바탕.

말로 먼저 이 장의 단어들은 이후 모든 장에서 계속 나옵니다. 경사하강(13장)은 "함수의 기울기"를, PCA(14장)는 "행렬로 쓴 함수"를 다룹니다. 요약하면: 변수는 바뀌고 상수는 고정, 함수는 입력을 출력으로, 정의역은 가능한 입력, 치역은 가능한 출력.
숫자로 한 번 해 보기
  1. 핵심 넷: 변수·식·함수·정의역/치역
  2. 연습 방법: 작은 숫자 하나를 직접 넣어 보기
  3. 다음: 2장에서 "숫자 여러 개를 한 번에" 다루는 벡터·행렬
학교 수학으로 보면
고등 수학 전체의 "함수적 사고".
AI에서는
모델 설명서의 "입력 차원", "출력 범위", "파라미터"가 각각 정의역, 치역, 상수(가중치)에 해당합니다.

실험함수 기계 실험실 — a와 b를 돌려 그래프 바꾸기

왜 이 방법을 쓰나
  1. 문제: "키가 크면 몸무게도 늘어난다"를 컴퓨터가 계산하려면 말이 아닌 규칙이 필요합니다.
  2. 앞 방법의 한계: 말로 쓴 규칙("대충 비례")은 숫자를 넣어 출력을 낼 수 없습니다.
  3. 이 방법의 해법: 입력 x를 출력 y로 바꾸는 함수 f(x)로 적으면, 어떤 x든 넣어 y를 계산할 수 있습니다.

쉽게 말하면 레시피를 "적당히"가 아니라 "설탕 2스푼 + 3g"으로 적는 것.

연구원이 묻고, 조교 하루가 풀어 봅니다

시아f(x) = 2x + 3에서 2랑 3은 각각 무슨 일을 해요?

말로 먼저 2는 "x가 1 늘 때 y가 얼마나 느는지"(기울기), 3은 "x가 0일 때 y가 어디서 출발하는지"(절편)예요.

학교 수학으로 보면 중2 일차함수 y = ax + b의 기울기와 y절편.

숫자로 한 번 해 보기
  1. x: 0 → 1 이면 y: 3 → 5, 2만큼 증가
  2. x: 1 → 2 이면 y: 5 → 7, 또 2만큼
  3. x = 0일 때 y = 3 — 그래프가 y축과 만나는 곳
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
a에이, 기울기x 한 걸음당 y의 변화
b비, 절편x = 0일 때 y

조교 하루실험실에서 a를 바꾸면 기울기가, b를 바꾸면 높이가 바뀌는지 눈으로 확인해 보세요.

박사의 정리

함수는 "규칙을 숫자로 적은 것"입니다. a·b 같은 숫자를 바꾸면 규칙이 바뀌고, AI가 학습한다는 것은 바로 이 숫자들을 데이터에 맞게 고치는 일이에요. 오늘 손으로 돌린 a, b가 AI의 "가중치"입니다.

이 실험의 한계 실제 모델은 입력이 x 하나가 아니라 수백~수백만 개입니다. 여러 입력을 한 번에 다루는 법은 2~4장(벡터·행렬)에서 봅니다.
AI 판단 코너주판봇의 "√(−4) = −2" 사건

박사는 늘 두 가지를 묻습니다. "가정이 맞나? 숫자가 그럴듯한가?"

  1. 가정이 맞나? √x는 어떤 x를 넣을 수 있는 함수였나요(정의역)?
  2. 숫자가 그럴듯한가? (−2)²을 계산하면 −4가 나오나요?
확인해 보기 (먼저 스스로 따져 본 뒤 펼치세요)

틀렸습니다. (−2)² = 4이지 −4가 아니에요. 제곱해서 음수가 되는 실수는 없으므로 √(−4)는 실수 범위에서 정의되지 않습니다(정의역 x ≥ 0 밖). 실제 코드에서도 numpy.sqrt(−4)는 경고와 함께 nan(숫자 아님)을 냅니다.

# %% 1. 함수 f(x) = 2x + 3과 값 표
import numpy as np
import matplotlib.pyplot as plt

def f(x):
    """입력 x를 두 배 하고 3을 더해 내보내는 함수"""
    return 2 * x + 3

print("x  | f(x) = 2x + 3")
for x in [-2, -1, 0, 1, 2]:
    print(f"{x:>2} | {f(x):>3}")

# %% 2. ML에서 흔한 함수 네 종류 그리기
xs = np.linspace(-3, 3, 200)
funcs = {
    "Linear: 2x + 3": 2 * xs + 3,
    "Quadratic: x^2": xs ** 2,
    "Polynomial: 0.1x^3 - x": 0.1 * xs ** 3 - xs,
    "Non-linear: sin(x), e^x": None,
}
fig, axes = plt.subplots(2, 2, figsize=(9, 6))
for ax, (name, ys) in zip(axes.ravel(), funcs.items()):
    if ys is None:
        ax.plot(xs, np.sin(xs), label="sin(x)")
        ax.plot(xs, np.exp(xs) / 5, label="e^x / 5")
        ax.legend()
    else:
        ax.plot(xs, ys)
    ax.axhline(0, color="gray", lw=0.8); ax.axvline(0, color="gray", lw=0.8)
    ax.set_title(name)
plt.tight_layout(); plt.show()

# %% 3. 정의역 검사: sqrt(x)는 x >= 0에서만
def safe_sqrt(x):
    if x < 0:
        return f"{x}은(는) 정의역 밖 (x >= 0 이어야 함)"
    return np.sqrt(x)

for x in [0, 4, 9, -4]:
    print("sqrt(", x, ") ->", safe_sqrt(x))
with np.errstate(invalid="ignore"):
    print("numpy.sqrt(-4) 그대로 계산하면:", np.sqrt(-4.0))   # nan = 숫자가 아님

# %% 4. 방정식 2x + 3 = 11 풀고 확인하기
x_sol = (11 - 3) / 2
print("해 x =", x_sol, "/ 대입 확인 2x+3 =", f(x_sol), "->", f(x_sol) == 11)

# %% 5. 상수 pi와 e
print("pi =", round(np.pi, 4), "/ e =", round(np.e, 3))
for r in [1, 2]:
    print(f"반지름 {r}인 원의 둘레 2*pi*r = {2 * np.pi * r:.3f}")
print("배운 점: 1) 함수는 입력 하나에 출력 하나  2) 정의역 밖 입력은 nan  3) 상수는 그대로, 변수만 바뀐다")

정리 — 함수는 AI를 읽는 첫 단어

질문답 한 줄
변수와 상수의 차이는?변수는 값이 바뀌는 이름표, 상수는 고정된 값(π, e, 5).
방정식과 식의 차이는?방정식은 등호가 있는 참·거짓 문장(2x + 3 = 11), 식은 계산 덩어리(3x + 5).
함수란?입력 하나에 출력 하나가 정해지는 규칙. AI 모델 전체가 하나의 큰 함수.
정의역과 치역은?넣을 수 있는 입력 전체와 나올 수 있는 출력 전체. √x는 둘 다 0 이상.
AI에서 흔한 함수는?일차(선형 회귀), 이차(손실 그릇), 다항(다항 회귀), 비선형(활성화 함수).

용어 대응 카드

ML에서 수학이란 = 모델이 어떻게 움직이는지 설명하는 언어이자 도구.
변수 = 바뀔 수 있는 값에 붙인 이름표. 보통 x, y, z로 씁니다.
상수 = 바뀌지 않는 고정된 값. π = 3.1416…, e = 2.718…, 5, 10 같은 수.
방정식과 식 = 방정식은 "두 식이 같다"는 문장, 식은 변수와 상수를 엮은 계산 덩어리.
함수 = 입력 x 하나를 넣으면 출력 y 하나가 정해져 나오는 규칙. y = f(x).
ML에서 흔한 함수 네 종류 = 일차(직선), 이차(그릇), 다항(구불구불), 비선형(sin, eˣ 등 곡선).
정의역과 치역 = 정의역 = 넣을 수 있는 입력 전체, 치역 = 실제로 나올 수 있는 출력 전체.
ML에서 왜 중요한가 = 데이터·모델 식 이해, 알고리즘 만들기, 최적화, 경사하강·PCA 같은 고급 주제의 바탕.

원자료와 다르게 쓴 곳

  • 원자료 1번 상자의 문장은 그대로 옮기고, 다섯 분야가 도감의 어느 장인지 덧붙였습니다.
  • 원자료 "상수" 상자에 "가중치는 학습 중엔 변수, 예측할 땐 상수처럼 쓰인다"는 설명을 보탰습니다(원자료에는 없음).

비유와 예시의 한계

  • 자판기 비유는 "입력 하나에 출력 하나"만 보여 줍니다. 확률을 내는 모델처럼 출력이 확률인 경우도 함수예요(출력이 "확률 숫자" 하나).
  • 여기서는 실수 범위만 봤습니다. 복소수까지 넓히면 √(−4) = 2i가 있지만 이 도감에서는 다루지 않아요.
