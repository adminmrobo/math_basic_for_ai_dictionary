10-01

공분산이란 What is Covariance

두 변수가 같은 방향으로 움직이는지(+) 반대로 움직이는지(−) 알려 주는 값. Cov = Σ(xᵢ − x̄)(yᵢ − ȳ) / n.

말로 먼저 각 점에서 "x가 평균보다 큰가"와 "y가 평균보다 큰가"를 곱해요. 둘 다 크거나 둘 다 작으면 곱이 양수, 엇갈리면 음수예요. 이 곱들의 평균이 공분산입니다. 다만 크기는 단위에 따라 달라져서 "얼마나 강한가"는 말해 주지 못해요.
숫자로 한 번 해 보기
  1. 평균보다 둘 다 큰 점 (5, 5): (+2) × (+1) = +2
  2. 둘 다 작은 점 (1, 2): (−2) × (−2) = +4
  3. 엇갈린 점이 있으면 음수가 더해짐
학교 수학으로 보면
중3 "편차", 고등 "상관관계"의 수식판(대학 통계).
AI에서는
공분산 행렬(14장)의 한 항목. 특성들이 함께 움직이는 구조를 한 표로 정리해요.
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
Cov(X,Y) = (1/n) Σ (xᵢ − x̄)(yᵢ − ȳ)공분산편차 곱의 평균
10-02

공분산 읽기 Interpretation of Covariance

Cov > 0 함께 증가, Cov < 0 하나가 늘면 다른 하나가 줆, Cov = 0 직선 관계 없음.

말로 먼저 공부 시간↑·점수↑는 양수, 가격↑·수요↓는 음수예요. 0이면 "직선 관계가 없다"는 뜻일 뿐, 아무 관계도 없다는 뜻은 아니에요(곡선 관계는 있을 수 있음).
숫자로 한 번 해 보기
  1. 공부 시간과 점수 → Cov > 0
  2. 가격과 판매량 → Cov < 0
  3. 키와 생일 날짜 → Cov ≈ 0 (관련 없음)
학교 수학으로 보면
고등 "양의 상관관계·음의 상관관계".
AI에서는
음의 공분산도 유용한 정보예요. "할인율↑ → 반품률↓" 같은 관계를 모델이 씁니다.

헷갈리기 쉬운 점 원자료 표의 "키와 신발 크기(관련 없을 수도)"는 실제로는 양의 관계가 있는 경우가 많아, 이 도감에서는 "키와 생일 날짜"로 바꿨습니다.

10-03

공분산 계산 예 Example: Covariance Calculation

X = 1, 2, 3, 4, 5, Y = 2, 4, 5, 4, 5 → Cov = 6/5 = 1.2 (양의 관계).

말로 먼저 평균은 x̄ = 3, ȳ = 4. 다섯 점의 편차 곱을 구해 더하고 5로 나눕니다.
숫자로 한 번 해 보기
  1. (1−3)(2−4) = (−2)(−2) = 4
  2. (2−3)(4−4) = 0, (3−3)(5−4) = 0, (4−3)(4−4) = 0
  3. (5−3)(5−4) = (2)(1) = 2
  4. 합 6 ÷ 5 = 1.2
학교 수학으로 보면
평균·편차 계산(중3).
AI에서는
코드로는 np.cov(x, y, ddof=0)[0, 1]. 기본값(ddof=1)은 n − 1로 나눠 1.5가 나오니 주의.
10-04

상관계수란 What is Correlation

두 변수의 직선 관계의 세기와 방향. r = Cov(X, Y) / (σX σY), 늘 −1 ≤ r ≤ 1.

말로 먼저 공분산을 두 표준편차로 나누면 단위가 사라져서 "키와 몸무게"든 "온도와 아이스크림 판매"든 같은 잣대로 비교할 수 있어요. r = 1 완벽한 양의 직선, 0 < r < 1 양의 관계(1에 가까울수록 강함), r = 0 직선 관계 없음, −1 < r < 0 음의 관계, r = −1 완벽한 음의 직선.
숫자로 한 번 해 보기
  1. r = 0.9 → 강한 양의 관계
  2. r = 0.3 → 약한 양의 관계
  3. r = −0.8 → 강한 음의 관계
학교 수학으로 보면
고등 "상관계수"(통계, 교과서 심화).
AI에서는
가장 흔한 것은 피어슨 상관계수. 순위만 보는 스피어만 상관도 있어요.
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
r = Cov(X,Y) / (σX σY)피어슨 상관계수−1 ≤ r ≤ 1
10-05

상관계수 계산 예 Example: Correlation Calculation

같은 5점에서 σX = √2 ≈ 1.414, σY = √1.2 ≈ 1.095 → r = 1.2 / 1.549 ≈ 0.775.

말로 먼저 공분산 1.2는 앞에서 구했어요. 각 변수의 표준편차를 구해 곱하고 나누면 됩니다.
숫자로 한 번 해 보기
  1. σX = √[((−2)² + (−1)² + 0² + 1² + 2²)/5] = √(10/5) = √2 ≈ 1.414
  2. σY = √[((−2)² + 0² + 1² + 0² + 1²)/5] = √(6/5) = √1.2 ≈ 1.095
  3. r = 1.2 / (1.414 × 1.095) = 1.2 / 1.549 ≈ 0.775 → 꽤 강한 양의 관계
학교 수학으로 보면
표준편차 계산(중3) + 나눗셈.
AI에서는
np.corrcoef(x, y)[0, 1] = 0.7746. 상관계수는 n과 n − 1 어느 쪽으로 나눠도 같은 값이 나와요(분자·분모에서 지워짐).

산점도와 상관 Scatter Plots and Correlation

점 구름의 모양으로 상관을 눈으로 본다: 강한 양(r ≈ 1), 강한 음(r ≈ −1), 없음(r ≈ 0), 약한 양(r > 0).

말로 먼저 점이 오른쪽 위로 한 줄에 몰리면 r이 1에 가깝고, 오른쪽 아래로 몰리면 −1에 가까워요. 아무렇게나 흩어지면 0 근처. 숫자 r만 보지 말고 늘 그림을 함께 봐야 해요. 튀는 점 하나나 곡선 관계가 r을 속이거든요.
숫자로 한 번 해 보기
  1. 직선 위의 점들 → r = 1
  2. y = x² (−3 ~ 3) → 뚜렷한 관계인데 r = 0
  3. 점 하나가 멀리 튀면 r이 크게 바뀜

10-07

공분산 vs 상관 Covariance vs Correlation

공분산: 방향만, 범위 −∞~+∞, 단위에 따라 바뀜. 상관: 방향과 세기, −1~+1, 단위 없음.

말로 먼저 키를 cm에서 mm로 바꾸면 공분산은 10배가 되지만 상관계수는 그대로예요. 그래서 공분산은 예비 분석이나 PCA의 재료로, 상관은 ML과 통계 해석에서 널리 씁니다.
숫자로 한 번 해 보기
  1. Y를 10배 → Cov 1.2 → 12
  2. 같은 경우 r = 0.775 → 0.775
  3. 해석: 공분산 = 양/음/0, 상관 = 방향 + 세기
학교 수학으로 보면
단위 변환과 비율.

10-08

ML에서의 쓰임과 정리 Real-World Use in ML

특성 선택(겹치는 특성 제거), 회귀의 다중공선성 이해, 중요한 특성 찾기, EDA, 추천·금융·의료.

말로 먼저 정리: 공분산은 관계의 방향, 상관은 세기와 방향을 재고, 상관값은 언제나 −1과 1 사이이며, 산점도로 확인하고, 데이터 분석과 ML에서 널리 쓰입니다. 그리고 가장 중요한 주의 — 상관은 인과가 아니에요.
숫자로 한 번 해 보기
  1. 키(cm)와 키(inch)는 r = 1 → 하나만 남김
  2. 아이스크림 판매와 익사 사고는 r > 0 → 둘 다 "여름" 때문(인과 아님)
  3. 결과와 |r|이 큰 특성 → 후보 특성

헷갈리기 쉬운 점 상관관계 ≠ 인과관계. 숨은 공통 원인(교란 변수)이 둘을 함께 움직일 수 있어요.

실험점 구름 실험실 — 함께 움직이는 정도를 숫자 하나로

왜 이 방법을 쓰나
  1. 문제: 쇼핑몰 특성 50개 중 어느 것이 "구매 금액"과 함께 움직이는지 빨리 골라내고 싶습니다.
  2. 앞 방법의 한계: 공분산은 단위에 따라 크기가 달라져 "원 단위 금액"과 "횟수"를 같은 잣대로 비교할 수 없습니다.
  3. 이 방법의 해법: 표준편차로 나눠 단위를 지운 상관계수 r(−1~1)로 모든 특성을 같은 잣대에 올립니다.

쉽게 말하면 키 차이와 몸무게 차이를 각자의 "보통 차이"로 나눠 비교하는 것.

연구원이 묻고, 조교 하루가 풀어 봅니다

시아공분산을 표준편차 두 개로 나누면 왜 단위가 사라져요?

말로 먼저 공분산의 단위는 "X 단위 × Y 단위"(예: cm × kg)예요. σX는 cm, σY는 kg이라 둘을 곱해 나누면 단위가 지워지고 순수한 숫자만 남아요.

학교 수학으로 보면 단위 계산, 분수의 약분.

숫자로 한 번 해 보기
  1. Cov = 1.2 (단위: X × Y)
  2. σX σY = 1.414 × 1.095 = 1.549 (단위: X × Y)
  3. r = 1.2 / 1.549 ≈ 0.775 (단위 없음)
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
Cov(X,Y)공분산X 단위 × Y 단위
σX σY표준편차 곱X 단위 × Y 단위

조교 하루실험실에서 단위 배율을 ×10으로 올려 보세요. Cov는 10배, r은 그대로예요.

박사의 정리

상관계수는 "직선으로 얼마나 함께 가는가"만 재는 자입니다. 곡선 관계, 튀는 점, 숨은 원인은 이 자로 보이지 않아요. 그래서 r은 늘 산점도와 한 쌍으로 읽고, 높은 r을 보면 "왜 함께 움직일까?"를 꼭 물어야 합니다.

이 실험의 한계 실험실의 점은 정규분포로 만든 가상 데이터예요. 실제 데이터는 곡선 관계나 여러 무리가 섞인 모양이 흔합니다.
AI 판단 코너주판봇의 "공분산 1200 > 1.2니까 둘째 데이터의 관계가 훨씬 강하다"

박사는 늘 두 가지를 묻습니다. "가정이 맞나? 숫자가 그럴듯한가?"

  1. 가정이 맞나? 두 데이터의 단위가 같은가요? (첫째는 m, 둘째는 mm로 잰 것이라면?)
  2. 숫자가 그럴듯한가? 두 데이터의 상관계수를 각각 구하면 얼마인가요?
확인해 보기 (먼저 스스로 따져 본 뒤 펼치세요)

공분산은 단위에 따라 크기가 달라져요. 같은 관계라도 한쪽을 1000배 큰 단위로 재면 공분산은 1000배가 됩니다. 세기를 비교하려면 상관계수를 봐야 하고, 두 데이터의 r이 모두 0.775라면 관계의 세기는 같아요. "공분산의 크기로 세기를 비교하지 않는다" — 원자료 1번 상자의 마지막 줄이 바로 이 말입니다.

코드 펼치기 (몰라도 됩니다 · 35줄)
# %% 1. 공분산과 상관계수: 직접 vs numpy
import numpy as np
import matplotlib.pyplot as plt

X = np.array([1, 2, 3, 4, 5], dtype=float); Y = np.array([2, 4, 5, 4, 5], dtype=float)
mx, my = X.mean(), Y.mean()
cov = sum((x - mx) * (y - my) for x, y in zip(X, Y)) / len(X)
sx = np.sqrt(sum((x - mx) ** 2 for x in X) / len(X)); sy = np.sqrt(sum((y - my) ** 2 for y in Y) / len(Y))
r = cov / (sx * sy)
print(f"평균 x={mx}, y={my} / 공분산 = {cov} / σx = {sx:.3f}, σy = {sy:.3f} / r = {r:.4f}")
print("np.cov(ddof=0) =", np.cov(X, Y, ddof=0)[0, 1], "/ np.cov 기본(ddof=1) =", np.cov(X, Y)[0, 1], "(n-1로 나눔)")
print("np.corrcoef =", round(np.corrcoef(X, Y)[0, 1], 4))

# %% 2. 단위를 바꾸면?
print("배율 |   공분산 | 상관계수")
for k in [1, 10, 1000]:
    print(f"{k:>4} | {np.cov(X, Y * k, ddof=0)[0, 1]:>8.1f} | {np.corrcoef(X, Y * k)[0, 1]:.4f}")

# %% 3. 여러 상관의 산점도
rng = np.random.default_rng(0)
fig, axes = plt.subplots(2, 2, figsize=(8, 7))
for ax, target in zip(axes.ravel(), [0.95, -0.9, 0.0, 0.4]):
    a, b = rng.normal(size=100), rng.normal(size=100)
    x, y = a, target * a + np.sqrt(1 - target ** 2) * b
    ax.scatter(x, y, s=12); ax.set_title(f"r = {np.corrcoef(x, y)[0, 1]:.2f}")
plt.tight_layout(); plt.show()

# %% 4. 곡선 관계는 r = 0일 수 있다
xs = np.linspace(-3, 3, 61); ys = xs ** 2
print("y = x^2 의 상관계수 =", round(np.corrcoef(xs, ys)[0, 1], 6))
plt.scatter(xs, ys, s=10); plt.title("y = x^2 : strong relation, r = 0"); plt.show()

# %% 5. 튀는 점 하나의 힘
x5, y5 = np.append(X, 6), np.append(Y, 0)
print(f"점 (6, 0) 하나를 넣으면 r: {np.corrcoef(X, Y)[0, 1]:.3f} -> {np.corrcoef(x5, y5)[0, 1]:.3f}")

정리 — 함께 가는 정도를 −1~1로

질문답 한 줄
공분산은?편차 곱의 평균. 방향(+, −, 0)을 알려 줌. 원자료 예 1.2.
상관계수는?Cov ÷ (σX σY). 방향과 세기, −1~1. 원자료 예 0.775.
둘의 차이는?공분산은 단위에 따라 크기가 바뀌고, r은 단위가 없음.
산점도는 왜?r이 놓치는 곡선 관계와 튀는 점을 보여 줌.
가장 큰 주의는?상관은 인과가 아니다.

용어 대응 카드

공분산이란 = 두 변수가 같은 방향으로 움직이는지(+) 반대로 움직이는지(−) 알려 주는 값. Cov = Σ(xᵢ − x̄)(yᵢ − ȳ) / n.
공분산 읽기 = Cov > 0 함께 증가, Cov < 0 하나가 늘면 다른 하나가 줆, Cov = 0 직선 관계 없음.
공분산 계산 예 = X = 1, 2, 3, 4, 5, Y = 2, 4, 5, 4, 5 → Cov = 6/5 = 1.2 (양의 관계).
상관계수란 = 두 변수의 직선 관계의 세기와 방향. r = Cov(X, Y) / (σX σY), 늘 −1 ≤ r ≤ 1.
상관계수 계산 예 = 같은 5점에서 σX = √2 ≈ 1.414, σY = √1.2 ≈ 1.095 → r = 1.2 / 1.549 ≈ 0.775.
산점도와 상관 = 점 구름의 모양으로 상관을 눈으로 본다: 강한 양(r ≈ 1), 강한 음(r ≈ −1), 없음(r ≈ 0), 약한 양(r > 0).
공분산 vs 상관 = 공분산: 방향만, 범위 −∞~+∞, 단위에 따라 바뀜. 상관: 방향과 세기, −1~+1, 단위 없음.
ML에서의 쓰임과 정리 = 특성 선택(겹치는 특성 제거), 회귀의 다중공선성 이해, 중요한 특성 찾기, EDA, 추천·금융·의료.

원자료와 다르게 쓴 곳

  • 원자료 2번 표의 "키와 신발 크기(관련 없을 수도)"를 공분산 0의 예로 쓰지 않고 "키와 생일 날짜"로 바꿨습니다. 키와 신발 크기는 실제로 양의 관계가 있는 경우가 많기 때문입니다.
  • 원자료 7번 표에 "상관 ≠ 인과"와 "r = 0이어도 곡선 관계가 있을 수 있다"는 주의를 덧붙였습니다.
