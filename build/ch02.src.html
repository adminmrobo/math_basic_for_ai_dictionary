02장 선형대수 기초 — 스칼라·벡터·행렬

엑셀 표 한 장을 AI는 어떻게 "숫자 덩어리 하나"로 받아들일까?

1장에서 함수는 숫자 하나를 넣었습니다. 실제 데이터는 키·몸무게·나이처럼 여러 숫자가 한꺼번에 들어오지요. 이 장은 숫자를 담는 그릇 세 가지 — 숫자 하나(스칼라), 숫자 한 줄(벡터), 숫자 표(행렬) — 와 행렬의 이름표, 크기, 기호를 도감 항목 9개로 정리합니다.

글 · 안상선 ((주)M-Robo 대표) · 저자 소개 · 2026-11-26 · v1.0

처음이라면 「스칼라·벡터·행렬」 세 항목만 먼저 읽고 실험실에서 표 크기를 바꿔 보세요. 나머지 항목은 필요할 때 찾아보면 됩니다.

처음 오신 분께 — 이 장을 3줄로

  1. 무엇을 스칼라(숫자 하나), 벡터(한 줄), 행렬(행과 열로 된 표), 여러 종류의 행렬, m × n 크기, Aᵢⱼ·Aᵀ·A⁻¹ 같은 기호를 봅니다.
  2. 왜 중요한가 컴퓨터는 표를 행렬로 받아 한꺼번에 계산합니다. 데이터의 "모양"을 읽지 못하면 AI 코드의 오류 메시지 대부분을 읽을 수 없어요.
  3. AI에서는 데이터 한 건 = 벡터, 데이터 전체 = 행렬, 신경망의 가중치 = 행렬. 행 = 표본, 열 = 특성.

코드와 수식을 몰라도 됩니다. 항목마다 "말로 먼저"와 "숫자로 한 번 해 보기"가 먼저 나오고, 식은 "식으로 보면"을 펼칠 때만 나옵니다. 여기서 한 번 멈춰도 괜찮아요.

02-01

선형대수란 What is Linear Algebra

벡터·행렬과 "선형 변환"을 다루는 수학. 데이터를 숫자 표로 다루는 도구.

말로 먼저 선형대수는 숫자 여러 개를 한 묶음으로 다루고, 그 묶음을 늘이거나 돌리는(변환) 규칙을 연구합니다. "선형"은 직선처럼 곧게, 즉 2배 넣으면 2배 나오는 성질을 말해요. 선형 회귀·PCA·SVM·신경망이 모두 이 위에서 움직입니다.
숫자로 한 번 해 보기
  1. 데이터는 행렬로 저장
  2. 모델 학습·최적화도 행렬 계산
  3. PCA(차원 줄이기)와 신경망의 바탕
학교 수학으로 보면
중학교 "좌표평면", 고등 "행렬"(일부 교육과정) 단원.
AI에서는
GPU가 AI에 쓰이는 이유가 "행렬 계산을 한꺼번에 아주 빨리" 하기 때문이에요.
02-02

스칼라 Scalar

숫자 하나. a, b, c 같은 소문자로 씁니다. 예: a = 5.

말로 먼저 스칼라는 크기만 있는 숫자 하나예요. 온도 25도, 가격 3000원, 학습률 0.01처럼요.
숫자로 한 번 해 보기
  1. a = 5
  2. 학습률 α = 0.1
  3. 스칼라 × 벡터: 3 × [1, 2] = [3, 6] (3장)
학교 수학으로 보면
초·중학교에서 다룬 "수" 그 자체.
AI에서는
학습률, 손실 값, 정확도처럼 하나의 숫자로 나오는 것들이 스칼라입니다.
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
a = 5에이는 오숫자 하나
02-03

벡터 Vector

숫자를 한 줄로 늘어놓은 묶음. 굵은 글씨 v나 화살표 v⃗로 씁니다.

말로 먼저 벡터는 순서가 있는 숫자 목록이에요. v = [1 2 3]은 숫자 3개짜리 "1 × 3 벡터"(한 행에 세 개)입니다. 그림으로는 원점에서 (1, 2, 3)까지 가는 화살표예요.
숫자로 한 번 해 보기
  1. v = [1 2 3] → 숫자 3개, 1 × 3
  2. 학생 한 명 = [키 170, 몸무게 60, 나이 16]
  3. 순서를 바꾸면 다른 벡터: [3 2 1] ≠ [1 2 3]
학교 수학으로 보면
좌표평면의 점 (x, y)와 같은 생각, 고등 기하의 벡터.
AI에서는
데이터 한 건(사람 한 명, 사진 한 장)이 벡터 하나입니다. 단어도 벡터로 바꿔(임베딩) 계산해요.
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
v = [1 2 3]벡터 v1 × 3 벡터
02-04

행렬 Matrix

숫자를 행(가로줄)과 열(세로줄)로 배열한 표. 대문자 A, B로 씁니다.

말로 먼저 행렬은 벡터를 여러 줄 쌓은 것이에요. A = [[1 2 3], [4 5 6]]은 가로줄(행) 2개, 세로줄(열) 3개라서 "2 × 3 행렬"입니다.
숫자로 한 번 해 보기
  1. A = [[1, 2, 3], [4, 5, 6]]
  2. 행 2개 × 열 3개 → 2 × 3, 숫자 6개
  3. 첫째 행 [1 2 3], 둘째 열 [2 5]
학교 수학으로 보면
표와 순서쌍의 확장. 고등 "행렬" 단원.
AI에서는
엑셀 표, 흑백 사진(가로 × 세로 밝기), 신경망 한 층의 가중치가 모두 행렬입니다.
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
A = [[1 2 3], [4 5 6]]에이2 × 3 행렬
02-05

행렬의 종류 Types of Matrices

행 행렬·열 행렬·정사각·대각·단위·영행렬 — 모양과 채워진 수로 붙인 이름.

말로 먼저 ① 행 행렬 [1 2 3] — 한 줄. ② 열 행렬 — 한 기둥. ③ 정사각 행렬 — 행과 열 수가 같음. ④ 대각 행렬 [[5 0], [0 8]] — 대각선 밖은 0. ⑤ 단위행렬 I — 대각선이 모두 1, 나머지 0. ⑥ 영행렬 O — 모두 0.
숫자로 한 번 해 보기
  1. [[1 2], [3 4]] → 2 × 2 정사각
  2. [[1 0], [0 1]] → 단위행렬 I (곱해도 그대로, 4장)
  3. [[0 0], [0 0]] → 영행렬 O (더해도 그대로)
학교 수학으로 보면
고등 "행렬" 단원의 단위행렬·영행렬.
AI에서는
단위행렬은 "아무것도 안 하는 변환", 대각 행렬은 특성마다 크기만 바꾸는 변환(예: 표준화 배율)이에요.
02-06

행렬의 크기 Matrix Dimensions

행이 m개, 열이 n개면 m × n 행렬. 행을 먼저, 열을 나중에 읽습니다.

말로 먼저 크기는 "가로줄 몇 개 × 세로줄 몇 개"예요. 순서가 중요해서 2 × 3과 3 × 2는 다른 모양입니다. 행렬곱(4장)은 이 크기가 맞아야만 됩니다.
숫자로 한 번 해 보기
  1. [[1 2 3], [4 5 6]] → 행 2, 열 3 → 2 × 3
  2. [1 2 3]ᵀ(세로로 세움) → 3 × 1
  3. 사진 28 × 28 → 숫자 784개
학교 수학으로 보면
순서쌍 (m, n)을 읽는 순서와 같아요.
AI에서는
코드 오류 "shapes (2,3) and (2,3) not aligned"는 크기가 맞지 않는다는 뜻이에요. AI 코드에서 가장 흔한 오류 중 하나.

헷갈리기 쉬운 점 "m × n"은 곱셈이 아니라 크기 표기입니다. 숫자 개수는 m과 n을 곱한 값이 맞지만, 읽을 때는 "엠 바이 엔".

식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
m × n엠 바이 엔행 m개, 열 n개
02-07

자주 쓰는 기호 Common Notations

A 행렬, Aᵢⱼ i행 j열의 수, Aᵀ 전치, A⁻¹ 역행렬, I 단위, O 영행렬, ℝ^(m×n) m × n 행렬 전체.

말로 먼저 기호는 긴 말을 줄인 약속이에요. Aᵢⱼ의 아래 첨자는 "몇째 행, 몇째 열"을 가리키는 주소입니다. Aᵀ(전치)는 행과 열을 바꾼 것, A⁻¹(역행렬)은 곱하면 I가 되는 짝(4장)이에요.
숫자로 한 번 해 보기
  1. A = [[1 2 3], [4 5 6]]에서 A₁₂ = 2, A₂₃ = 6
  2. Aᵀ = [[1 4], [2 5], [3 6]] (3 × 2)
  3. A ∈ ℝ^(2×3): "A는 2 × 3 실수 행렬"
학교 수학으로 보면
수열의 aₙ처럼 아래 첨자로 자리를 표시.
AI에서는
논문과 코드 설명서는 이 기호로 쓰여 있어요. X ∈ ℝ^(n×d)는 "표본 n개, 특성 d개짜리 데이터"라는 뜻.
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
Aᵢⱼ에이 아이 제이i행 j열의 수
Aᵀ에이 전치행↔열 바꾸기
A⁻¹에이 역역행렬
I, O단위·영행렬1의 대각선 / 모두 0
ℝ^(m×n)알 엠 바이 엔m × n 실수 행렬의 모임
02-08

데이터를 행렬로 Data Representation

ML에서 데이터셋은 행렬 X. 행 하나 = 표본(데이터 한 건), 열 하나 = 특성.

말로 먼저 원자료의 예는 학생 3명의 키·몸무게·나이(축소한 값)예요. 3명이 행, 세 가지 특성이 열이라 3 × 3 행렬 X가 됩니다. 새 학생이 오면 행이 하나 늘고, 새 특성(예: 시력)을 재면 열이 하나 늘어요.
숫자로 한 번 해 보기
  1. X = [[1.2, 3.4, 0.5], [0.7, 2.1, 1.8], [1.5, 3.0, 2.2]]
  2. 둘째 학생 = 둘째 행 [0.7, 2.1, 1.8]
  3. "나이" 열 = 셋째 열 [0.5, 1.8, 2.2]
학교 수학으로 보면
통계의 자료표, 중학교 "도수분포표"의 확장.
AI에서는
pandas의 표(DataFrame)를 .values로 바꾸면 바로 이 행렬이 됩니다. 모델의 fit(X, y)에 들어가는 X가 바로 이것.

헷갈리기 쉬운 점 원자료 표의 값(키 1.2, 몸무게 3.4 등)은 실제 단위가 아니라 축소한 예시 숫자입니다.

02-09

핵심 정리와 면접 질문 Key Takeaways & Interview Questions

스칼라 → 숫자 하나, 벡터 → 1차원 배열, 행렬 → 2차원 표. 행렬은 실제 데이터를 담는다.

말로 먼저 원자료의 면접 질문 다섯 개에 한 줄씩 답하면 이 장 복습이 끝납니다. ① 벡터와 행렬이란? ② 스칼라·벡터·행렬의 차이? ③ 단위행렬이란? ④ ML에서 데이터는 행렬로 어떻게? ⑤ ML 알고리즘에서 행렬의 쓰임?
숫자로 한 번 해 보기
  1. ② 숫자 하나 / 한 줄 / 표
  2. ③ 대각선 1·나머지 0, 곱해도 그대로
  3. ④ 행 = 표본, 열 = 특성
  4. ⑤ 가중치 저장·한꺼번에 계산·PCA
학교 수학으로 보면

왜 이 방법을 쓰나
  1. 문제: 학생 100명의 키·몸무게·나이를 하나씩 계산하면 300번 따로 다뤄야 합니다.
  2. 앞 방법의 한계: 숫자를 낱개로 다루면 "어느 학생의 어느 값"인지 헷갈리고 계산이 느립니다.
  3. 이 방법의 해법: 표를 행렬 하나로 묶고 주소(Aᵢⱼ)로 부르면, 한 번에 계산하고 자리도 정확히 찾습니다.

쉽게 말하면 반 학생 출석부를 한 장의 표로 만들어 "3번 학생의 2교시"처럼 부르는 것.

연구원이 묻고, 조교 하루가 풀어 봅니다

모아Aᵢⱼ에서 i랑 j 중에 어느 게 가로줄이에요? 맨날 헷갈려요.

말로 먼저 i가 먼저, 행(가로줄) 번호예요. j가 나중, 열(세로줄) 번호예요. "행렬"이라는 이름 순서 그대로 읽으면 됩니다.

학교 수학으로 보면 좌표 (x, y)를 읽는 약속처럼 순서를 정해 둔 것.

숫자로 한 번 해 보기
  1. A = [[1 2 3], [4 5 6]]
  2. A₂₁ → 2행 1열 → 4
  3. A₁₃ → 1행 3열 → 3
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
i아이행 번호(위에서 몇째 줄)
j제이열 번호(왼쪽에서 몇째 줄)

조교 하루실험실에서 숫자를 눌러 주소가 맞는지 확인해 보세요. 전치를 켜면 주소가 뒤바뀌는 것도 보여요.

박사의 정리

행렬은 "모양이 있는 숫자 묶음"입니다. AI 코드에서 맨 먼저 확인할 것은 값이 아니라 모양이에요. 표본이 몇 개, 특성이 몇 개인지 말할 수 있으면 데이터의 절반을 이해한 것입니다.

이 실험의 한계 실제 데이터는 3차원 이상(컬러 사진 = 가로 × 세로 × 색 3개)인 경우가 많아요. 그런 묶음은 "텐서"라고 부르며 이 도감에서는 행렬까지만 다룹니다.
AI 판단 코너주판봇의 "이 표는 3 × 4 행렬"

박사는 늘 두 가지를 묻습니다. "가정이 맞나? 숫자가 그럴듯한가?"

  1. 가정이 맞나? 행과 열 중 무엇을 먼저 세었나요?
  2. 숫자가 그럴듯한가? 학생 4명 × 특성 3개라면 숫자는 모두 몇 개여야 하나요?
확인해 보기 (먼저 스스로 따져 본 뒤 펼치세요)

학생 4명(행) × 특성 3개(열)이면 4 × 3 행렬이 맞습니다. 주판봇은 열을 먼저 세어 3 × 4라고 했어요. 숫자 개수(12개)는 같아서 그럴듯해 보이지만, 모양이 뒤집혀 있으면 모델이 "특성이 4개인 학생 3명"으로 읽어 버립니다. 실제 코드에서는 X.shape로 꼭 확인하세요.

# %% 1. 스칼라·벡터·행렬 만들기
import numpy as np
import pandas as pd

a = 5                                   # 스칼라: 숫자 하나
v = np.array([1, 2, 3])                 # 벡터: 한 줄
A = np.array([[1, 2, 3],
              [4, 5, 6]])               # 행렬: 행 2개 x 열 3개
print("스칼라 a =", a, "/ ndim =", np.ndim(a))
print("벡터 v =", v, "/ shape =", v.shape)
print("행렬 A =\n", A, "\nshape =", A.shape, "(행, 열)")

# %% 2. 주소로 꺼내기: 수학의 A_23 = 파이썬의 A[1, 2] (0부터 센다)
print("A_23 (2행 3열) =", A[1, 2])
print("첫째 행 =", A[0], "/ 둘째 열 =", A[:, 1])

# %% 3. 행렬의 종류
kinds = {
    "행 행렬 (1x3)": np.array([[1, 2, 3]]),
    "열 행렬 (3x1)": np.array([[1], [2], [3]]),
    "정사각 행렬": np.array([[1, 2], [3, 4]]),
    "대각 행렬": np.diag([5, 8]),
    "단위행렬 I": np.eye(2, dtype=int),
    "영행렬 O": np.zeros((2, 2), dtype=int),
}
for name, M in kinds.items():
    print(f"{name}: shape={M.shape}\n{M}")

# %% 4. 전치: 행과 열 바꾸기
print("A.T =\n", A.T, "\nshape:", A.shape, "->", A.T.shape)

# %% 5. 데이터를 행렬로: 행 = 표본, 열 = 특성
df = pd.DataFrame({"Height": [1.2, 0.7, 1.5], "Weight": [3.4, 2.1, 3.0], "Age": [0.5, 1.8, 2.2]},
                  index=["student1", "student2", "student3"])
print(df)
X = df.values
print("X.shape =", X.shape, "-> 표본", X.shape[0], "개, 특성", X.shape[1], "개")
print("둘째 학생 =", X[1], "/ Age 열 =", X[:, 2])

정리 — 모양을 먼저 읽는다

질문답 한 줄
스칼라·벡터·행렬의 차이는?숫자 하나 / 숫자 한 줄 / 행과 열로 된 표.
m × n은?행 m개, 열 n개. 2 × 3과 3 × 2는 다른 모양.
Aᵢⱼ는?i행 j열에 있는 수. 파이썬에서는 A[i−1, j−1].
데이터는 행렬로 어떻게?행 = 표본, 열 = 특성. 학생 3명 × 특성 3개 = 3 × 3.
단위행렬은?대각선 1, 나머지 0. 곱해도 그대로인 행렬.

용어 대응 카드

선형대수란 = 벡터·행렬과 "선형 변환"을 다루는 수학. 데이터를 숫자 표로 다루는 도구.
스칼라 = 숫자 하나. a, b, c 같은 소문자로 씁니다. 예: a = 5.
벡터 = 숫자를 한 줄로 늘어놓은 묶음. 굵은 글씨 v나 화살표 v⃗로 씁니다.
행렬 = 숫자를 행(가로줄)과 열(세로줄)로 배열한 표. 대문자 A, B로 씁니다.
행렬의 종류 = 행 행렬·열 행렬·정사각·대각·단위·영행렬 — 모양과 채워진 수로 붙인 이름.
행렬의 크기 = 행이 m개, 열이 n개면 m × n 행렬. 행을 먼저, 열을 나중에 읽습니다.
자주 쓰는 기호 = A 행렬, Aᵢⱼ i행 j열의 수, Aᵀ 전치, A⁻¹ 역행렬, I 단위, O 영행렬, ℝ^(m×n) m × n 행렬 전체.
데이터를 행렬로 = ML에서 데이터셋은 행렬 X. 행 하나 = 표본(데이터 한 건), 열 하나 = 특성.
핵심 정리와 면접 질문 = 스칼라 → 숫자 하나, 벡터 → 1차원 배열, 행렬 → 2차원 표. 행렬은 실제 데이터를 담는다.

원자료와 다르게 쓴 곳

  • 원자료 "Rows (m)" 그림의 행·열 화살표는 그대로 두고, "행을 먼저 읽는다"는 읽는 순서를 강조했습니다.
