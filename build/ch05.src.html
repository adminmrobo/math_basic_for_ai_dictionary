05장 연립일차방정식 — Ax = b와 선형 회귀

점 세 개를 가장 잘 지나는 직선은 어떻게 "한 번에" 계산될까?

중학교에서 푼 연립방정식을 행렬로 옮기면 Ax = b 한 줄이 됩니다. 그러면 4장의 역행렬로 x = A⁻¹b를 바로 구할 수 있고, 행렬식으로 해가 몇 개인지도 미리 알 수 있어요. 이 장의 끝에서 이 방법이 선형 회귀의 공식 β = (XᵀX)⁻¹Xᵀy가 되는 것을 확인합니다.

글 · 안상선 ((주)M-Robo 대표) · 저자 소개 · 2026-11-26 · v1.0

처음이라면 「행렬로 쓰기」와 「해의 종류」를 읽고, 실험실에서 평행한 두 직선 버튼을 눌러 보세요. 직선이 만나지 않는 모습이 det = 0의 뜻이에요.

05-01

연립일차방정식이란 What is a System of Linear Equations

미지수가 여러 개인 일차방정식들의 묶음. 모두 동시에 참이 되는 값을 찾는다.

말로 먼저 2x + 3y = 7과 x − y = 1은 각각 직선 하나예요. 두 식을 동시에 만족하는 (x, y)는 두 직선이 만나는 점입니다. "일차"는 x², xy 같은 항 없이 x, y가 한 번씩만 곱해진다는 뜻이에요.
숫자로 한 번 해 보기
  1. 식 ①: 2x + 3y = 7
  2. 식 ②: x − y = 1 → x = y + 1
  3. ①에 넣으면 2(y+1) + 3y = 7 → 5y = 5 → y = 1, x = 2

05-02

행렬로 쓰기 Matrix Representation

Ax = b. A는 계수 행렬, x는 미지수 벡터, b는 상수 벡터.

말로 먼저 2x + 3y = 7, x − y = 1의 계수를 그대로 표에 옮기면 A = [[2 3], [1 −1]], 미지수 x = [x, y]ᵀ, 오른쪽 값 b = [7, 1]ᵀ. 4장의 행렬곱으로 A × x를 계산하면 원래 두 식의 왼쪽이 그대로 나와요.
숫자로 한 번 해 보기
  1. A = [[2, 3], [1, −1]] (2 × 2)
  2. x = [x, y]ᵀ (2 × 1), b = [7, 1]ᵀ (2 × 1)
  3. A × [2, 1]ᵀ = [2·2 + 3·1, 2 − 1] = [7, 1] = b ✔
학교 수학으로 보면
연립방정식의 계수 정리 + 행렬의 곱.
AI에서는
데이터 n개, 가중치 d개면 A는 n × d 행렬. 미지수가 수천 개여도 식은 Ax = b 한 줄.

역행렬로 풀기 Solving Using Matrix Inverse

A가 가역(det A ≠ 0)이면 x = A⁻¹b.

말로 먼저 숫자 방정식 3x = 6을 양변에 1/3을 곱해 풀듯, Ax = b의 양변 앞에 A⁻¹을 곱하면 x = A⁻¹b예요. 원자료 예: det A = 2(−1) − 3(1) = −5, A⁻¹ = (1/−5)[[−1 −3], [−1 2]].
숫자로 한 번 해 보기
  1. A⁻¹b = (1/−5) × [[−1, −3], [−1, 2]] × [7, 1]ᵀ
  2. = (1/−5) × [−7 − 3, −7 + 2] = (1/−5) × [−10, −5]
  3. = [2, 1] → x = 2, y = 1

05-04

크라메르 공식 Cramer's Rule

x = det(Aₓ)/det(A), y = det(A_y)/det(A). A의 열 하나를 b로 바꿔 끼운다.

말로 먼저 Aₓ는 A의 첫째 열(x의 계수)을 b로 바꾼 행렬, A_y는 둘째 열을 b로 바꾼 행렬이에요. 각 행렬식을 det A로 나누면 답이 나옵니다.
숫자로 한 번 해 보기
  1. det A = 2(−1) − 3(1) = −5
  2. Aₓ = [[7, 3], [1, −1]] → det = 7(−1) − 3(1) = −10 → x = −10/−5 = 2
  3. A_y = [[2, 7], [1, 1]] → det = 2(1) − 7(1) = −5 → y = −5/−5 = 1

행렬식과 가감법의 정리.

05-05

해의 종류 Types of Solutions

det A ≠ 0 → 해가 하나. det A = 0 → 해가 무수히 많거나(겹침) 없음(평행).

말로 먼저 두 직선은 ① 한 점에서 만나거나, ② 완전히 겹치거나, ③ 평행해서 안 만납니다. det A = 0은 두 직선의 기울기가 같다는 뜻이라 ②나 ③이에요. 오른쪽 값 b까지 비례하면 겹침, 아니면 평행.
숫자로 한 번 해 보기
  1. x + y = 2, 2x + 2y = 4 → 둘째 식 = 첫째 × 2 → 겹침, 해 무수히 많음
  2. x + y = 2, x + y = 3 → 같은 왼쪽, 다른 오른쪽 → 평행, 해 없음
  3. 두 경우 모두 det = 1×1 − 1×1 = 0 (2x+2y 경우는 1×2 − 1×2 = 0)
학교 수학으로 보면
중2 연립방정식의 해가 없는 경우·무수히 많은 경우.

  3. 릿지: (XᵀX + λI)β = Xᵀy — 흔들림을 막는 λ를 더함

예: 선형 회귀 Example: Linear Regression

점 (1, 2), (2, 3), (3, 5)에 y = β₀ + β₁x를 맞추면 β₀ ≈ 0.333, β₁ = 1.5.

말로 먼저 설계 행렬 X의 첫째 열은 모두 1(절편 β₀ 자리), 둘째 열은 x예요. XᵀX와 Xᵀy를 계산해 2 × 2 방정식을 풀면 됩니다.
숫자로 한 번 해 보기
  1. XᵀX = [[3, 6], [6, 14]], Xᵀy = [10, 23]
  2. det = 3×14 − 6×6 = 6
  3. β₀ = (14×10 − 6×23)/6 = 2/6 ≈ 0.333, β₁ = (−6×10 + 3×23)/6 = 9/6 = 1.5
  4. 직선 y ≈ 0.333 + 1.5x → x = 4이면 약 6.33
학교 수학으로 보면
일차함수 y = ax + b + 연립방정식.

실험두 직선 실험실 — 해가 하나, 무수히, 없음

왜 이 방법을 쓰나
  1. 문제: 미지수가 2개면 손으로 풀지만, 데이터 1000개·가중치 50개면 대입법으로는 끝이 안 납니다.
  2. 앞 방법의 한계: 대입법·가감법은 미지수마다 손이 많이 가고, 해가 있는지 미리 알 수 없습니다.
  3. 이 방법의 해법: 식을 Ax = b로 묶으면 행렬식으로 해의 존재를 먼저 판정하고, 역행렬(또는 컴퓨터의 solve)로 한 번에 풉니다.

쉽게 말하면 문제집을 한 문제씩 푸는 대신 공식에 표를 통째로 넣는 것.

연구원이 묻고, 조교 하루가 풀어 봅니다

X2det A = 0이면 왜 해가 하나로 안 정해져요?

말로 먼저 행렬식 ad − bc = 0은 두 직선의 기울기가 같다는 뜻이에요. 기울기가 같은 두 직선은 겹치거나 평행할 뿐, 한 점에서 만날 수 없어요.

학교 수학으로 보면 중2 일차함수의 기울기, 평행한 직선.

숫자로 한 번 해 보기
  1. x + y = 2와 x + y = 3: 둘 다 기울기 −1
  2. ad − bc = 1×1 − 1×1 = 0
  3. 그래프: 평행선 → 해 없음
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
ad − bc행렬식0이면 기울기가 같음
a/b = c/d기울기 비교ad = bc와 같은 말

조교 하루실험실에서 a₂, b₂를 a₁, b₁과 같은 비율로 맞추면 det가 0이 되는 순간을 볼 수 있어요.

박사의 정리

연립방정식의 해는 "직선들이 만나는 곳"이고, 행렬식은 "만날 수 있는가"를 미리 알려 주는 신호입니다. 데이터에 맞는 직선을 찾는 회귀도 결국 이 질문이에요. 다만 점이 많으면 정확히 만나는 곳이 없어서, 가장 가까운 곳(최소제곱)을 찾습니다.

이 실험의 한계 실험실은 미지수 2개(직선 2개)만 보여 줍니다. 미지수가 3개면 평면 3장이 만나는 점이고, 그 이상은 그림 대신 계산으로만 볼 수 있어요.
AI 판단 코너주판봇의 "점 3개면 직선이 딱 하나로 지나간다"

박사는 늘 두 가지를 묻습니다. "가정이 맞나? 숫자가 그럴듯한가?"

  1. 가정이 맞나? 점 (1, 2), (2, 3), (3, 5)가 정말 한 직선 위에 있나요? 기울기를 두 번 재 보세요.
  2. 숫자가 그럴듯한가? 주판봇의 직선 y = x + 1에 x = 3을 넣으면 5가 나오나요?
확인해 보기 (먼저 스스로 따져 본 뒤 펼치세요)

(1,2)→(2,3)의 기울기는 1인데 (2,3)→(3,5)의 기울기는 2라서 세 점은 한 직선 위에 없습니다. 주판봇의 y = x + 1은 앞 두 점만 지나고 (3, 5)에서는 4를 내 1만큼 빗나가요. 세 점 모두에 가장 가까운 직선은 최소제곱 해 y ≈ 0.333 + 1.5x이고, 이 직선도 어느 점은 조금씩 빗나갑니다(정답 − 예측 = 0.17, −0.33, 0.17).

주제: Ax = b, 역행렬 풀이, 크라메르 공식, 해의 종류, 정규방정식
요구 사항:
1. 2x + 3y = 7, x - y = 1을 numpy 행렬 A, b로 만들고 (a) np.linalg.inv(A) @ b (b) np.linalg.solve(A, b) (c) 크라메르 공식 세 가지로 풀어 결과를 비교해 줘.
2. 해가 무수히 많은 예(x+y=2, 2x+2y=4)와 해가 없는 예(x+y=2, x+y=3)의 행렬식을 계산하고, 두 경우를 자동으로 구분하는 함수를 만들어 줘.
3. 세 경우의 두 직선을 matplotlib으로 1×3 그림에 그려 줘(영어 제목).

5. 모든 줄에 한국어 주석.

코드 펼치기 (몰라도 됩니다 · 46줄)
# %% 1. Ax = b를 세 가지로 풀기
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression

A = np.array([[2, 3], [1, -1]], dtype=float); b = np.array([7, 1], dtype=float)
print("(a) A^-1 b      =", np.linalg.inv(A) @ b)
print("(b) solve(A, b) =", np.linalg.solve(A, b))
detA = np.linalg.det(A)
Ax = A.copy(); Ax[:, 0] = b          # x 열을 b로
Ay = A.copy(); Ay[:, 1] = b          # y 열을 b로
print(f"(c) 크라메르: det A = {detA:.0f}, x = {np.linalg.det(Ax):.0f}/{detA:.0f} = {np.linalg.det(Ax)/detA:.0f}, y = {np.linalg.det(Ay)/detA:.0f}")

# %% 2. 해의 종류 판정
def kind(a1, b1, c1, a2, b2, c2):
    D = a1 * b2 - b1 * a2
    if abs(D) > 1e-12:
        return f"해가 하나 (det = {D})"
    same = abs(a1 * c2 - a2 * c1) < 1e-12 and abs(b1 * c2 - b2 * c1) < 1e-12
    return "해가 무수히 많음 (det = 0, 겹침)" if same else "해가 없음 (det = 0, 평행)"

cases = {"unique": (2, 3, 7, 1, -1, 1), "infinite": (1, 1, 2, 2, 2, 4), "none": (1, 1, 2, 1, 1, 3)}
for name, c in cases.items():
    print(f"{name:9s} {c} -> {kind(*c)}")

# %% 3. 세 경우를 그림으로
xs = np.linspace(-1, 4, 50)
fig, axes = plt.subplots(1, 3, figsize=(12, 3.6))
for ax, (name, (a1, b1, c1, a2, b2, c2)) in zip(axes, cases.items()):
    ax.plot(xs, (c1 - a1 * xs) / b1, "r", lw=2, label="eq 1")
    ax.plot(xs, (c2 - a2 * xs) / b2, "b--", lw=2, label="eq 2")
    ax.set_title(name); ax.set_ylim(-3, 5); ax.grid(alpha=0.3); ax.legend()
plt.tight_layout(); plt.show()

# %% 4. 정규방정식으로 선형 회귀
x = np.array([1, 2, 3], dtype=float); y = np.array([2, 3, 5], dtype=float)
X = np.column_stack([np.ones_like(x), x])        # 설계 행렬: [1, x]
XtX, Xty = X.T @ X, X.T @ y
print("X^T X =\n", XtX, "\nX^T y =", Xty)
beta = np.linalg.inv(XtX) @ Xty
print(f"정규방정식: beta0 = {beta[0]:.3f}, beta1 = {beta[1]:.3f}")
lr = LinearRegression().fit(x.reshape(-1, 1), y)
print(f"sklearn   : beta0 = {lr.intercept_:.3f}, beta1 = {lr.coef_[0]:.3f}")
print("각 점의 오차(정답 - 예측):", (y - X @ beta).round(3))
plt.scatter(x, y, s=60, label="data"); plt.plot(xs, beta[0] + beta[1] * xs, "g", label="y = 0.333 + 1.5x")
plt.legend(); plt.grid(alpha=0.3); plt.title("Least squares line"); plt.show()

정리 — 만나는 점을 한 번에 찾는다

질문답 한 줄
연립방정식을 행렬로 쓰면?Ax = b. A 계수 행렬, x 미지수, b 상수.
역행렬로 풀면?x = A⁻¹b. 원자료 예의 답은 x = 2, y = 1.
크라메르 공식은?x = det(Aₓ)/det(A). 열 하나를 b로 바꿔 끼운 행렬식.
해의 종류는?det ≠ 0 하나, det = 0이면 겹침(무수히) 또는 평행(없음).
회귀와의 관계는?정규방정식 β = (XᵀX)⁻¹Xᵀy가 최소제곱 해.

용어 대응 카드

연립일차방정식이란 = 미지수가 여러 개인 일차방정식들의 묶음. 모두 동시에 참이 되는 값을 찾는다.
행렬로 쓰기 = Ax = b. A는 계수 행렬, x는 미지수 벡터, b는 상수 벡터.
역행렬로 풀기 = A가 가역(det A ≠ 0)이면 x = A⁻¹b.
크라메르 공식 = x = det(Aₓ)/det(A), y = det(A_y)/det(A). A의 열 하나를 b로 바꿔 끼운다.
해의 종류 = det A ≠ 0 → 해가 하나. det A = 0 → 해가 무수히 많거나(겹침) 없음(평행).
ML에서의 쓰임 = 선형 회귀(정규방정식), 최소제곱 최적화, 가중치 구하기, 릿지 회귀.
예: 선형 회귀 = 점 (1, 2), (2, 3), (3, 5)에 y = β₀ + β₁x를 맞추면 β₀ ≈ 0.333, β₁ = 1.5.

원자료와 다르게 쓴 곳

  • 원자료 5번 표의 "Unique Solution" 예시(x = 1, y = 2)는 조건 없이 값만 적혀 있어, 이 도감에서는 실제 식 2x + 3y = 7, x − y = 1의 해(x = 2, y = 1)로 설명했습니다.
  • 원자료 7번 상자의 회귀 예에 대해 β₀ ≈ 0.333, β₁ = 1.5를 직접 계산해 넣었습니다.
