12-01

편미분이란 What are Partial Derivatives

다른 변수는 상수로 고정하고 변수 하나에 대해서만 미분한 변화율. ∂f/∂x 또는 fₓ.

말로 먼저 f(x, y)에서 "x 방향으로만 한 걸음" 갈 때의 기울기가 ∂f/∂x, "y 방향으로만" 갈 때가 ∂f/∂y예요. 계산 방법은 11장과 같고, 다만 다른 변수를 숫자처럼(상수로) 취급합니다. 여러 변수 함수의 ML과 최적화에 쓰여요.
숫자로 한 번 해 보기
  1. f(x, y) = x² + y²
  2. ∂f/∂x: y²는 상수 → 2x
  3. ∂f/∂y: x²는 상수 → 2y
학교 수학으로 보면
고등 미분의 확장(대학 미적분학).
AI에서는
손실 L(w₁, w₂, …)의 ∂L/∂w₁ = "w₁만 조금 바꾸면 손실이 얼마나 변하나".
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
fₓ = ∂f/∂x에프 엑스y 고정, x로 미분
f_y = ∂f/∂y에프 와이x 고정, y로 미분
12-02

편미분 계산 예 Example: Finding Partial Derivatives

f(x, y) = x²y + 3xy + y² → ∂f/∂x = 2xy + 3y, ∂f/∂y = x² + 3x + 2y.

말로 먼저 x로 미분할 때 y는 숫자처럼: x²y → 2x·y, 3xy → 3y, y² → 0. y로 미분할 때 x는 숫자처럼: x²y → x², 3xy → 3x, y² → 2y.
숫자로 한 번 해 보기
  1. ∂f/∂x = 2xy + 3y + 0 = 2xy + 3y
  2. ∂f/∂y = x² + 3x + 2y
  3. 점 (1, 2): ∂f/∂x = 4 + 6 = 10, ∂f/∂y = 1 + 3 + 4 = 8
학교 수학으로 보면
다항함수의 미분 + "상수 취급".
AI에서는
프레임워크의 자동 미분이 이 계산을 수백만 변수에 대해 합니다.
12-03

2계 편미분과 혼합 편미분 Higher Order Partial Derivatives

편미분을 한 번 더. fₓₓ, f_yy, 그리고 순서를 섞은 fₓᵧ, f_yₓ.

말로 먼저 f(x, y) = x²y + y³이면 fₓ = 2xy, f_y = x² + 3y². 한 번 더 하면 fₓₓ = 2y, f_yy = 6y, fₓᵧ = 2x, f_yₓ = 2x. 2계 편미분이 연속이면 순서를 바꿔도 같아요(fₓᵧ = f_yₓ). 휘어진 정도(곡률)를 알려 주어 2차 최적화 방법에 씁니다.
숫자로 한 번 해 보기
  1. fₓ = 2xy → fₓₓ = 2y, fₓᵧ = 2x
  2. f_y = x² + 3y² → f_yy = 6y, f_yₓ = 2x
  3. fₓᵧ = f_yₓ = 2x ✔
학교 수학으로 보면
대학 미적분학(슈바르츠·클레로 정리).
AI에서는
2계 편미분을 표로 모은 것이 헤세 행렬(15장). 뉴턴 방법 같은 2차 최적화가 사용해요.

헷갈리기 쉬운 점 원자료의 조건 "if function is continuous"는 정확히는 "2계 편미분들이 연속이면"입니다.

12-04

그래디언트 Gradient

모든 편미분을 모은 벡터 ∇f = (∂f/∂x, ∂f/∂y). 함수가 가장 가파르게 증가하는 방향을 가리킨다.

말로 먼저 편미분 두 개를 화살표 하나로 묶으면, 그 화살표는 "가장 빨리 오르는 방향"을, 길이는 "그 방향의 가파름"을 알려 줘요. 그래디언트는 언제나 등고선에 직각입니다. 경사하강 같은 최적화 알고리즘에 널리 쓰여요.
숫자로 한 번 해 보기
  1. f = x²y + 3xy + y² → ∇f = (2xy + 3y, x² + 3x + 2y)
  2. 점 (1, 2)에서 ∇f = (10, 8)
  3. 가파름 ‖∇f‖ = √(100 + 64) ≈ 12.8
학교 수학으로 보면
고등 벡터(3장) + 편미분.
AI에서는
loss.backward()가 채우는 .grad가 바로 이 벡터. 가중치 개수만큼의 숫자가 들어 있어요.
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
∇f(x, y) = (∂f/∂x, ∂f/∂y)나블라 에프가장 가파른 오르막
12-05

변수가 n개일 때 Gradient for Multiple Variables

∇f(x₁, …, xₙ) = (∂f/∂x₁, …, ∂f/∂xₙ). 편미분 n개짜리 벡터.

말로 먼저 변수가 셋이든 백만이든 방법은 같아요. 하나씩 편미분해 줄 세우면 됩니다. f(x, y, z) = x² + y² + z²이면 ∇f = (2x, 2y, 2z).
숫자로 한 번 해 보기
  1. f = x² + y² + z² → ∇f = (2x, 2y, 2z)
  2. 점 (1, −1, 2) → ∇f = (2, −2, 4)
  3. 원점 (0, 0, 0) → ∇f = (0, 0, 0): 바닥(최솟값)
학교 수학으로 보면
3장 벡터 + 편미분.
AI에서는
GPT 같은 모델은 가중치가 수십억 개라 그래디언트도 수십억 개 숫자짜리 벡터예요.
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
∇f = (∂f/∂x₁, …, ∂f/∂xₙ)n변수 그래디언트편미분 n개
12-06

접평면과 선형 근사 Tangent Plane and Linear Approximation

한 점 (a, b) 근처에서 곡면을 평평한 판으로 근사. z = f(a, b) + fₓ(a, b)(x − a) + f_y(a, b)(y − b).

말로 먼저 11장의 접선이 "한 점에서 곡선에 붙인 직선"이라면, 접평면은 "한 점에서 곡면에 붙인 평평한 판"이에요. 점 근처에서는 곡면 대신 이 판으로 계산해도 거의 맞아요(선형 근사).
숫자로 한 번 해 보기
  1. f = x² + y², 점 (1, 2): f = 5, fₓ = 2, f_y = 4
  2. z = 5 + 2(x − 1) + 4(y − 2) = 2x + 4y − 5
  3. (1.1, 2.1)에서 판 5.6, 실제 f = 1.21 + 4.41 = 5.62 → 거의 같음
학교 수학으로 보면
접선의 방정식의 확장.
AI에서는
경사하강의 한 걸음은 "지금 점의 접평면을 믿고 내리막으로" 가는 것. 그래서 걸음이 너무 크면(학습률이 크면) 판과 곡면이 어긋나 빗나갑니다.
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
z = f(a,b) + fₓ(x−a) + f_y(y−b)접평면점 근처의 평평한 근사
12-07

경사하강의 직관 Gradient Descent Intuition

그래디언트는 최대 증가 방향 → 반대(−∇f)로 가면 가장 빨리 줄어든다. θ_new = θ_old − α∇f(θ).

말로 먼저 안개 낀 산에서 발밑 경사만 느낄 수 있다면, 가장 가파른 내리막(−그래디언트)으로 한 걸음, 다시 경사를 재고 한 걸음… 이것을 되풀이하면 골짜기 바닥(최솟값)에 닿아요. α(학습률)는 걸음 크기예요.
숫자로 한 번 해 보기
  1. f = x² + y², 출발 (1, 2), α = 0.1
  2. ∇f = (2, 4) → (1, 2) − 0.1 × (2, 4) = (0.8, 1.6)
  3. 손실 5 → 3.2로 줄어듦
학교 수학으로 보면
벡터의 뺄셈 + 스칼라배(3장).
AI에서는
13장 최적화의 주인공. 거의 모든 딥러닝 학습이 이 한 줄의 변형이에요.
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
θ_new = θ_old − α∇f(θ)경사하강그래디언트 반대로 α만큼
12-08

자주 쓰는 함수의 그래디언트 Common Functions and Their Gradients

x² + y² → (2x, 2y), xy → (y, x), sin x + cos y → (cos x, −sin y), eˣʸ → (yeˣʸ, xeˣʸ), ln(x² + y²) → (2x/(x² + y²), 2y/(x² + y²)).

말로 먼저 정리: 편미분은 변수 하나에 대한 변화를 재고, 그래디언트는 모든 편미분의 벡터이며, 최적화·신경망·ML에 쓰이고, 접평면과 선형 근사를 찾게 해 주며, 경사하강은 그래디언트로 함수를 최소화합니다.
숫자로 한 번 해 보기
  1. xy의 그래디언트 (y, x): 점 (2, 3) → (3, 2)
  2. eˣʸ: x로 미분하면 연쇄 법칙으로 y·eˣʸ
  3. ln(x² + y²): 겉 1/u × 속 2x
학교 수학으로 보면
11장의 미분 법칙(연쇄 법칙)을 변수마다.
AI에서는
이 표의 함수들은 시험 문제용이고, 실제 손실(MSE·교차 엔트로피)의 그래디언트도 같은 법칙으로 구합니다.

실험등고선 지도 실험실 — 어디를 눌러도 화살표가 생긴다

왜 이 방법을 쓰나
  1. 문제: 가중치 두 개(w₁, w₂)로 된 손실 지형에서 어느 쪽으로 움직여야 손실이 가장 빨리 줄지 알고 싶습니다.
  2. 앞 방법의 한계: 11장의 미분은 변수 하나의 기울기만 알려 줘서, 두 방향을 동시에 고려할 수 없습니다.
  3. 이 방법의 해법: 변수마다 편미분을 구해 그래디언트 벡터로 묶으면, 가장 가파른 오르막 방향이 화살표 하나로 나옵니다. 그 반대로 갑니다.

쉽게 말하면 등산 앱이 동쪽 경사와 북쪽 경사를 합쳐 "이 방향이 가장 가파름"이라고 화살표로 보여 주는 것.

연구원이 묻고, 조교 하루가 풀어 봅니다

시아∂ 기호는 그냥 d랑 뭐가 달라요? 읽는 법부터 모르겠어요.

말로 먼저 ∂는 "라운드 디" 또는 "파셜"이라고 읽어요. "변수가 여럿인데 그중 하나로만 미분한다"는 표시예요. 계산은 d와 같고, 나머지 변수를 숫자처럼 둔다는 약속만 다릅니다.

학교 수학으로 보면 11장의 dy/dx와 같은 뜻 + "다른 변수는 고정".

숫자로 한 번 해 보기
  1. f = x²y, y = 3으로 고정하면 f = 3x²
  2. d(3x²)/dx = 6x
  3. ∂(x²y)/∂x = 2xy → y = 3이면 6x ✔
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
∂f/∂x파셜 에프 파셜 엑스y 고정, x로 미분
∇나블라모든 편미분을 모으라는 명령
−∇f마이너스 그래디언트가장 빠른 내리막

조교 하루실험실에서 「원자료 x²y + 3xy + y²」를 고르고 점 (1, 2)를 눌러 보세요. ∂f/∂x = 10, ∂f/∂y = 8이 나와요.

박사의 정리

그래디언트는 "지금 이 자리에서 가장 가파르게 오르는 방향"입니다. AI 학습은 이 화살표를 거꾸로 따라가는 일이에요. 다만 화살표는 "지금 이 자리"만 알려 주므로, 몇 걸음마다 다시 재야 합니다.

이 실험의 한계 실험실 지도는 변수 두 개(평면)까지만 그립니다. 실제 손실은 수백만 차원이라 그림 대신 숫자로만 다뤄요.
AI 판단 코너주판봇의 "f = x²y의 ∂f/∂x = 2x"

박사는 늘 두 가지를 묻습니다. "가정이 맞나? 숫자가 그럴듯한가?"

  1. 가정이 맞나? x로 편미분할 때 y는 사라지나요, 상수로 남나요?
  2. 숫자가 그럴듯한가? y = 3으로 고정한 f = 3x²를 미분하면 얼마인가요? 주판봇의 2x와 같나요?
확인해 보기 (먼저 스스로 따져 본 뒤 펼치세요)

틀렸습니다. 편미분에서 y는 "없애는" 것이 아니라 "상수로 남겨 두는" 거예요. ∂(x²y)/∂x = 2x·y = 2xy입니다. y = 3이면 3x²의 미분 6x와 맞고, 주판봇의 2x는 y = 1일 때만 우연히 맞아요. 숫자 하나를 고정해 1변수 미분과 비교하는 것이 편미분을 검산하는 가장 쉬운 방법입니다.

# %% 1. 편미분과 그래디언트 (sympy)
import numpy as np
import matplotlib.pyplot as plt
import sympy as sp

x, y = sp.symbols("x y")
f = x**2 * y + 3 * x * y + y**2
fx, fy = sp.diff(f, x), sp.diff(f, y)
print("∂f/∂x =", fx, "/ ∂f/∂y =", fy)
print("∇f(1, 2) =", (fx.subs({x: 1, y: 2}), fy.subs({x: 1, y: 2})))

# %% 2. 2계·혼합 편미분
g = x**2 * y + y**3
gxx, gyy = sp.diff(g, x, x), sp.diff(g, y, y)
gxy, gyx = sp.diff(g, x, y), sp.diff(g, y, x)
print("fxx =", gxx, "/ fyy =", gyy, "/ fxy =", gxy, "/ fyx =", gyx, "/ 같은가?", sp.simplify(gxy - gyx) == 0)

# %% 3. 수치 편미분으로 검산
def F(p):
    a, b = p
    return a**2 * b + 3 * a * b + b**2
def num_grad(fn, p, h=1e-5):
    p = np.array(p, dtype=float); grad = np.zeros_like(p)
    for i in range(len(p)):
        e = np.zeros_like(p); e[i] = h
        grad[i] = (fn(p + e) - fn(p - e)) / (2 * h)
    return grad
print("수치 그래디언트 (1, 2):", num_grad(F, [1, 2]).round(6))

# %% 4. 등고선과 그래디언트 화살표
X, Y = np.meshgrid(np.linspace(-3, 3, 200), np.linspace(-3, 3, 200))
plt.figure(figsize=(5.5, 5)); plt.contour(X, Y, X**2 + Y**2, levels=10, cmap="viridis")
P, Q = np.meshgrid(np.linspace(-2.5, 2.5, 7), np.linspace(-2.5, 2.5, 7))
plt.quiver(P, Q, 2 * P, 2 * Q, color="red")                     # ∇f = (2x, 2y)
plt.gca().set_aspect("equal"); plt.title("Gradient arrows are perpendicular to contours"); plt.show()

# %% 5. 접평면과 선형 근사
h2 = lambda a, b: a**2 + b**2
plane = lambda a, b: 2 * a + 4 * b - 5                          # (1, 2)에서의 접평면
print(f"(1.1, 2.1): 실제 {h2(1.1, 2.1):.4f} / 접평면 {plane(1.1, 2.1):.4f}")
print(f"(2.0, 3.0): 실제 {h2(2, 3):.4f} / 접평면 {plane(2, 3):.4f}  <- 멀어지면 어긋남")

# %% 6. 경사하강 다섯 걸음
p = np.array([1.0, 2.0]); alpha = 0.1
print("걸음 |     점        | f = x^2 + y^2")
for t in range(6):
    print(f"{t:>3}  | ({p[0]:.4f}, {p[1]:.4f}) | {h2(*p):.4f}")
    p = p - alpha * np.array([2 * p[0], 2 * p[1]])              # 그래디언트 반대로

용어 대응 카드

편미분이란 = 다른 변수는 상수로 고정하고 변수 하나에 대해서만 미분한 변화율. ∂f/∂x 또는 fₓ.
편미분 계산 예 = f(x, y) = x²y + 3xy + y² → ∂f/∂x = 2xy + 3y, ∂f/∂y = x² + 3x + 2y.
2계 편미분과 혼합 편미분 = 편미분을 한 번 더. fₓₓ, f_yy, 그리고 순서를 섞은 fₓᵧ, f_yₓ.
그래디언트 = 모든 편미분을 모은 벡터 ∇f = (∂f/∂x, ∂f/∂y). 함수가 가장 가파르게 증가하는 방향을 가리킨다.
변수가 n개일 때 = ∇f(x₁, …, xₙ) = (∂f/∂x₁, …, ∂f/∂xₙ). 편미분 n개짜리 벡터.
접평면과 선형 근사 = 한 점 (a, b) 근처에서 곡면을 평평한 판으로 근사. z = f(a, b) + fₓ(a, b)(x − a) + f_y(a, b)(y − b).
경사하강의 직관 = 그래디언트는 최대 증가 방향 → 반대(−∇f)로 가면 가장 빨리 줄어든다. θ_new = θ_old − α∇f(θ).
자주 쓰는 함수의 그래디언트 = x² + y² → (2x, 2y), xy → (y, x), sin x + cos y → (cos x, −sin y), eˣʸ → (yeˣʸ, xeˣʸ), ln(x² + y²) → (2x/(x² + y²), 2y/(x² + y²)).

원자료와 다르게 쓴 곳

  • 원자료 3번의 "fxy = fyx (if function is continuous)"를 "2계 편미분들이 연속이면"으로 정확히 고쳐 썼습니다.
  • 원자료 4번 3D 그림의 축 이름(x가 두 번 표기)은 이 도감 그림에서 x, y로 바로잡았습니다.
