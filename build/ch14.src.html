14장 고윳값·고유벡터와 PCA — 데이터의 주축 찾기

특성이 100개인 데이터를 그림 한 장에 그릴 수 있을까? 정보를 가장 많이 남기는 방향은 어디일까?

행렬을 곱하면 대부분의 화살표는 방향이 꺾입니다. 그런데 어떤 특별한 화살표는 방향은 그대로이고 길이만 바뀌어요. 그것이 고유벡터, 늘어난 배율이 고윳값입니다. 데이터의 공분산 행렬(10장)에서 고유벡터를 찾으면 "데이터가 가장 넓게 퍼진 방향"이 나오고, 그 방향 몇 개만 남기는 것이 PCA(주성분 분석)예요. 2~13장의 도구가 모두 모이는 응용 장입니다.

14-01

고윳값과 고유벡터란 What are Eigenvalues and Eigenvectors

정사각 행렬 A에 대해 Ax = λx이면 x는 고유벡터, λ는 고윳값. A를 곱해도 방향은 그대로, 크기만 λ배.

말로 먼저 A를 "공간을 늘이고 돌리는 기계"라고 생각하면, 대부분의 화살표는 기계를 지나며 방향이 꺾여요. 고유벡터는 꺾이지 않고 같은 직선 위에 남는 특별한 화살표(0이 아닌 벡터)이고, 고윳값 λ는 그때 길이가 몇 배가 되는지예요. λ가 음수면 반대 방향으로 뒤집힙니다.
숫자로 한 번 해 보기
  1. A = [[2, 1], [1, 2]], x = [1, 1]
  2. Ax = [2+1, 1+2] = [3, 3] = 3 × [1, 1] → λ = 3
  3. x = [1, 0] → Ax = [2, 1]: 방향이 꺾임 → 고유벡터 아님
학교 수학으로 보면
4장 행렬곱 + 3장 스칼라배(대학 선형대수).
AI에서는
PCA, 차원 축소, 스펙트럴 군집, 페이지랭크 등 많은 ML 알고리즘에 쓰입니다.
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
Ax = λx에이 엑스는 람다 엑스곱해도 방향 유지, λ배
A: n × n, x ≠ 0, λ: 스칼라조건정사각 행렬, 영벡터 제외
14-02

고윳값 찾기 How to Find Eigenvalues

특성방정식 det(A − λI) = 0을 풀어 λ를 구한다. ① A − λI ② 행렬식 ③ λ에 대해 풀기.

말로 먼저 Ax = λx를 (A − λI)x = 0으로 옮기면, 0이 아닌 x가 있으려면 A − λI의 역행렬이 없어야 해요(있으면 x = 0뿐). 역행렬이 없다 = 행렬식이 0(4·5장). 그래서 det(A − λI) = 0이 λ를 찾는 식이 됩니다.
숫자로 한 번 해 보기
  1. A = [[4, 1], [1, 3]]
  2. det = (4 − λ)(3 − λ) − 1 = λ² − 7λ + 11 = 0
  3. λ = (7 ± √5)/2 ≈ 4.618, 2.382
학교 수학으로 보면
고1 "이차방정식의 근의 공식" + 행렬식.
AI에서는
큰 행렬은 이 방정식 대신 컴퓨터의 반복 계산(np.linalg.eig)으로 구해요.
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
det(A − λI) = 0특성방정식λ를 찾는 식
(a − λ)(d − λ) − bc = 02 × 2이차방정식
14-03

고유벡터 찾기 How to Find Eigenvectors

고윳값 λ마다 (A − λI)x = 0을 풀어 x를 구한다. 0이 아닌 상수배는 모두 같은 고유벡터.

말로 먼저 λ = (7 + √5)/2를 넣으면 첫째 식 (4 − λ)x₁ + x₂ = 0에서 x₂ = (λ − 4)x₁. x₁ = 1로 두면 x = [1, λ − 4] ≈ [1, 0.618]. 방향만 의미가 있어서 [2, 1.236]이나 −[1, 0.618]도 같은 고유벡터예요. 보통 길이 1로 맞춥니다(정규화).
숫자로 한 번 해 보기
  1. λ₁ ≈ 4.618 → x ≈ [1, 0.618] → 길이 1로: [0.851, 0.526]
  2. 확인: A × [1, 0.618] = [4.618, 2.854] ≈ 4.618 × [1, 0.618] ✔
  3. λ₂ ≈ 2.382 → x ≈ [1, −1.618]
학교 수학으로 보면
연립방정식(5장)의 해가 무수히 많은 경우.
AI에서는
라이브러리는 길이 1로 정규화한 고유벡터를 돌려주며, 부호(+/−)는 라이브러리마다 다를 수 있어요.
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
(A − λI)x = 0고유벡터 식λ를 넣고 x 풀기
x = [1, λ − 4]원자료 예상수배는 모두 고유벡터
14-04

고윳값의 성질 Properties of Eigenvalues

n × n 행렬은 고윳값 n개(중복 포함). 합 = 대각합 tr A, 곱 = 행렬식 det A. 대칭 행렬은 고윳값이 실수, 고유벡터가 서로 직각.

말로 먼저 고윳값은 실수일 수도 복소수일 수도 있어요(예: 회전 행렬). 대각합·행렬식 성질은 손계산을 검산하는 데 아주 편하고, 대칭 행렬의 성질은 PCA가 잘 작동하는 이유예요(공분산 행렬은 늘 대칭).
숫자로 한 번 해 보기
  1. A = [[4, 1], [1, 3]]: tr A = 7 = 4.618 + 2.382 ✔
  2. det A = 12 − 1 = 11 = 4.618 × 2.382 ✔
  3. 대칭이라 고유벡터 [0.851, 0.526]·[−0.526, 0.851] = 0 (직각)
학교 수학으로 보면
근과 계수의 관계(고1): 두 근의 합 = 7, 곱 = 11.
AI에서는
공분산 행렬의 고윳값의 합 = 전체 분산. 그래서 "PC1이 설명하는 몫 = λ₁ / Σλ".
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
tr(A) = Σ λᵢ대각합고윳값의 합
det(A) = Π λᵢ행렬식고윳값의 곱
14-05

PCA의 공분산 행렬 Covariance Matrix in PCA

PCA는 먼저 데이터의 공분산 행렬 Σ = (1/(n−1))(X − μ)ᵀ(X − μ)를 계산한다. 대칭이며 특성들이 함께 움직이는 정도를 보여 준다.

말로 먼저 특성 2개면 Σ = [[σ₁², σ₁₂], [σ₁₂, σ₂²]]: 대각선은 각 특성의 분산(8장), 나머지는 두 특성의 공분산(10장)이에요. 평균을 뺀 데이터 행렬의 전치와 자기 자신을 곱하면(4장) 한 번에 계산됩니다.
숫자로 한 번 해 보기
  1. 특성 2개 → 2 × 2 공분산 행렬
  2. 대각: 분산 σ₁², σ₂²
  3. 대각 밖: 공분산 σ₁₂ (위아래 같음 → 대칭)
학교 수학으로 보면
8장 분산 + 10장 공분산 + 4장 행렬곱.
AI에서는
특성 단위가 다르면 먼저 표준화(평균 0, 표준편차 1)한 뒤 공분산 행렬을 구해요. 그러면 상관 행렬과 같아집니다.
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
Σ = (1/(n−1)) (X − μ)ᵀ(X − μ)공분산 행렬표본 공분산(n − 1)

고유벡터로 하는 PCA PCA using Eigenvalues & Eigenvectors

① 표준화 ② 공분산 행렬 Σ ③ Σ의 고윳값·고유벡터 ④ 고윳값 내림차순 정렬 ⑤ 상위 k개 고유벡터(주성분) 선택 ⑥ Z = X_centered · W로 투영.

말로 먼저 큰 고윳값의 고유벡터일수록 데이터가 그 방향으로 많이 퍼져 있어요(분산이 큼 = 정보가 많음). 상위 k개만 모은 행렬 W로 데이터를 옮기면(투영) 특성 n개가 k개로 줄어듭니다.
숫자로 한 번 해 보기
  1. 특성 100개 → Σ는 100 × 100
  2. 고윳값 상위 2개가 전체의 90%라면 k = 2
  3. Z = X_c · W: (표본 수 × 100) · (100 × 2) = 표본 수 × 2
학교 수학으로 보면
4장 행렬곱(크기 규칙)으로 투영.
AI에서는
sklearn의 PCA(n_components=k).fit_transform(X)이 이 여섯 단계를 합니다(내부적으로는 SVD라는 방법을 씀).
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
Z = X_centered · W투영W = 고른 고유벡터들을 열로 모은 행렬

PCA 2차원 예제 PCA Example (2D Data)

X = [[0,0],[1,1],[0,−1],[−1,0]] → Σ = [[2/3, 1/3], [1/3, 2/3]] → λ₁ = 1, v₁ = (1/√2)[1, 1], λ₂ = 1/3, v₂ = (1/√2)[1, −1].

말로 먼저 두 특성의 평균이 모두 0이라 바로 Σ = XᵀX / (4 − 1)을 계산해요. 고윳값 1과 1/3 → PC1 하나가 전체 분산의 1 ÷ (1 + 1/3) = 75%를 설명합니다. PC1 방향은 대각선 [1, 1] 쪽이에요.
숫자로 한 번 해 보기
  1. XᵀX = [[2, 1], [1, 2]] → ÷ 3 → [[2/3, 1/3], [1/3, 2/3]]
  2. det(Σ − λI) = (2/3 − λ)² − 1/9 = 0 → λ = 1, 1/3
  3. PC1 투영: Z = X · v₁ = [0, 1.414, −0.707, −0.707]
  4. 설명 비율: 1 / (4/3) = 0.75
학교 수학으로 보면
이차방정식, 행렬곱.
AI에서는
2차원 데이터를 1차원으로 줄여도 정보(분산)의 75%가 남는다는 뜻이에요.

헷갈리기 쉬운 점 원자료는 이 데이터를 "표준화한 뒤"라고 적었지만, 실제로는 평균만 0으로 맞춘(중심화한) 데이터입니다(각 특성의 분산이 2/3이라 표준편차가 1이 아님).

14-08

PCA 시각화와 정리 PCA Visualization & Key Takeaways

원래 축(특성1, 특성2) 대신 PC1(가장 넓게 퍼진 방향)과 PC2(그와 직각)를 새 축으로 쓰면, 비스듬한 점 구름이 가로로 눕는다.

말로 먼저 정리: 고윳값·고유벡터는 Ax = λx를 풀고, PCA의 주성분을 찾는 데 쓰이며, 공분산 행렬이 분산과 특성 간 관계를 담고, PCA는 상위 고유벡터를 골라 차원을 줄이며, 대칭 행렬의 고유벡터는 직각이고, 큰 고윳값 = 더 중요한 주성분이에요. 데이터 전처리·시각화·특성 선택에 널리 쓰이고, 잡음을 줄여 모델 성능을 높이며, 이미지 압축·추천·군집에도 씁니다.
숫자로 한 번 해 보기
  1. 원래 좌표 (특성1, 특성2) → 새 좌표 (PC1, PC2)
  2. PC2 방향의 퍼짐이 작으면 PC2를 버려도 손실이 적음
  3. 고차원 데이터를 2D 그림으로 보는 표준 방법
학교 수학으로 보면
좌표축 회전(좌표 첫걸음).
AI에서는
얼굴 사진 PCA(아이겐페이스), 유전자 데이터 시각화, 추천 시스템의 잠재 요인이 모두 같은 생각이에요.

실험주축 찾기 실험실 — 점 구름이 가장 넓게 퍼진 방향

왜 이 방법을 쓰나
  1. 문제: 고객 데이터 특성이 50개라 그림으로 볼 수도 없고, 비슷한 특성끼리 정보가 겹칩니다.
  2. 앞 방법의 한계: 특성을 아무거나 골라 버리면(예: 50개 중 2개만) 버린 특성의 정보를 통째로 잃습니다.
  3. 이 방법의 해법: 공분산 행렬의 고유벡터로 "정보가 가장 많이 몰린 새 축"을 만들고, 고윳값이 큰 축 몇 개만 남깁니다.

쉽게 말하면 기울어진 연필 묶음을 사진 찍을 때, 가장 길게 보이는 방향으로 카메라를 돌리는 것.

연구원이 묻고, 조교 하루가 풀어 봅니다

모아det(A − λI) = 0은 갑자기 어디서 나와요? Ax = λx만 있었잖아요.

말로 먼저 Ax = λx를 Ax − λx = 0, 즉 (A − λI)x = 0으로 옮겨요. 이 식에 0이 아닌 해 x가 있으려면 A − λI에 역행렬이 없어야 해요. 역행렬이 없다는 것이 바로 행렬식 0이에요.

학교 수학으로 보면 5장 "det = 0이면 해가 무수히 많다".

숫자로 한 번 해 보기
  1. λx = λIx로 바꿔 쓰기(I를 곱해도 그대로)
  2. (A − λI)x = 0: 해가 x = 0만 있으면 고유벡터가 없음
  3. det(A − λI) = 0 → 해가 무수히 많음 → 0 아닌 x 존재
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
A − λI에이 빼기 람다 아이대각선에서 λ를 뺀 행렬
det(…) = 0행렬식 00이 아닌 해가 있을 조건
λ람다이 조건을 만족하는 수

조교 하루5장의 "겹치는 두 직선"이 여기서 다시 나와요. 해가 무수히 많아야 고유벡터가 있어요.

박사의 정리

고유벡터는 "행렬이 방향을 바꾸지 못하는 화살표", 공분산 행렬의 고유벡터는 "데이터가 가장 넓게 퍼진 방향"입니다. PCA는 그 방향을 새 축으로 삼아, 정보가 적은 축을 버리는 일이에요. 버린 만큼 정보도 조금 잃는다는 것, 그래서 "몇 %가 남았나"를 함께 말해야 합니다.

이 실험의 한계 PCA는 직선 방향의 퍼짐만 봅니다. 데이터가 휘어진 모양(곡면)에 놓여 있으면 다른 방법(t-SNE, UMAP 등)이 필요해요.
AI 판단 코너주판봇의 "PCA로 특성 100개를 2개로 줄였어요. 정보 손실 없음!"

박사는 늘 두 가지를 묻습니다. "가정이 맞나? 숫자가 그럴듯한가?"

  1. 가정이 맞나? 버린 98개 축의 고윳값이 모두 0인가요?
  2. 숫자가 그럴듯한가? 설명된 분산 비율(상위 두 고윳값 ÷ 고윳값 전체 합)을 계산하면 몇 %인가요?
확인해 보기 (먼저 스스로 따져 본 뒤 펼치세요)

버린 축들의 고윳값이 0이 아니라면 그만큼의 분산(정보)을 잃은 것이에요. 반드시 "설명된 분산 비율"을 함께 보고해야 합니다. 예를 들어 상위 2개가 60%라면 40%의 정보를 버린 셈이죠. 또, PCA는 분산이 큰 방향을 남길 뿐 "예측에 중요한 방향"을 남긴다는 보장은 없어요. 분산은 작지만 정답을 가르는 데 결정적인 방향이 버려질 수도 있습니다.

# %% 1. 고윳값: 근의 공식 vs numpy, 그리고 검산
import numpy as np
import matplotlib.pyplot as plt
from sklearn.decomposition import PCA
from sklearn.datasets import load_digits

A = np.array([[4, 1], [1, 3]], dtype=float)
lam = [(7 + np.sqrt(5)) / 2, (7 - np.sqrt(5)) / 2]
print("근의 공식 λ =", np.round(lam, 4))
vals, vecs = np.linalg.eig(A)
vals, vecs = np.real(vals), np.real(vecs)      # 버전에 따라 복소수 꼴로 나올 수 있어 실수부만 (대칭 행렬이라 실제로 실수)
print("np.linalg.eig λ =", np.round(vals, 4))
for i in range(2):
    v = vecs[:, i]
    print(f"λ={vals[i]:.4f}, v={v.round(4)}: A@v = {(A @ v).round(4)}, λv = {(vals[i] * v).round(4)}")
print("합", round(vals.sum(), 4), "= 대각합", np.trace(A), "/ 곱", round(vals.prod(), 4), "= 행렬식", round(np.linalg.det(A), 4))

# %% 2. 원을 타원으로: 고유벡터는 방향이 그대로
t = np.linspace(0, 2 * np.pi, 100); circle = np.vstack([np.cos(t), np.sin(t)])
ellipse = A @ circle
plt.figure(figsize=(5.5, 5.5)); plt.plot(*circle, "gray", label="unit circle"); plt.plot(*ellipse, "b", label="A @ circle")
for i, c in enumerate(["red", "orange"]):
    v = vecs[:, i] * vals[i]; plt.arrow(0, 0, v[0], v[1], color=c, width=0.05, length_includes_head=True)
plt.gca().set_aspect("equal"); plt.legend(); plt.title("Eigenvectors keep their direction"); plt.grid(alpha=0.3); plt.show()

# %% 3. PCA 여섯 단계를 손으로
X = np.array([[0, 0], [1, 1], [0, -1], [-1, 0]], dtype=float)
Xc = X - X.mean(axis=0)                                   # 1) 중심화 (여기서는 이미 평균 0)
S = Xc.T @ Xc / (len(X) - 1)                              # 2) 공분산 행렬
w, V = np.linalg.eigh(S)                                  # 3) 고윳값·고유벡터 (대칭 행렬용)
order = np.argsort(w)[::-1]; w, V = w[order], V[:, order] # 4) 내림차순
W = V[:, :1]                                              # 5) 상위 1개
Z = Xc @ W                                                # 6) 투영
print("공분산 행렬 =\n", S.round(4))
print("고윳값 =", w.round(4), "/ PC1 =", W.ravel().round(4), "/ 설명 비율 =", round(w[0] / w.sum(), 4))
print("투영 Z =", Z.ravel().round(4))
sk = PCA(n_components=1).fit(X)
print("sklearn 설명 비율 =", sk.explained_variance_ratio_.round(4), "/ 투영 =", sk.transform(X).ravel().round(4), "(부호는 반대일 수 있음)")

# %% 4. 비스듬한 점 구름과 주성분
rng = np.random.default_rng(5)
P = rng.multivariate_normal([0, 0], [[3, 2], [2, 2]], size=200)
pca = PCA(2).fit(P)
plt.figure(figsize=(6, 6)); plt.scatter(P[:, 0], P[:, 1], s=10, alpha=0.5, label="data")
for comp, var, c in zip(pca.components_, pca.explained_variance_, ["red", "orange"]):
    plt.arrow(0, 0, *(comp * 2 * np.sqrt(var)), color=c, width=0.06, length_includes_head=True)
proj = (P @ pca.components_[0])[:, None] * pca.components_[0]
plt.scatter(proj[:, 0], proj[:, 1], s=8, color="green", label="projected on PC1")
plt.gca().set_aspect("equal"); plt.legend(); plt.title(f"PC1 explains {pca.explained_variance_ratio_[0]:.0%}"); plt.show()

# %% 5. 손글씨 숫자 64차원 -> 2차원
digits = load_digits()
p2 = PCA(2).fit(digits.data); Z2 = p2.transform(digits.data)
print("손글씨 64차원: 상위 2개 설명 비율 =", round(p2.explained_variance_ratio_.sum(), 3),
      "/ 상위 10개 =", round(PCA(10).fit(digits.data).explained_variance_ratio_.sum(), 3))
plt.figure(figsize=(6.5, 5)); sc = plt.scatter(Z2[:, 0], Z2[:, 1], c=digits.target, cmap="tab10", s=8)
plt.colorbar(sc, label="digit"); plt.xlabel("PC1"); plt.ylabel("PC2"); plt.title("Digits (64-D) projected to 2-D"); plt.show()

용어 대응 카드

고윳값과 고유벡터란 = 정사각 행렬 A에 대해 Ax = λx이면 x는 고유벡터, λ는 고윳값. A를 곱해도 방향은 그대로, 크기만 λ배.
고윳값 찾기 = 특성방정식 det(A − λI) = 0을 풀어 λ를 구한다. ① A − λI ② 행렬식 ③ λ에 대해 풀기.
고유벡터 찾기 = 고윳값 λ마다 (A − λI)x = 0을 풀어 x를 구한다. 0이 아닌 상수배는 모두 같은 고유벡터.
고윳값의 성질 = n × n 행렬은 고윳값 n개(중복 포함). 합 = 대각합 tr A, 곱 = 행렬식 det A. 대칭 행렬은 고윳값이 실수, 고유벡터가 서로 직각.
PCA의 공분산 행렬 = PCA는 먼저 데이터의 공분산 행렬 Σ = (1/(n−1))(X − μ)ᵀ(X − μ)를 계산한다. 대칭이며 특성들이 함께 움직이는 정도를 보여 준다.
고유벡터로 하는 PCA = ① 표준화 ② 공분산 행렬 Σ ③ Σ의 고윳값·고유벡터 ④ 고윳값 내림차순 정렬 ⑤ 상위 k개 고유벡터(주성분) 선택 ⑥ Z = X_centered · W로 투영.
PCA 2차원 예제 = X = [[0,0],[1,1],[0,−1],[−1,0]] → Σ = [[2/3, 1/3], [1/3, 2/3]] → λ₁ = 1, v₁ = (1/√2)[1, 1], λ₂ = 1/3, v₂ = (1/√2)[1, −1].
PCA 시각화와 정리 = 원래 축(특성1, 특성2) 대신 PC1(가장 넓게 퍼진 방향)과 PC2(그와 직각)를 새 축으로 쓰면, 비스듬한 점 구름이 가로로 눕는다.

원자료와 다르게 쓴 곳

  • 원자료 7번 예제의 "after standardization"은 실제로는 평균만 0으로 맞춘 중심화 데이터라서(각 특성 분산 2/3), 이 도감에서는 "중심화"라고 고쳐 썼습니다.
  • 원자료 3번의 고유벡터 [1, λ − 4]에 숫자(≈ [1, 0.618])와 정규화 값([0.851, 0.526])을 덧붙였습니다.

비유와 예시의 한계

  • 연필 묶음 사진 비유는 "가장 길게 보이는 방향" 하나까지만 맞습니다. 여러 주성분을 동시에 고르는 것은 그림으로 보기 어려워요.
  • PCA는 직선 방향의 분산만 봅니다. 분산이 크다고 늘 예측에 중요한 것은 아니에요.
