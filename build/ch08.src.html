통계의 두 갈래 Types of Statistics

기술통계(데이터를 요약)와 추론통계(표본으로 모집단을 짐작).

말로 먼저 기술통계는 가진 데이터를 평균·분산·그래프로 요약할 뿐 일반화하지 않아요. 추론통계는 일부(표본)로 전체(모집단)를 추정하고, 가설을 검정하고, 신뢰구간을 만듭니다.
숫자로 한 번 해 보기

  2. 추론: "이 반으로 보아 전국 고1 평균 키는 163~167 cm일 것"
  3. 추론에는 늘 오차 범위가 붙음

08-03

가운데를 재는 숫자 Measures of Central Tendency

평균(다 더해 개수로 나눔), 중앙값(정렬한 가운데), 최빈값(가장 자주 나온 값).

말로 먼저 2, 4, 6, 8, 10의 평균은 30 ÷ 5 = 6, 정렬한 가운데도 6이에요. 최빈값은 2, 4, 6, 4, 8처럼 4가 두 번 나오면 4입니다. 값이 짝수 개면 중앙값은 가운데 두 값의 평균이에요.
숫자로 한 번 해 보기
  1. 평균: (2 + 4 + 6 + 8 + 10) ÷ 5 = 6
  2. 중앙값: 2, 4, [6], 8, 10 → 6
  3. 최빈값: 2, 4, 6, 4, 8 → 4
  4. 짝수 개 1, 3, 5, 7 → 중앙값 (3 + 5)/2 = 4
학교 수학으로 보면
중학교 "대푯값".
AI에서는
소득·집값처럼 한쪽으로 치우친 데이터는 평균보다 중앙값이 "보통"을 더 잘 말해요.
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
x̄ = (Σ xᵢ) / n엑스 바평균: 합 ÷ 개수
08-04

퍼짐을 재는 숫자 Measures of Dispersion

범위(최댓값 − 최솟값), 분산(평균에서 떨어진 정도의 제곱 평균), 표준편차(분산의 제곱근).

말로 먼저 평균이 같아도 퍼짐은 다를 수 있어요. 분산은 "평균과의 차이"를 제곱해 평균 낸 값이고(제곱하는 이유: 음수·양수가 서로 지우지 않게), 표준편차는 그 제곱근이라 원래 단위로 돌아옵니다.
숫자로 한 번 해 보기
  1. 2, 4, 6, 8, 10: 범위 = 10 − 2 = 8
  2. 평균 6과의 차이: −4, −2, 0, 2, 4 → 제곱 16, 4, 0, 4, 16
  3. 분산 σ² = 40 ÷ 5 = 8, 표준편차 σ = √8 ≈ 2.828
학교 수학으로 보면
중3 "산포도: 분산과 표준편차".
AI에서는
표준화 z = (x − 평균) ÷ 표준편차로 키(cm)와 몸무게(kg)처럼 단위가 다른 특성을 같은 크기로 맞춥니다.

헷갈리기 쉬운 점 원자료의 분산은 n으로 나누는 모집단 분산입니다. 표본으로 모집단을 추정할 때는 n − 1로 나눠요(15장, 이때 2, 4, 6, 8, 10의 분산은 10).

식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
σ² = (1/n) Σ (xᵢ − μ)²시그마 제곱모집단 분산
σ = √σ²시그마표준편차
08-05

사분위수·백분위수·IQR Quartiles, Percentiles and IQR

정렬한 데이터를 넷으로 나누는 점 Q1·Q2·Q3. IQR = Q3 − Q1은 가운데 절반의 폭.

말로 먼저 1, 2, 4, 6, 8, 10, 12(이미 정렬)에서 중앙값 Q2 = 6. 아래 절반 1, 2, 4의 가운데 Q1 = 2, 위 절반 8, 10, 12의 가운데 Q3 = 10. IQR = 10 − 2 = 8. 최솟값·Q1·중앙값·Q3·최댓값 다섯 숫자로 상자 그림을 그려요.
숫자로 한 번 해 보기
  1. Q1(25번째 백분위수) = 2
  2. Q2(중앙값) = 6, Q3(75번째 백분위수) = 10
  3. IQR = 8, 다섯 숫자 요약: 1, 2, 6, 10, 12
학교 수학으로 보면
고등 "통계"의 백분위수, 상자 그림(교과서 보충).
AI에서는
흔한 이상치 기준: Q1 − 1.5 × IQR보다 작거나 Q3 + 1.5 × IQR보다 큰 값. 이 예에서는 −10 미만, 22 초과.

헷갈리기 쉬운 점 사분위수 계산법은 여러 가지라(가운데 값을 포함하느냐 등) 프로그램마다 조금 다를 수 있어요. 이 도감은 원자료처럼 "가운데 값을 빼고 반으로 나누는" 방법을 씁니다.

식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
IQR = Q3 − Q1아이큐알가운데 50%의 폭

평균·중앙값·최빈값 비교 Mean, Median, Mode Comparison

한쪽으로 튀는 값(이상치)은 평균만 크게 끌어당긴다.

말로 먼저 1, 2, 2, 3, 100의 평균은 108 ÷ 5 = 21.6인데 중앙값은 2예요. 100 하나가 평균을 혼자 끌어올렸죠. 5, 5, 5, 5, 5는 셋 다 5, 10, 20, 30은 평균·중앙값 20이고 최빈값은 없습니다.
숫자로 한 번 해 보기
  1. 2, 4, 6, 8, 10 → 평균 6, 중앙값 6 (대칭)
  2. 1, 2, 2, 3, 100 → 평균 21.6, 중앙값 2, 최빈값 2
  3. 10, 20, 30 → 평균 20, 중앙값 20, 최빈값 없음
학교 수학으로 보면
중학교 "대푯값의 선택".
AI에서는

분포 이해, 이상치 찾기, 특성 크기 맞추기, 전처리·정제, 모델 선택·평가, EDA.

실험숫자 묶음 요약기 — 가운데와 퍼짐

왜 이 방법을 쓰나
  1. 문제: 고객 1만 명의 구매 금액을 한눈에 보고 "보통 고객"을 말하고 싶습니다.
  2. 앞 방법의 한계: 평균 하나만 보면 큰손 고객 몇 명 때문에 "보통"이 실제보다 크게 보입니다.
  3. 이 방법의 해법: 가운데(평균·중앙값)와 퍼짐(표준편차·IQR)을 함께 보고, 상자 그림으로 튀는 값을 확인합니다.

쉽게 말하면 반 키를 말할 때 "평균 165"와 함께 "대부분 160~170"을 같이 말하는 것.

박사의 정리

요약 숫자는 늘 짝으로 읽으세요. "가운데 + 퍼짐". 그리고 평균과 중앙값이 멀리 떨어져 있으면 그림을 그려 튀는 값을 찾으세요. 모델에 넣기 전에 데이터를 들여다보는 이 습관이 AI 프로젝트의 절반을 구합니다.

이 실험의 한계 요약기는 숫자 묶음 하나만 봅니다. 두 변수가 함께 움직이는지(상관)는 10장에서 봐요.
AI 판단 코너주판봇의 "1, 2, 2, 3, 100의 대표값은 21.6"

박사는 늘 두 가지를 묻습니다. "가정이 맞나? 숫자가 그럴듯한가?"

  1. 가정이 맞나? 평균은 어떤 데이터에서 "보통"을 잘 나타내나요? 이 데이터는 대칭인가요?
  2. 숫자가 그럴듯한가? 다섯 값 중 21.6에 가까운 값이 하나라도 있나요?
확인해 보기 (먼저 스스로 따져 본 뒤 펼치세요)

계산(108 ÷ 5 = 21.6)은 맞지만 해석이 틀렸어요. 21.6 근처에는 값이 하나도 없고, 다섯 중 넷이 3 이하입니다. 이렇게 치우친 데이터의 "보통"은 중앙값 2가 더 잘 말해요. 계산이 맞는 것과 결론이 맞는 것은 다른 문제라는 것, AI 결과를 읽을 때 가장 자주 만나는 함정이에요.

주제: 평균·중앙값·최빈값, 범위·분산·표준편차, 사분위수·IQR, 이상치
요구 사항:
1. 데이터 [2, 4, 6, 8, 10]의 평균·중앙값·범위·분산·표준편차를 (a) 공식대로 반복문으로 직접 (b) numpy로 계산해 비교해 줘. 분산은 n으로 나누는 것(ddof=0)과 n-1로 나누는 것(ddof=1)을 둘 다 보여 줘.
2. [1, 2, 2, 3, 100]의 평균과 중앙값을 비교하고, 이상치 100을 빼면 평균이 어떻게 바뀌는지 보여 줘.
3. [1, 2, 4, 6, 8, 10, 12]의 Q1, Q2, Q3를 "가운데 값을 빼고 반으로 나누는 방법"으로 직접 구하고, numpy.percentile 결과와 왜 다를 수 있는지 주석으로 설명해 줘.
4. IQR 규칙(Q1-1.5*IQR, Q3+1.5*IQR)으로 이상치를 찾는 함수를 numpy.percentile로 만들어 줘.
5. 정규분포 난수 200개(seed 고정)로 히스토그램과 상자 그림을 1×2로 그려 줘(영어 라벨).
6. 키(cm)와 몸무게(kg) 예시 데이터를 표준화(z 점수)해서 평균 0, 표준편차 1이 되는지 확인해 줘.
7. 모든 줄에 한국어 주석.

연구소가 직접 실행해 결과를 확인한 코드입니다. 버튼 하나로 코랩에서 바로 열 수 있어요(구글 계정만 있으면 설치할 것이 없습니다).

코드 펼치기 (몰라도 됩니다 · 50줄)
# %% 1. 가운데와 퍼짐: 손으로 vs numpy
import numpy as np
import matplotlib.pyplot as plt

x = [2, 4, 6, 8, 10]
n = len(x)
mean = sum(x) / n
var_pop = sum((v - mean) ** 2 for v in x) / n          # 모집단 분산 (n으로 나눔)
var_smp = sum((v - mean) ** 2 for v in x) / (n - 1)    # 표본 분산 (n-1로 나눔)
print("평균", mean, "/ 중앙값", np.median(x), "/ 범위", max(x) - min(x))
print("분산(n)", var_pop, "= np.var", np.var(x), "/ 표준편차", round(var_pop ** 0.5, 3))
print("분산(n-1)", var_smp, "= np.var(ddof=1)", np.var(x, ddof=1))

# %% 2. 이상치가 평균을 끌어당긴다
y = np.array([1, 2, 2, 3, 100])
print("평균", y.mean(), "/ 중앙값", np.median(y))
print("100을 빼면 평균", y[y < 100].mean(), "/ 중앙값", np.median(y[y < 100]))

# %% 3. 사분위수 (원자료 방식: 가운데 값을 빼고 반으로)
def quartiles(data):
    s = sorted(data); m = len(s); h = m // 2
    lower, upper = s[:h], s[h + 1:] if m % 2 else s[h:]
    return np.median(lower), np.median(s), np.median(upper)

z = [1, 2, 4, 6, 8, 10, 12]
q1, q2, q3 = quartiles(z)
print("원자료 방식 Q1, Q2, Q3 =", q1, q2, q3, "/ IQR =", q3 - q1)
print("numpy.percentile 25, 50, 75 =", np.percentile(z, [25, 50, 75]), "(계산 방식이 달라 값이 다를 수 있음)")

# %% 4. IQR 규칙으로 이상치 찾기 (여기서는 numpy.percentile 방식의 사분위수 사용)
def outliers(data):
    q1, q3 = np.percentile(data, [25, 75]); iqr = q3 - q1
    lo, hi = q1 - 1.5 * iqr, q3 + 1.5 * iqr
    return [int(v) for v in data if v < lo or v > hi], (float(lo), float(hi))
found, (lo, hi) = outliers([1, 2, 2, 3, 100])
print("이상치:", found, f"/ 정상 범위 {lo} ~ {hi}")

# %% 5. 히스토그램과 상자 그림
rng = np.random.default_rng(1)
scores = rng.normal(70, 10, 200)
fig, ax = plt.subplots(1, 2, figsize=(10, 3.5))
ax[0].hist(scores, bins=15, color="teal", edgecolor="white"); ax[0].set_title("Histogram"); ax[0].set_xlabel("score")
ax[1].boxplot(scores); ax[1].set_title("Box plot")
plt.tight_layout(); plt.show()

# %% 6. 표준화: 단위가 다른 특성을 같은 크기로
h = np.array([160, 165, 170, 175, 180.0]); w = np.array([50, 58, 61, 70, 76.0])
zh, zw = (h - h.mean()) / h.std(), (w - w.mean()) / w.std()
print("키 z:", zh.round(2), "/ 평균", round(zh.mean(), 10), "표준편차", round(zh.std(), 3))
print("몸무게 z:", zw.round(2), "/ 평균", round(zw.mean(), 10), "표준편차", round(zw.std(), 3))

분산(n-1) 10.0 = np.var(ddof=1) 10.0

질문답 한 줄
통계의 두 갈래는?기술통계(요약)와 추론통계(표본으로 모집단 짐작).
가운데를 재는 숫자는?평균 6, 중앙값 6, 최빈값 4 (원자료 예).
퍼짐을 재는 숫자는?범위 8, 분산 8, 표준편차 √8 ≈ 2.828.
IQR은?Q3 − Q1. 1, 2, 4, 6, 8, 10, 12 → 10 − 2 = 8.
이상치가 있으면?평균이 끌려간다(21.6 vs 중앙값 2). 중앙값과 상자 그림을 함께.

용어 대응 카드

통계란 = 데이터를 모으고, 정리하고, 분석하고, 해석하는 수학의 한 분야.
통계의 두 갈래 = 기술통계(데이터를 요약)와 추론통계(표본으로 모집단을 짐작).
가운데를 재는 숫자 = 평균(다 더해 개수로 나눔), 중앙값(정렬한 가운데), 최빈값(가장 자주 나온 값).
퍼짐을 재는 숫자 = 범위(최댓값 − 최솟값), 분산(평균에서 떨어진 정도의 제곱 평균), 표준편차(분산의 제곱근).
사분위수·백분위수·IQR = 정렬한 데이터를 넷으로 나누는 점 Q1·Q2·Q3. IQR = Q3 − Q1은 가운데 절반의 폭.
평균·중앙값·최빈값 비교 = 한쪽으로 튀는 값(이상치)은 평균만 크게 끌어당긴다.
데이터 그리기 = 히스토그램(도수 분포), 상자 그림(퍼짐과 이상치), 산점도(두 변수의 관계).
ML 응용과 핵심 정리 = 분포 이해, 이상치 찾기, 특성 크기 맞추기, 전처리·정제, 모델 선택·평가, EDA.

원자료와 다르게 쓴 곳

  • 원자료 5번 상자 그림의 왼쪽 글자 "RoI"는 이 도감에서 "최솟값(Min)"으로 읽었습니다.
  • 원자료 6번 표의 "1, 2, 2, 3, 100"에 대해 이상치 판정 기준(IQR 규칙)을 덧붙였습니다.
