확률 빠른 공식 Probability (Quick Formulas)

0 ≤ P(A) ≤ 1, P(Aᶜ) = 1 − P(A), P(A∪B) = P(A) + P(B) − P(A∩B), P(A|B) = P(A∩B)/P(B), 베이즈 P(A|B) = P(B|A)P(A)/P(B), 독립 P(A∩B) = P(A)P(B).

말로 먼저 6~7장의 핵심입니다. 덧셈은 겹친 곳 빼기, 곱셈은 독립일 때만 그냥 곱하기, 조건부는 좁힌 세계에서 다시 세기, 베이즈는 방향 뒤집기.
숫자로 한 번 해 보기
  1. 주사위 A = {1,2,3}, B = {2,4,6} → P(A∪B) = 5/6 (6장)
  2. 유병률 1% 검사 → P(병|양성) ≈ 16.7% (7장)
  3. 동전 두 번 앞면 = 1/4 (6장)
학교 수학으로 보면

통계 빠른 공식 Statistics (Quick Formulas)

평균 x̄ = (1/n)Σxᵢ, 표본분산 s² = (1/(n−1))Σ(xᵢ − x̄)², 표준편차 s = √s², 공분산 Cov = (1/n)Σ(xᵢ − x̄)(yᵢ − ȳ), 상관 r = Cov/(σxσy), −1 ≤ r ≤ 1.

말로 먼저 8·10장의 핵심입니다. 이 카드의 분산은 n − 1로 나누는 표본분산이에요(8장의 모집단 분산은 n으로 나눔). 가진 데이터로 더 큰 집단의 분산을 추정할 때는 n − 1이 더 정확합니다.
숫자로 한 번 해 보기
  1. 2, 4, 6, 8, 10: 모집단 분산 8, 표본분산 10
  2. X = 1~5, Y = 2, 4, 5, 4, 5 → Cov 1.2, r ≈ 0.775 (10장)
  3. r은 단위가 바뀌어도 그대로
학교 수학으로 보면
중3 산포도, 고등 통계.
AI에서는
표준화(평균 0·표준편차 1), 특성 선택, 다중공선성 점검.

헷갈리기 쉬운 점 원자료는 분산은 n − 1, 공분산은 n으로 나눠 적었습니다. 같은 분석에서는 둘을 같은 기준으로 맞추세요(상관계수는 어느 쪽이든 같음).

편미분과 그래디언트 Partial Derivatives & Gradient

말로 먼저 12장의 핵심입니다. 원자료 예 f(x, y) = x²y + 3xy²: x로 미분하면 2xy + 3y², y로 미분하면 x² + 6xy.

최적화 빠른 공식 Optimization (Quick Formulas)

경사하강 θ_new = θ_old − α∇f(θ). 최솟값: ∇f = 0이고 헤세 행렬 H = ∇²f가 양의 정부호. 최댓값: ∇f = 0이고 H가 음의 정부호.

말로 먼저 13장의 핵심 + 새 개념 하나, 헤세 행렬입니다. Hᵢⱼ = ∂²f/∂xᵢ∂xⱼ(12장의 2계 편미분을 표로). 기울기가 0인 평평한 점에서, 모든 방향으로 아래로 볼록하면(양의 정부호) 바닥, 위로 볼록하면(음의 정부호) 꼭대기, 섞여 있으면 안장점이에요.
숫자로 한 번 해 보기
  1. f = x² + y² → H = [[2, 0], [0, 2]] → 고윳값 2, 2 > 0 → (0, 0)은 최솟값
  2. f = x² − y² → H = [[2, 0], [0, −2]] → 섞임 → (0, 0)은 안장점
  3. 경사하강 종류: 배치, SGD, 미니배치, 모멘텀·RMSProp·Adam
학교 수학으로 보면
이차함수의 볼록성, 14장 고윳값(정부호 = 고윳값이 모두 양수).
AI에서는
신경망 손실 지형에는 안장점이 아주 많아요. 경사하강이 평평한 곳에서 느려지는 이유 중 하나.

헷갈리기 쉬운 점 원자료의 "∇f = 0이고 H가 양의 정부호"는 최솟값(정확히는 극소)의 충분조건입니다. H가 0을 포함하면 이 판정으로는 알 수 없어요.

고윳값·고유벡터 빠른 공식 Eigenvalues & Eigenvectors

Ax = λx, 특성방정식 det(A − λI) = 0, 2 × 2: (a − λ)(d − λ) − bc = 0. n × n은 고윳값 n개, 서로 다른 λ의 고유벡터는 일차독립, 대칭이면 고유벡터가 직각.

말로 먼저 14장의 핵심입니다. "서로 다른 고윳값의 고유벡터는 일차독립"은 원자료에 새로 나온 성질로, 고유벡터들이 서로 다른 방향을 가리킨다는 뜻이에요.
숫자로 한 번 해 보기
  1. A = [[2, 1], [1, 2]] → (2 − λ)² − 1 = 0 → λ = 3, 1
  2. v₁ = (1/√2)[1, 1], v₂ = (1/√2)[1, −1]
  3. 대칭이라 v₁·v₂ = 0
학교 수학으로 보면
이차방정식, 행렬식.
AI에서는
PCA, 스펙트럴 군집, 페이지랭크.

PCA 핵심 공식 PCA (Key Formulas)

표준화(평균 0, 표준편차 1) → 공분산 Σ = (1/(n−1))(X − μ)ᵀ(X − μ) → Σ의 고유분해 → 내림차순 정렬 → 상위 k개 → Z = X_centered · W.

말로 먼저 14장의 여섯 단계 그대로예요. PCA는 차원 축소와 시각화를 돕고, W는 고른 고유벡터들, Z는 옮겨진 데이터(주성분)입니다.
숫자로 한 번 해 보기
  1. 특성 64개 손글씨 → 2개로: 분산의 약 28.5% 유지
  2. 같은 데이터 → 10개로: 약 73.8% 유지
  3. 몇 % 남았는지를 늘 함께 말하기
학교 수학으로 보면
행렬곱, 고윳값.

15-09

ML에서 자주 쓰는 함수 Common Functions in ML

시그모이드 1/(1+e⁻ˣ), tanh (eˣ − e⁻ˣ)/(eˣ + e⁻ˣ), ReLU max(0, x), MSE (1/m)Σ(yᵢ − ŷᵢ)², 교차 엔트로피 −(1/m)Σ[y log ŷ + (1−y) log(1−ŷ)], 소프트맥스 e^zᵢ / Σe^zⱼ.

말로 먼저 앞 셋은 활성화 함수(신경망이 곡선을 배울 수 있게 하는 비선형 함수, 1장), 뒤 셋 중 MSE와 교차 엔트로피는 손실 함수, 소프트맥스는 점수를 확률 분포(합 1, 9장)로 바꾸는 함수예요. ① 시그모이드: 어떤 수든 0~1로(확률처럼). ② tanh: −1~1로. ③ ReLU: 음수는 0, 양수는 그대로 — 계산이 가장 간단해 가장 많이 씀. ④ MSE: 회귀의 손실(13장). ⑤ 교차 엔트로피: 분류의 손실, 정답에 낮은 확률을 주면 크게 벌함. ⑥ 소프트맥스: 여러 점수를 합이 1인 확률로.
숫자로 한 번 해 보기
  1. σ(0) = 1/(1 + 1) = 0.5, σ(2) ≈ 0.881
  2. ReLU(−3) = 0, ReLU(2) = 2
  3. 정답 1인데 ŷ = 0.9 → 손실 −log 0.9 ≈ 0.105 / ŷ = 0.1 → −log 0.1 ≈ 2.303
  4. 소프트맥스([2, 1, 0]) ≈ [0.665, 0.245, 0.090]
학교 수학으로 보면

박사의 정리

공식을 다 외울 필요는 없습니다. "이 공식이 무엇을 재는가, 어디서 쓰는가"를 말할 수 있으면 나머지는 찾아보면 돼요. 그게 도감의 쓰임입니다. 대신 AI가 공식을 써서 낸 결과는, 그 공식이 무엇을 재는지 알아야만 판단할 수 있어요.

이 실험의 한계 공식 도감은 이 도감의 열다섯 장에 나온 공식만 담았습니다. 정보이론(엔트로피), 행렬 분해(SVD) 등은 자매편 「인공지능을 위한 수학」에서 이어 보세요.
AI 판단 코너주판봇의 "소프트맥스 출력 [0.7, 0.5, 0.3]이니까 첫째 클래스!"

박사는 늘 두 가지를 묻습니다. "가정이 맞나? 숫자가 그럴듯한가?"

  1. 가정이 맞나? 소프트맥스 출력은 어떤 성질이 있어야 하나요(9장의 분포 성질)?
  2. 숫자가 그럴듯한가? 세 값을 더하면 얼마인가요?
확인해 보기 (먼저 스스로 따져 본 뒤 펼치세요)

소프트맥스 출력은 확률 분포라서 모두 더하면 1이어야 해요. 0.7 + 0.5 + 0.3 = 1.5이므로 이 숫자는 소프트맥스를 거친 값이 아닙니다(아마 클래스마다 시그모이드를 따로 쓴 값). 그런 경우 "첫째 클래스일 확률 70%"라고 읽으면 안 돼요. 결과 가장 큰 값이 첫째라는 판단 자체는 맞을 수 있지만, 확률로 해석하려면 합이 1인지부터 확인해야 합니다.

# %% 1. 공식을 함수로, 도감 예시로 검산
import numpy as np
import matplotlib.pyplot as plt

dot = lambda a, b: sum(x * y for x, y in zip(a, b))
norm = lambda v: dot(v, v) ** 0.5
det2 = lambda M: M[0][0] * M[1][1] - M[0][1] * M[1][0]
mean = lambda xs: sum(xs) / len(xs)
var_s = lambda xs: sum((x - mean(xs)) ** 2 for x in xs) / (len(xs) - 1)      # 표본분산
cov = lambda xs, ys: sum((x - mean(xs)) * (y - mean(ys)) for x, y in zip(xs, ys)) / len(xs)
corr = lambda xs, ys: cov(xs, ys) / ((cov(xs, xs) ** 0.5) * (cov(ys, ys) ** 0.5))
bayes = lambda p, sens, fpr: sens * p / (sens * p + fpr * (1 - p))

assert dot([1, 2, 3], [4, 5, 6]) == 32
assert norm([3, 4]) == 5
assert (np.array([[1, 2, 3], [4, 5, 6]]) @ np.array([[7, 8], [9, 10], [11, 12]])).tolist() == [[58, 64], [139, 154]]
assert det2([[2, 1], [1, 2]]) == 3
assert mean([2, 4, 6, 8, 10]) == 6 and var_s([2, 4, 6, 8, 10]) == 10
X, Y = [1, 2, 3, 4, 5], [2, 4, 5, 4, 5]
assert round(cov(X, Y), 3) == 1.2 and round(corr(X, Y), 3) == 0.775
assert round(bayes(0.01, 0.99, 0.05), 3) == 0.167
print("공식 검산 9개 모두 통과")

# %% 2. 활성화 함수와 소프트맥스
sigmoid = lambda x: 1 / (1 + np.exp(-x))
relu = lambda x: np.maximum(0, x)
def softmax(z):
    z = np.asarray(z, dtype=float); e = np.exp(z - z.max())     # 최댓값을 빼서 overflow 방지
    return e / e.sum()
xs = np.linspace(-5, 5, 200)
fig, ax = plt.subplots(1, 3, figsize=(12, 3.2))
for a, (name, ys) in zip(ax, [("Sigmoid", sigmoid(xs)), ("Tanh", np.tanh(xs)), ("ReLU", relu(xs))]):
    a.plot(xs, ys); a.axhline(0, color="gray", lw=0.6); a.set_title(name); a.grid(alpha=0.3)
plt.tight_layout(); plt.show()
print("σ(0) =", sigmoid(0), "/ σ(2) =", round(sigmoid(2), 3), "/ ReLU(-3), ReLU(2) =", relu(-3), relu(2))
s = softmax([2, 1, 0]); print("softmax([2,1,0]) =", s.round(3), "합 =", round(s.sum(), 6))
print("softmax([1000, 1001]) =", softmax([1000, 1001]).round(3), "(큰 수도 안전)")

# %% 3. 손실 함수
mse = lambda y, yh: np.mean((np.asarray(y) - np.asarray(yh)) ** 2)
def bce(y, yh, eps=1e-12):
    y, yh = np.asarray(y, float), np.clip(np.asarray(yh, float), eps, 1 - eps)
    return -np.mean(y * np.log(yh) + (1 - y) * np.log(1 - yh))
print("MSE([2,3,5], [1.833,3.333,4.833]) =", round(mse([2, 3, 5], [1.833, 3.333, 4.833]), 4))
print("정답 1, 예측 0.9 -> 교차 엔트로피", round(bce([1], [0.9]), 3), "/ 예측 0.1 ->", round(bce([1], [0.1]), 3))

# %% 4. 실전 예제 세 개
p = np.array([1.0, 2.0]); p_new = p - 0.1 * 2 * p
print("(a) 경사하강 한 걸음:", p, "->", p_new)
vals, vecs = np.linalg.eigh(np.array([[2, 1], [1, 2]], dtype=float))
print("(b) 고윳값:", vals[::-1], "/ 고유벡터(열):\n", vecs[:, ::-1].round(4))
Xp = np.array([[2, 0], [0, 1], [1, 1]], dtype=float); Xc = Xp - Xp.mean(axis=0)
S = Xc.T @ Xc / (len(Xp) - 1); w, V = np.linalg.eigh(S); w = w[::-1]
print("(c) 평균", Xp.mean(axis=0).round(3), "/ 공분산\n", S.round(3), "\n    고윳값", w.round(3), "/ PC1 설명 비율", round(w[0] / w.sum(), 3))

용어 대응 카드

선형대수 빠른 공식 = 벡터 x = [x₁, …, xₙ], 내적 a·b = Σaᵢbᵢ, 행렬곱 (AB)ᵢⱼ = Σₖ AᵢₖBₖⱼ, 전치 (Aᵀ)ᵢⱼ = Aⱼᵢ, 역행렬 AA⁻¹ = I, 2 × 2 행렬식 ad − bc.
확률 빠른 공식 = 0 ≤ P(A) ≤ 1, P(Aᶜ) = 1 − P(A), P(A∪B) = P(A) + P(B) − P(A∩B), P(A|B) = P(A∩B)/P(B), 베이즈 P(A|B) = P(B|A)P(A)/P(B), 독립 P(A∩B) = P(A)P(B).
통계 빠른 공식 = 평균 x̄ = (1/n)Σxᵢ, 표본분산 s² = (1/(n−1))Σ(xᵢ − x̄)², 표준편차 s = √s², 공분산 Cov = (1/n)Σ(xᵢ − x̄)(yᵢ − ȳ), 상관 r = Cov/(σxσy), −1 ≤ r ≤ 1.
미적분 빠른 공식 = 미분의 정의 f′(x) = lim(h→0) [f(x+h) − f(x)]/h, (xⁿ)′ = nxⁿ⁻¹, (sin x)′ = cos x, (cos x)′ = −sin x, (eˣ)′ = eˣ, (ln x)′ = 1/x (x > 0).
편미분과 그래디언트 = fₓ = ∂f/∂x, f_y = ∂f/∂y, ∇f(x, y) = (∂f/∂x, ∂f/∂y), n변수 ∇f = (∂f/∂x₁, …, ∂f/∂xₙ).
최적화 빠른 공식 = 경사하강 θ_new = θ_old − α∇f(θ). 최솟값: ∇f = 0이고 헤세 행렬 H = ∇²f가 양의 정부호. 최댓값: ∇f = 0이고 H가 음의 정부호.
고윳값·고유벡터 빠른 공식 = Ax = λx, 특성방정식 det(A − λI) = 0, 2 × 2: (a − λ)(d − λ) − bc = 0. n × n은 고윳값 n개, 서로 다른 λ의 고유벡터는 일차독립, 대칭이면 고유벡터가 직각.
PCA 핵심 공식 = 표준화(평균 0, 표준편차 1) → 공분산 Σ = (1/(n−1))(X − μ)ᵀ(X − μ) → Σ의 고유분해 → 내림차순 정렬 → 상위 k개 → Z = X_centered · W.
ML에서 자주 쓰는 함수 = 시그모이드 1/(1+e⁻ˣ), tanh (eˣ − e⁻ˣ)/(eˣ + e⁻ˣ), ReLU max(0, x), MSE (1/m)Σ(yᵢ − ŷᵢ)², 교차 엔트로피 −(1/m)Σ[y log ŷ + (1−y) log(1−ŷ)], 소프트맥스 e^zᵢ / Σe^zⱼ.
실전 예제 세 개 = ① 경사하강 한 걸음: (1, 2) → (0.8, 1.6). ② 2 × 2 고윳값: [[2, 1], [1, 2]] → λ = 3, 1. ③ 간단한 PCA: X = [[2, 0], [0, 1], [1, 1]].
핵심 정리 = 수학은 ML의 바탕. 선형대수는 데이터 표현, 확률·통계는 데이터 이해, 미적분은 최적화, 그래디언트는 학습, PCA는 차원 축소.

원자료와 다르게 쓴 곳

  • 원자료 5번의 편미분 예(x²y + 3xy²)는 12장 예(x²y + 3xy + y²)와 다른 함수입니다. 두 결과를 섞지 않게 각 장에 따로 적었습니다.
  • 원자료 3번은 분산을 n − 1, 공분산을 n으로 나눠 적었습니다. 이 차이를 항목의 주의 상자에 밝혔습니다.
  • 원자료 10번 ③(PCA) 예는 단계만 있어 이 도감에서 계산(λ ≈ 1.268, 0.066, 설명 비율 약 95.1%)을 마쳤습니다.
  • 원자료 6번의 헤세 조건은 극소·극대의 충분조건이라는 설명을 덧붙였습니다.
