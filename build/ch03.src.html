03장 벡터 연산 — 더하기·내적·길이·각도

음악 앱은 내 취향과 "닮은" 노래를 어떻게 숫자 하나로 골라낼까?

03-01

벡터란 What is a Vector

숫자의 1차원 배열이자, 크기와 방향을 가진 양. 행이나 열로 씁니다.

말로 먼저 [1 2 3]처럼 가로로 쓰면 1 × 3 벡터(행 벡터), 세로로 세우면 3 × 1 벡터(열 벡터)예요. 숫자는 같지만 모양이 달라 계산할 때 구분합니다. ML에서는 데이터 한 건, 특성, 가중치를 벡터로 나타내요.
숫자로 한 번 해 보기
  1. v = [1 2 3] → 1 × 3
  2. 세로로 세운 v → 3 × 1
  3. 바람 = [동쪽 3 m/s, 북쪽 4 m/s] → 크기 5 m/s
학교 수학으로 보면
고등 기하의 "벡터"(크기와 방향).
AI에서는
챗봇은 단어 하나를 수백 개 숫자로 된 벡터(임베딩)로 바꿔 계산합니다.
03-02

벡터 덧셈 Vector Addition

같은 자리끼리 더한다. 두 벡터의 크기(차원)가 같아야 한다.

말로 먼저 [1 2 3] + [4 5 6]은 첫째끼리, 둘째끼리, 셋째끼리 더해 [5 7 9]예요. 그림으로는 a 화살표 끝에 b 화살표를 이어 붙였을 때 도착하는 곳이 a + b입니다.
숫자로 한 번 해 보기
  1. [1 2 3] + [4 5 6] = [1+4, 2+5, 3+6] = [5 7 9]
  2. [1 2] + [1 2 3] → 크기가 달라 더할 수 없음
  3. 집→학교 [3, 1] + 학교→학원 [1, 3] = 집→학원 [4, 4]
학교 수학으로 보면
고등 기하 "벡터의 덧셈"(평행사변형·삼각형 법칙).
AI에서는
임베딩에서 "왕 − 남자 + 여자 ≈ 여왕" 같은 계산이 벡터 덧셈·뺄셈이에요(대략 맞는 예로 유명).
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
a + b = [a₁+b₁, a₂+b₂, …]에이 더하기 비같은 자리끼리 더하기
03-03

벡터 뺄셈 Vector Subtraction

같은 자리끼리 뺀다. a − b는 "b 끝에서 a 끝으로 가는 화살표".

말로 먼저 [5 4 3] − [1 2 1] = [4 2 2]. 뺄셈 결과의 길이가 곧 두 점 사이의 거리라서, "얼마나 다른가"를 재는 데 씁니다.
숫자로 한 번 해 보기
  1. [5 4 3] − [1 2 1] = [5−1, 4−2, 3−1] = [4 2 2]
  2. [4 2 2]의 길이 = √(16+4+4) = √24 ≈ 4.90
  3. 거리 = 차이 벡터의 길이
학교 수학으로 보면
벡터의 뺄셈, 두 점 사이 거리(피타고라스 정리).
AI에서는
예측 − 정답 = 오차 벡터. 이 길이를 줄이는 것이 학습의 목표예요(13장).
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
a − b에이 빼기 비같은 자리끼리 빼기
03-04

스칼라배 Scalar Multiplication

벡터의 모든 숫자에 같은 수 k를 곱한다. 방향은 그대로, 길이만 k배.

말로 먼저 3 × [1 2 3] = [3 6 9]. k가 음수면 방향이 반대로 뒤집히고, 0이면 영벡터가 됩니다.
숫자로 한 번 해 보기
  1. 3 × [1 2 3] = [3 6 9]
  2. −1 × [1 2] = [−1 −2] (반대 방향)
  3. 0.5 × [4 6] = [2 3] (길이 절반)
학교 수학으로 보면
벡터의 실수배.
AI에서는
경사하강에서 "학습률 α × 기울기 벡터"가 스칼라배예요(13장).
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
k·v = [k·v₁, k·v₂, …]케이 곱하기 브이모든 자리에 k를 곱함
03-05

내적 Dot Product (Inner Product)

같은 자리끼리 곱해서 모두 더한 숫자 하나. 두 벡터가 얼마나 닮았는지 잰다.

말로 먼저 [1 2 3]·[4 5 6] = 1×4 + 2×5 + 3×6 = 4 + 10 + 18 = 32. 결과가 벡터가 아니라 숫자 하나(스칼라)인 것이 핵심이에요. 성질 셋: 순서를 바꿔도 같고(a·b = b·a), 자기 자신과의 내적은 길이의 제곱(a·a = ‖a‖²), 내적이 0이면 두 벡터는 직각.
숫자로 한 번 해 보기
  1. [1 2 3]·[4 5 6] = 4 + 10 + 18 = 32
  2. [3 4]·[3 4] = 9 + 16 = 25 = 5² (길이 5의 제곱)
  3. [1 0]·[0 1] = 0 → 직각
학교 수학으로 보면
고등 기하 "벡터의 내적".
AI에서는
신경망 뉴런 하나의 계산이 "가중치 · 입력 + 편향"이에요. 추천 점수도 사용자 벡터 · 상품 벡터.
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
a·b = a₁b₁ + a₂b₂ + … + aₙbₙ에이 내적 비같은 자리끼리 곱해 더하기
a·a = ‖a‖²자기 내적길이의 제곱
03-06

벡터의 노름(크기) Vector Norm (Magnitude)

벡터의 길이. 보통 L2 노름 ‖v‖ = √(v₁² + … + vₙ²).

말로 먼저 [3 4]의 길이는 원점에서 (3, 4)까지의 직선 거리예요. 직각삼각형의 빗변이니 √(3² + 4²) = √25 = 5. 숫자가 몇 개든 같은 방법입니다.
숫자로 한 번 해 보기
  1. ‖[3 4]‖ = √(9 + 16) = √25 = 5
  2. ‖[1 2 2]‖ = √(1 + 4 + 4) = 3
  3. ‖[2 3 6]‖ = √(4 + 9 + 36) = 7
학교 수학으로 보면
중2 피타고라스 정리, 두 점 사이 거리.
AI에서는
임베딩 길이를 1로 맞추는 "정규화", 가중치가 너무 커지지 않게 막는 "규제(L2)"에 씁니다.
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
‖v‖ = √(v₁² + v₂² + … + vₙ²)노름 vL2 길이(유클리드 길이)
03-07

두 벡터 사이 각도 Angle Between Two Vectors

cos θ = a·b / (‖a‖‖b‖). 1이면 같은 방향, 0이면 직각, −1이면 반대.

말로 먼저 내적은 길이에도 영향을 받아요. 길이로 나눠 주면 "방향만의 닮음"이 남는데, 그것이 코사인 유사도입니다. [1 0]과 [0 1]은 내적 0 → cos θ = 0 → 90°(직각)예요.
숫자로 한 번 해 보기
  1. a = [1 0], b = [0 1] → a·b = 0 → θ = 90°
  2. a = [1 2 3], b = [4 5 6] → 32 / (√14 × √77) ≈ 0.975 → 약 12.9°
  3. a = [1 1], b = [−1 −1] → cos θ = −1 → 180°
학교 수학으로 보면
고등 기하 "내적과 사잇각", 삼각비.
AI에서는
추천·검색에서 가장 많이 쓰는 "코사인 유사도"가 바로 cos θ예요. 글의 길이가 달라도 주제(방향)가 같으면 닮았다고 봅니다.
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
cos θ = a·b / (‖a‖ ‖b‖)코사인 세타방향의 닮음, −1 ~ 1
03-08

핵심 정리 Key Takeaways

덧셈·뺄셈·스칼라배는 같은 자리끼리, 내적은 닮음, 노름은 길이, 각도는 방향의 닮음.

말로 먼저 벡터 연산은 ML에서 특성 표현, 유사도 검색, 최적화에 두루 쓰입니다. 덧셈·뺄셈은 "이동", 스칼라배는 "늘이기", 내적과 코사인은 "닮음", 노름은 "크기·거리"로 기억하세요.
숫자로 한 번 해 보기
  1. 이동: a + b
  2. 거리: ‖a − b‖
  3. 닮음: cos θ

실험화살표 실험실 — 더하고, 빼고, 늘이고, 닮음 재기

왜 이 방법을 쓰나
  1. 문제: 두 학생의 취향 [액션 3, 로맨스 1]과 [액션 1, 로맨스 3]이 얼마나 닮았는지 숫자로 말하고 싶습니다.
  2. 앞 방법의 한계: "좀 다르다"는 말로는 수백만 명 중 가장 닮은 사람을 고를 수 없습니다.
  3. 이 방법의 해법: 내적과 코사인으로 방향의 닮음을 숫자 하나(−1~1)로 만듭니다.

쉽게 말하면 두 사람이 가리키는 손가락 방향이 얼마나 같은지 각도로 재는 것.

박사의 정리

내적은 "같은 쪽을 가리키는 정도 × 길이"입니다. 길이를 나눠 없애면 코사인 유사도가 되고, 이것이 추천·검색의 심장이에요. 숫자 하나가 −1에서 1 사이라는 범위가 있어서 비교하기 좋습니다.

이 실험의 한계 화면은 2차원 화살표만 보여 줍니다. 실제 임베딩은 수백~수천 차원이지만 계산 방법은 똑같아요.
AI 판단 코너주판봇의 "[1, 2]와 [100, 200]은 전혀 안 닮았다"

박사는 늘 두 가지를 묻습니다. "가정이 맞나? 숫자가 그럴듯한가?"

  1. 가정이 맞나? 주판봇은 무엇으로 닮음을 쟀나요 — 거리인가요, 방향인가요?
  2. 숫자가 그럴듯한가? 두 벡터의 cos θ를 직접 계산하면 얼마인가요?
확인해 보기 (먼저 스스로 따져 본 뒤 펼치세요)

주판봇은 차이 벡터의 길이(거리 ≈ 221.4)만 보고 "전혀 다르다"고 했어요. 하지만 [100, 200] = 100 × [1, 2]라서 방향은 완전히 같고 cos θ = 1입니다. 거리는 "크기 차이"까지 재고, 코사인은 "방향"만 잽니다. 어느 쪽이 맞는지는 질문에 달려 있어요 — 같은 주제의 짧은 글과 긴 글을 비교한다면 코사인이 맞습니다.

확인 퀴즈

실습코랩 실습실 — 배운 것을 직접 돌려 보기

두 가지 방법이 있어요. ① 생성 AI에게 프롬프트를 주고 코드를 만들게 해 보기, ② 연구소가 미리 만들어 검사까지 마친 코드를 돌려 보기. 둘을 나란히 돌려 결과를 비교하면, AI가 낸 코드를 믿어도 되는지 스스로 판단하는 연습이 됩니다.

너는 고등학생에게 벡터를 가르치는 파이썬 선생님이야. 구글 코랩에서 실행되는 코드를 만들어 줘.
주제: 벡터 연산(덧셈, 뺄셈, 스칼라배, 내적, 노름, 코사인 유사도)
요구 사항:
1. numpy로 a = [1, 2, 3], b = [4, 5, 6]을 만들고 a+b, a-b, 3*a, 내적(np.dot), 노름(np.linalg.norm)을 출력해 줘.
2. 내적을 for 반복문으로 직접 계산한 값과 np.dot 결과가 같은지 비교해 줘.
3. 두 벡터 사이 각도를 cos θ 공식으로 구해 도(degree)로 출력하는 함수 angle_deg(a, b)를 만들어 줘.
4. 2차원 벡터 [3, 1], [1, 3]과 그 합을 matplotlib의 quiver로 화살표 그림으로 그려 줘(축 비율 같게, 영어 라벨).
5. 영화 취향 예시: 사용자 [액션 5, 로맨스 1, 코미디 3]과 영화 3편의 특성 벡터를 만들고, 코사인 유사도가 가장 높은 영화를 추천하는 코드를 써 줘.
6. 모든 줄에 한국어 주석.
② 실제로 돌아가는 코드 — 파이썬 · 코랩

연구소가 직접 실행해 결과를 확인한 코드입니다. 버튼 하나로 코랩에서 바로 열 수 있어요(구글 계정만 있으면 설치할 것이 없습니다).

코드 펼치기 (몰라도 됩니다 · 45줄)
# %% 1. 기본 연산
import numpy as np
import matplotlib.pyplot as plt

a = np.array([1, 2, 3]); b = np.array([4, 5, 6])
print("a + b =", a + b)
print("a - b =", a - b)
print("3 * a =", 3 * a)
print("내적 a·b =", np.dot(a, b))
print("노름 ||a|| =", round(np.linalg.norm(a), 3), "/ ||b|| =", round(np.linalg.norm(b), 3))

# %% 2. 내적을 손으로(반복문) 계산해 비교
s = 0
for x, y in zip(a, b):
    s += x * y          # 같은 자리끼리 곱해서 더하기
print("반복문 내적 =", s, "/ np.dot과 같은가?", s == np.dot(a, b))

# %% 3. 두 벡터 사이 각도
def angle_deg(u, v):
    cos = np.dot(u, v) / (np.linalg.norm(u) * np.linalg.norm(v))
    return np.degrees(np.arccos(np.clip(cos, -1, 1))), cos

for u, v in [([1, 0], [0, 1]), ([1, 2, 3], [4, 5, 6]), ([1, 1], [-1, -1]), ([3, 4], [30, 40])]:
    deg, cos = angle_deg(np.array(u), np.array(v))
    print(f"{u} vs {v}: cos = {cos:.3f}, 각도 = {deg:.1f}도")

# %% 4. 화살표 그림
p, q = np.array([3, 1]), np.array([1, 3])
plt.figure(figsize=(5, 5))
plt.quiver([0, 0, 0], [0, 0, 0], [p[0], q[0], (p+q)[0]], [p[1], q[1], (p+q)[1]],
           color=["red", "blue", "green"], angles="xy", scale_units="xy", scale=1)
plt.quiver(p[0], p[1], q[0], q[1], color="blue", alpha=0.4, angles="xy", scale_units="xy", scale=1)
plt.xlim(0, 5); plt.ylim(0, 5); plt.gca().set_aspect("equal"); plt.grid(alpha=0.3)
plt.title("a (red) + b (blue) = a+b (green)"); plt.show()

# %% 5. 코사인 유사도로 영화 추천
user = np.array([5, 1, 3])                     # [액션, 로맨스, 코미디]
movies = {"Action Hero": np.array([9, 1, 4]), "Love Letter": np.array([1, 9, 2]), "Funny Day": np.array([2, 2, 9])}
def cos_sim(u, v):
    return np.dot(u, v) / (np.linalg.norm(u) * np.linalg.norm(v))
scores = {name: cos_sim(user, vec) for name, vec in movies.items()}
for name, s in sorted(scores.items(), key=lambda t: -t[1]):
    print(f"{name:12s} 코사인 유사도 = {s:.3f}")
print("추천:", max(scores, key=scores.get))
print("영화 벡터를 10배로 늘려도 같은가?", np.isclose(cos_sim(user, movies["Action Hero"] * 10), scores["Action Hero"]))

정리 — 화살표로 닮음과 거리를 잰다

질문답 한 줄
벡터 덧셈·뺄셈은?같은 자리끼리. 크기(차원)가 같아야 함.
스칼라배는?모든 자리에 같은 수를 곱함. 방향 그대로, 길이만 k배.
내적은?같은 자리끼리 곱해 더한 숫자 하나. [1 2 3]·[4 5 6] = 32.
노름은?벡터의 길이. ‖[3 4]‖ = 5.
코사인 유사도는?a·b ÷ (‖a‖‖b‖). 1 같은 방향, 0 직각, −1 반대.

용어 대응 카드

벡터란 = 숫자의 1차원 배열이자, 크기와 방향을 가진 양. 행이나 열로 씁니다.
벡터 덧셈 = 같은 자리끼리 더한다. 두 벡터의 크기(차원)가 같아야 한다.
벡터 뺄셈 = 같은 자리끼리 뺀다. a − b는 "b 끝에서 a 끝으로 가는 화살표".
스칼라배 = 벡터의 모든 숫자에 같은 수 k를 곱한다. 방향은 그대로, 길이만 k배.
내적 = 같은 자리끼리 곱해서 모두 더한 숫자 하나. 두 벡터가 얼마나 닮았는지 잰다.
벡터의 노름(크기) = 벡터의 길이. 보통 L2 노름 ‖v‖ = √(v₁² + … + vₙ²).
두 벡터 사이 각도 = cos θ = a·b / (‖a‖‖b‖). 1이면 같은 방향, 0이면 직각, −1이면 반대.
핵심 정리 = 덧셈·뺄셈·스칼라배는 같은 자리끼리, 내적은 닮음, 노름은 길이, 각도는 방향의 닮음.

원자료와 다르게 쓴 곳

  • 원자료의 각도 예([1 0]·[0 1])에 더해 [1 2 3]과 [4 5 6]의 각도(약 12.9°)를 검산해 넣었습니다.

비유와 예시의 한계

  • 손가락 방향 비유는 2·3차원까지 그림으로 맞습니다. 수백 차원의 각도는 그림 대신 계산으로만 볼 수 있어요.
  • 코사인 유사도는 크기를 무시하므로, 크기 자체가 중요한 문제(예: 구매 금액)에는 거리와 함께 봐야 합니다.
