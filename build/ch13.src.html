AI는 "학습한다"는 말 대신 실제로 무엇을 반복하고 있을까?

최적화는 함수를 가장 작게(또는 크게) 만드는 값을 찾는 일입니다. ML에서는 손실 함수를 최소화하는 가중치를 찾아요. 12장의 그래디언트 반대로 한 걸음씩 걷는 경사하강, 걸음 크기인 학습률, 데이터를 얼마나 나눠 쓰느냐에 따른 세 가지 경사하강, 그리고 Adam 같은 개선판을 항목 8개로 정리합니다.

13-01

최적화란 What is Optimization

함수를 최소화(또는 최대화)하는 파라미터의 가장 좋은 값을 찾는 것. θ* = argmin f(θ).

말로 먼저 θ는 파라미터(가중치·계수), f(θ)는 목적 함수(예: 손실 함수)예요. argmin은 "가장 작은 값" 자체가 아니라 "가장 작게 만드는 입력"을 뜻합니다. f(θ) = (θ − 3)²이면 최솟값은 0이고 argmin은 3이에요.
숫자로 한 번 해 보기
  1. f(θ) = (θ − 3)² → min f = 0, argmin = 3
  2. ML: 손실이 가장 작은 가중치 = argmin
  3. 최대화는 argmax (예: 이익, 정확도)
학교 수학으로 보면
고등 "미분의 활용: 최댓값·최솟값".
AI에서는
"모델을 학습시켰다" = "손실 함수의 argmin(근처)을 찾았다".
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
θ* = argmin_θ f(θ)세타 스타는 아그민손실을 가장 작게 하는 θ
13-02

최소화와 최대화 Types of Optimization Problems

아래로 볼록한 그릇의 바닥(최소화), 위로 볼록한 언덕의 꼭대기(최대화). ML 예: 선형 회귀 MSE, 로지스틱 로그 손실, 신경망 교차 엔트로피, 하이퍼파라미터의 검증 오차.

말로 먼저 최대화 문제는 부호를 바꾸면 최소화 문제가 돼요(argmax f = argmin(−f)). 그래서 ML 라이브러리는 대개 "최소화"만 구현합니다.
숫자로 한 번 해 보기
  1. 최소화: 손실 → 그릇 바닥
  2. 최대화: 정확도·이익 → 언덕 꼭대기
  3. max f(θ) = −min(−f(θ))
학교 수학으로 보면
이차함수의 최댓값·최솟값(중3·고1).
AI에서는
선형 회귀(MSE), 로지스틱 회귀(로그 손실), 신경망(교차 엔트로피), 하이퍼파라미터 튜닝(검증 오차) — 모두 최소화.
13-03

경사하강 Gradient Descent

함수의 최솟값을 찾는 반복 알고리즘. 그래디언트 반대로 α만큼 걷는다: θ_new = θ_old − α∇f(θ).

말로 먼저 f(θ) = θ²이면 ∇f = 2θ라서 θ_new = θ − α(2θ) = θ(1 − 2α). 걸음마다 θ에 (1 − 2α)가 곱해지니, 이 수의 크기가 1보다 작으면 θ가 0(바닥)으로 줄어들어요.
숫자로 한 번 해 보기
  1. θ = 4, α = 0.1 → θ × 0.8 = 3.2
  2. → 2.56 → 2.048 → … → 0에 다가감
  3. α = 0.5 → θ × 0 = 0 → 한 걸음에 바닥(이 그릇에서만)
학교 수학으로 보면
미분(접선의 기울기) + 수열(등비수열 θₙ = θ₀(1 − 2α)ⁿ).
AI에서는
거의 모든 딥러닝 학습의 기본 반복. 프레임워크의 optimizer.step() 한 번이 이 한 걸음.
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
θ_new = θ_old − α∇f(θ)경사하강반대 방향으로 α만큼
f = θ² → θ_new = θ(1 − 2α)예등비수열
13-04

경사하강의 세 가지 Types of Gradient Descent

배치(전체 데이터로 한 걸음), 확률적 SGD(데이터 하나로), 미니배치(데이터 몇십 개로).

말로 먼저 ① 배치: 수렴이 안정적이지만 데이터가 크면 한 걸음이 너무 느려요. ② SGD: 한 걸음이 빠르고 큰 데이터에 맞지만 걸음이 들쭉날쭉(덜 안정). ③ 미니배치: 둘의 균형, 다만 좋은 배치 크기를 골라야 해요. 실제로는 미니배치가 표준입니다.
숫자로 한 번 해 보기
  1. 데이터 1만 개, 배치: 한 걸음에 1만 개 계산
  2. SGD: 한 걸음에 1개 → 1만 걸음 = 1에포크
  3. 미니배치 32개: 한 걸음에 32개 → 약 313걸음 = 1에포크
학교 수학으로 보면
표본(8장)으로 전체를 짐작하는 생각.
AI에서는
배치 크기는 GPU 메모리와 학습 안정성 사이의 줄다리기. 32, 64, 128 같은 값을 흔히 씁니다.
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
배치: θ ← θ − α∇f(θ)전체안정·느림
SGD: θ ← θ − α∇f(θ; xᵢ)하나빠름·흔들림
미니배치: θ ← θ − α∇f(θ; B)묶음 B균형
13-05

학습률 Learning Rate

각 반복의 걸음 크기 α. 너무 크면 최솟값을 넘어가고, 너무 작으면 아주 느리게 수렴한다.

말로 먼저 좋은 학습률은 손실이 매끄럽게 줄고, 큰 학습률은 손실이 지그재그로 튀거나 폭발하고, 작은 학습률은 손실이 거의 안 줄어요. 학습 도중 학습률을 줄여 가는 "학습률 스케줄"도 씁니다.
숫자로 한 번 해 보기
  1. f = θ², θ₀ = 4: α = 0.1 → 15걸음 뒤 θ ≈ 0.14
  2. α = 0.01 → 15걸음 뒤 θ ≈ 2.95 (느림)
  3. α = 1.1 → 걸음마다 −1.2배 → 발산
학교 수학으로 보면
등비수열의 수렴 조건 |r| < 1.
AI에서는
"학습이 안 돼요"의 첫 번째 점검 항목. 손실이 nan(숫자 아님)이 되면 학습률이 너무 큰 경우가 많아요.
13-06

최적화 알고리즘 Optimization Algorithms

경사하강, 모멘텀(지난 기울기로 가속), RMSProp(제곱 기울기 평균으로 학습률 조절), Adam(모멘텀 + RMSProp, 가장 인기), Adagrad, Adadelta, 네스테로프.

말로 먼저 기본 경사하강은 좁고 긴 골짜기에서 벽 사이를 지그재그로 왔다 갔다 해요. 모멘텀은 굴러가는 공처럼 지난 방향을 기억해 흔들림을 줄이고, RMSProp·Adagrad는 변수마다 걸음 크기를 따로 맞추며, Adam은 둘을 합칩니다. 네스테로프는 "앞을 내다보고" 기울기를 재요.
숫자로 한 번 해 보기
  1. 모멘텀: v ← βv + ∇f, θ ← θ − αv (β ≈ 0.9)
  2. RMSProp: 자주 크게 흔들리는 변수는 걸음을 줄임
  3. Adam: 대부분의 딥러닝 기본값(α = 0.001)
학교 수학으로 보면
수열의 점화식(지난 값으로 다음 값).
AI에서는
코드 한 줄로 바꿔 끼울 수 있어요: torch.optim.SGD → torch.optim.Adam.
13-07

ML 최적화 예: 선형 회귀 Optimization in ML (Example)

MSE 손실 J(w, b) = (1/m) Σ (yᵢ − (wxᵢ + b))²를 w ← w − α ∂J/∂w, b ← b − α ∂J/∂b로 줄인다.

말로 먼저 5장의 점 (1, 2), (2, 3), (3, 5)에 경사하강을 쓰면, 반복할수록 w와 b가 정규방정식의 답 w = 1.5, b ≈ 0.333에 다가갑니다. 방정식을 한 번에 푸는 대신 조금씩 걸어서 같은 답에 닿는 거예요.
숫자로 한 번 해 보기
  1. ∂J/∂w = (−2/m) Σ xᵢ(yᵢ − ŷᵢ), ∂J/∂b = (−2/m) Σ (yᵢ − ŷᵢ)
  2. w = b = 0, α = 0.05에서 출발
  3. 수천 걸음 뒤 w ≈ 1.500, b ≈ 0.333 (5장 답과 같음)
학교 수학으로 보면
편미분(12장) + 일차함수.
AI에서는
데이터가 아주 크거나 모델이 비선형이면 정규방정식을 못 쓰니 경사하강이 유일한 길이에요.
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
J(w,b) = (1/m) Σ (yᵢ − (wxᵢ + b))²MSE 손실
w ← w − α ∂J/∂w, b ← b − α ∂J/∂b갱신 규칙손실이 최소가 될 때까지 반복
13-08

손실 곡면 (3D) Loss Surface (3D View)

가중치 축(w, b) 위에 손실 J를 높이로 세운 지형. 경사하강은 이 그릇의 바닥으로 내려가는 길.

말로 먼저 선형 회귀의 MSE는 바닥이 하나뿐인 매끈한 그릇이라 어디서 출발해도 같은 바닥에 닿아요. 신경망의 손실 지형은 울퉁불퉁해서 "충분히 좋은 골짜기(좋은 국소 최솟값)"에 닿는 것을 목표로 합니다. 정리: 최적화는 최선의 파라미터를 찾고, 경사하강은 그래디언트 반대로, 학습률이 수렴에 중요하고, 모멘텀·RMSProp·Adam이 더 빠르고 나은 최적화를 돕습니다.
숫자로 한 번 해 보기
  1. 그릇 하나(볼록): 전역 최솟값 = 유일한 바닥
  2. 울퉁불퉁: 국소 최솟값, 안장점이 있을 수 있음
  3. 목표: 전역 또는 충분히 좋은 국소 최솟값
학교 수학으로 보면
이차함수의 그래프(그릇)의 3D판.
AI에서는
자매편 「최적화 첫걸음」(좌표축 위의 그릇)에서 3D 지형을 직접 돌려 볼 수 있어요.

실험그릇 바닥 찾기 — 학습률 α에 따라 달라지는 걸음

왜 이 방법을 쓰나
  1. 문제: 손실 함수의 바닥(최적 가중치)을 찾고 싶은데, 가중치가 수백만 개라 방정식을 한 번에 풀 수 없습니다.
  2. 앞 방법의 한계: 5장의 정규방정식은 역행렬이 필요해 데이터·가중치가 크면 계산이 불가능하고, 비선형 모델에는 아예 쓸 수 없습니다.
  3. 이 방법의 해법: 지금 자리의 그래디언트만 계산해 반대 방향으로 조금씩 걷는 것을 반복합니다(경사하강).

쉽게 말하면 눈을 가리고 그릇 바닥을 찾을 때, 발밑 기울기를 느끼며 아래로 한 발씩.

연구원이 묻고, 조교 하루가 풀어 봅니다

X2θ(1 − 2α)라는 식이 왜 그렇게 중요해요?

말로 먼저 걸음마다 θ에 같은 수(1 − 2α)가 곱해지니 θ는 등비수열이에요. 공비의 크기가 1보다 작으면 0으로 줄고(수렴), 1보다 크면 점점 커져요(발산).

학교 수학으로 보면 고등 "등비수열의 수렴 조건".

숫자로 한 번 해 보기
  1. α = 0.1 → 공비 0.8 → 수렴
  2. α = 0.7 → 공비 −0.4 → 부호가 바뀌며 수렴(지그재그)
  3. α = 1.1 → 공비 −1.2 → 발산
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
1 − 2α공비한 걸음마다 곱해지는 수
|1 − 2α| < 1수렴 조건0 < α < 1
α = 0.5공비 0이 그릇에선 한 번에 바닥

조교 하루실험실 아래 "한 걸음마다 θ에 곱해지는 수"를 보며 α를 움직여 보세요. 그 수가 −1보다 작아지는 순간 발산이 시작돼요.

박사의 정리

학습률은 "지형을 얼마나 믿고 크게 걸을까"의 선택입니다. 너무 조심하면 해가 지도록 못 내려가고, 너무 과감하면 골짜기를 넘어 반대편 벽에 부딪쳐요. 그래서 실제 학습은 손실 곡선을 그려 보며 α를 고르고, 도중에 줄여 가기도 합니다.

이 실험의 한계 실험실의 그릇 f(θ) = θ²는 바닥이 하나뿐인 가장 쉬운 지형이에요. 실제 신경망 지형은 울퉁불퉁하고 차원도 엄청나게 높습니다.
AI 판단 코너주판봇의 "손실이 처음 10걸음 동안 안 줄었으니 학습률을 100배로!"

박사는 늘 두 가지를 묻습니다. "가정이 맞나? 숫자가 그럴듯한가?"

  1. 가정이 맞나? 손실이 안 줄어드는 이유가 "학습률이 너무 작아서"뿐인가요? 너무 커서 지그재그로 제자리인 경우는요?
  2. 숫자가 그럴듯한가? f = θ²에서 α = 0.6을 100배 하면 공비 1 − 2α는 얼마가 되나요?
확인해 보기 (먼저 스스로 따져 본 뒤 펼치세요)

손실이 줄지 않는 이유는 두 가지일 수 있어요. 학습률이 너무 작거나(거의 안 움직임), 너무 커서 바닥을 넘나들거나(진동). 손실 곡선의 모양을 봐야 구분됩니다. 매끄럽게 아주 천천히 줄면 작은 것, 오르내리며 튀면 큰 것. α = 0.6을 100배 하면 60이라 공비 1 − 120 = −119, 한 걸음에 손실이 만 배 넘게 폭발해요. 학습률은 10배 단위(×3, ÷3 정도)로 조심스럽게 바꾸는 것이 보통입니다.

# %% 1. 학습률에 따른 경사하강 (f = θ^2)
import numpy as np
import matplotlib.pyplot as plt

def gd_path(theta, alpha, steps):
    path = [theta]
    for _ in range(steps):
        theta = theta - alpha * 2 * theta       # ∇f = 2θ
        path.append(theta)
    return np.array(path)

for a in [0.01, 0.1, 0.7, 1.0, 1.1]:
    p = gd_path(4.0, a, 20); r = 1 - 2 * a
    kind = "발산" if abs(r) > 1 else "제자리 왕복" if abs(r) == 1 else ("지그재그 수렴" if r < 0 else "수렴")
    print(f"α={a:<5} 공비 {r:+.2f} -> 20걸음 뒤 θ = {p[-1]:+.4g} ({kind})")
    plt.plot(p ** 2 + 1e-12, label=f"alpha={a}")
plt.yscale("log"); plt.xlabel("step"); plt.ylabel("loss"); plt.legend(); plt.title("Learning rate matters"); plt.show()

# %% 2. 선형 회귀를 경사하강으로 (5장과 같은 데이터)
x = np.array([1, 2, 3.0]); y = np.array([2, 3, 5.0])
def grads(w, b):
    err = y - (w * x + b)
    return -2 * np.mean(x * err), -2 * np.mean(err), np.mean(err ** 2)
w = b = 0.0
for t in range(5000):
    gw, gb, J = grads(w, b)
    w, b = w - 0.05 * gw, b - 0.05 * gb
    if t in (0, 10, 100, 1000, 4999):
        print(f"걸음 {t:>4}: w = {w:.4f}, b = {b:.4f}, MSE = {J:.5f}")
X = np.column_stack([np.ones_like(x), x])
print("정규방정식 답:", np.linalg.solve(X.T @ X, X.T @ y).round(4), "(b, w)")

# %% 3. 배치 vs SGD vs 미니배치
rng = np.random.default_rng(0)
xd = rng.uniform(0, 2, 1000); yd = 3 * xd + 2 + rng.normal(0, 0.5, 1000)
def train(batch, epochs=20, lr=0.05):
    w = b = 0.0; hist = []
    for _ in range(epochs):
        idx = rng.permutation(len(xd))
        for s in range(0, len(xd), batch):
            j = idx[s:s + batch]; err = yd[j] - (w * xd[j] + b)
            w += lr * 2 * np.mean(xd[j] * err); b += lr * 2 * np.mean(err)
        hist.append(np.mean((yd - (w * xd + b)) ** 2))
    return w, b, hist
for name, bs in [("batch", 1000), ("SGD", 1), ("mini-batch 32", 32)]:
    w_, b_, h = train(bs)
    print(f"{name:14s}: w = {w_:.3f}, b = {b_:.3f}, 마지막 MSE = {h[-1]:.4f}")
    plt.plot(h, label=name)
plt.xlabel("epoch"); plt.ylabel("MSE"); plt.legend(); plt.title("Batch vs SGD vs mini-batch"); plt.show()

# %% 4. 좁고 긴 그릇에서 GD vs 모멘텀 vs Adam
f = lambda p: p[0] ** 2 + 10 * p[1] ** 2
g = lambda p: np.array([2 * p[0], 20 * p[1]])
def run(method, lr, steps=300):
    p = np.array([5.0, 1.0]); v = np.zeros(2); m = np.zeros(2); s = np.zeros(2)
    for t in range(1, steps + 1):
        gr = g(p)
        if method == "GD":
            p = p - lr * gr
        elif method == "Momentum":
            v = 0.9 * v + gr; p = p - lr * v
        else:  # Adam
            m = 0.9 * m + 0.1 * gr; s = 0.999 * s + 0.001 * gr ** 2
            mh, sh = m / (1 - 0.9 ** t), s / (1 - 0.999 ** t)
            p = p - lr * mh / (np.sqrt(sh) + 1e-8)
        if f(p) < 1e-6:
            return t
    return steps
for meth, lr in [("GD", 0.01), ("Momentum", 0.01), ("Adam", 0.1)]:
    print(f"{meth:8s} (lr={lr}): 손실 < 0.000001 까지 {run(meth, lr, 3000)}걸음")
print("GD를 lr=0.09로 잘 맞추면:", run("GD", 0.09), "걸음 -> 학습률을 잘 고르면 기본 GD도 빠르다.")
print("개선판의 장점: 학습률을 덜 까다롭게 골라도 잘 움직인다(같은 lr=0.01에서 모멘텀이 약 3배 빠름).")

질문답 한 줄
최적화란?함수를 최소화하는 파라미터 찾기. θ* = argmin f(θ).
경사하강은?θ ← θ − α∇f(θ). f = θ²이면 θ ← θ(1 − 2α).
학습률은?걸음 크기. 너무 크면 발산, 너무 작으면 느림.
세 가지 경사하강은?배치(안정·느림), SGD(빠름·흔들림), 미니배치(균형, 표준).
개선판은?모멘텀·RMSProp·Adam(가장 인기).

용어 대응 카드

최적화란 = 함수를 최소화(또는 최대화)하는 파라미터의 가장 좋은 값을 찾는 것. θ* = argmin f(θ).
최소화와 최대화 = 아래로 볼록한 그릇의 바닥(최소화), 위로 볼록한 언덕의 꼭대기(최대화). ML 예: 선형 회귀 MSE, 로지스틱 로그 손실, 신경망 교차 엔트로피, 하이퍼파라미터의 검증 오차.
경사하강 = 함수의 최솟값을 찾는 반복 알고리즘. 그래디언트 반대로 α만큼 걷는다: θ_new = θ_old − α∇f(θ).
경사하강의 세 가지 = 배치(전체 데이터로 한 걸음), 확률적 SGD(데이터 하나로), 미니배치(데이터 몇십 개로).
학습률 = 각 반복의 걸음 크기 α. 너무 크면 최솟값을 넘어가고, 너무 작으면 아주 느리게 수렴한다.
최적화 알고리즘 = 경사하강, 모멘텀(지난 기울기로 가속), RMSProp(제곱 기울기 평균으로 학습률 조절), Adam(모멘텀 + RMSProp, 가장 인기), Adagrad, Adadelta, 네스테로프.
ML 최적화 예: 선형 회귀 = MSE 손실 J(w, b) = (1/m) Σ (yᵢ − (wxᵢ + b))²를 w ← w − α ∂J/∂w, b ← b − α ∂J/∂b로 줄인다.
손실 곡면 (3D) = 가중치 축(w, b) 위에 손실 J를 높이로 세운 지형. 경사하강은 이 그릇의 바닥으로 내려가는 길.

원자료와 다르게 쓴 곳

  • 원자료 3번의 예 θ_new = θ(1 − 2α)에 "등비수열, |1 − 2α| < 1일 때 수렴"이라는 조건을 덧붙였습니다.
  • 원자료 7번(선형 회귀)에 5장 데이터로 경사하강을 돌려 정규방정식과 같은 답이 나오는 것을 확인해 넣었습니다.
