07장 조건부 확률과 베이즈 — 새 정보로 고치는 믿음

정확도 99% 검사에서 양성이 나왔는데, 실제로 병이 있을 확률은 왜 17%밖에 안 될까?

조건부 확률은 "이미 일어난 일"로 표본공간을 좁혀 다시 세는 방법입니다. 베이즈 정리는 그것을 뒤집어, 결과(검사 양성)를 보고 원인(병)의 확률을 고칩니다. 이 장의 하이라이트는 의료 검사 예예요. 직관과 다른 답이 나오는 이유를 1000명 그림으로 확인합니다.

조건부 확률이란 What is Conditional Probability

사건 B가 이미 일어났을 때 사건 A의 확률. P(A|B)로 쓰고 "B가 주어졌을 때 A"라고 읽는다.

말로 먼저 새 정보가 들어오면 가능한 경우가 줄어들어요. 그 줄어든 세계(B) 안에서 A가 차지하는 몫이 조건부 확률입니다. P(B) > 0일 때만 정의돼요(0으로 나눌 수 없으니까요).
숫자로 한 번 해 보기
  1. 반 30명 중 안경 쓴 학생 12명, 그중 여학생 5명
  2. P(여학생 | 안경) = 5/12 ≈ 0.417
  3. 안경이라는 정보로 세계를 12명으로 좁힘

07-02

공식과 뜻 Formula and Meaning

P(A|B) = P(A∩B)/P(B). 거꾸로 쓰면 곱셈 법칙 P(A∩B) = P(A|B)·P(B) = P(B|A)·P(A).

말로 먼저 P(A|B)는 "B일 때 A", P(A∩B)는 "A와 B가 둘 다", P(B)는 "B의 확률"이에요. 양변에 P(B)를 곱하면 두 사건이 함께 일어날 확률을 구하는 곱셈 법칙이 됩니다. 독립이면 P(A|B) = P(A)라서 6장의 P(A)P(B)가 돼요.
숫자로 한 번 해 보기
  1. P(B) = 0.4, P(A∩B) = 0.1 → P(A|B) = 0.25
  2. P(A∩B) = P(A|B)P(B) = 0.25 × 0.4 = 0.1 ✔
  3. 독립이면 P(A|B) = P(A)
학교 수학으로 보면
고등 "확률의 곱셈정리".
AI에서는
확률 모델은 복잡한 사건의 확률을 조건부 확률의 곱으로 쪼개 계산합니다(생성 AI가 단어를 하나씩 이어 붙이는 방식도 이 원리).
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
P(A∩B) = P(A|B)·P(B)곱셈 법칙둘 다 일어날 확률
P(B∩A) = P(B|A)·P(A)반대 방향같은 값

예 1: 공 뽑기 (비복원) Example 1 — Without Replacement

빨강 5, 파랑 3에서 둘을 꺼낼 때 첫 공이 빨강이면 두 번째가 빨강일 확률 = 4/7 ≈ 0.571.

말로 먼저 꺼낸 공을 다시 넣지 않으니(비복원) 첫 번째 결과가 두 번째 상자를 바꿉니다. 첫 공이 빨강이면 남은 것은 빨강 4, 파랑 3, 모두 7개.
숫자로 한 번 해 보기
  1. 처음: 빨강 5 / 전체 8
  2. 첫 공 빨강 뒤: 빨강 4 / 전체 7
  3. P(둘째 빨강 | 첫째 빨강) = 4/7 ≈ 0.571
  4. 둘 다 빨강 = 5/8 × 4/7 = 20/56 ≈ 0.357

예 2: 문제 풀기 Example 2 — Reading a Condition

쉬운 문제 60%, 어려운 문제 30%를 맞히는 학생. 어려운 문제가 주어지면 맞힐 확률 = P(S|H) = 0.3.

말로 먼저 이 예는 "조건부 확률은 조건 속에 이미 적혀 있을 때가 많다"는 것을 보여 줘요. H = 어려운 문제, S = 맞힘. "어려운 문제의 30%를 맞힌다"가 바로 P(S|H) = 0.3이에요.
숫자로 한 번 해 보기
  1. P(S|쉬움) = 0.6, P(S|어려움) = 0.3
  2. 쉬움·어려움이 반반이면 전체 정답률 = 0.5×0.6 + 0.5×0.3 = 0.45
  3. "맞혔을 때 어려운 문제였을 확률"은 베이즈로: 0.15 / 0.45 ≈ 0.333
학교 수학으로 보면

AI에서는

헷갈리기 쉬운 점 원자료는 답(0.3)만 적고 계산은 없습니다. 전체 정답률과 반대 방향 확률은 이 도감이 "반반"이라는 가정을 더해 계산했어요.

베이즈 정리 Bayes' Theorem

P(A|B) = P(B|A) × P(A) / P(B). 새 증거 B로 가설 A의 확률을 고친다.

말로 먼저 네 조각의 이름: P(A|B) 사후확률(고친 믿음), P(B|A) 가능도(가설이 맞으면 증거가 나올 확률), P(A) 사전확률(처음 믿음), P(B) 증거의 전체 확률. 핵심은 "결과 → 원인" 방향으로 뒤집는 것이에요.
숫자로 한 번 해 보기
  1. P(A) = 0.2, P(B|A) = 0.9, P(B) = 0.3
  2. P(A|B) = 0.9 × 0.2 / 0.3 = 0.6
  3. 증거를 보고 믿음이 0.2 → 0.6으로 커짐

예 3: 의료 검사 Example 3 — Medical Test

유병률 1%, 민감도 99%, 거짓 양성 5%면 양성일 때 실제 병일 확률 ≈ 16.7%.

말로 먼저 1000명으로 생각하면 쉬워요. 병이 있는 사람 10명 중 약 9.9명이 양성, 병이 없는 990명 중 5%인 49.5명도 양성. 양성 59.4명 중 진짜 환자는 9.9명뿐이라 약 1/6이에요. 병이 드물면(기저율이 낮으면) 거짓 양성이 진짜 양성보다 많아집니다.
숫자로 한 번 해 보기
  1. P(T|D)P(D) = 0.99 × 0.01 = 0.0099
  2. P(T|~D)P(~D) = 0.05 × 0.99 = 0.0495
  3. P(D|T) = 0.0099 / (0.0099 + 0.0495) = 0.0099 / 0.0594 ≈ 0.167

확률 나무 Probability Tree Diagram

갈림길마다 조건부 확률을 적은 나무. 가지를 따라 곱하면 곱사건, 가지들을 더하면 전체 확률.

말로 먼저 출발 → A 또는 ~A (확률 P(A), P(~A)) → 다시 B 또는 ~B (P(B|A) 등). 끝 잎 네 개가 A∩B, A∩~B, ~A∩B, ~A∩~B예요. B로 끝나는 잎 두 개를 더하면 P(B), 그중 A 잎의 몫이 P(A|B)입니다.
숫자로 한 번 해 보기
  1. A 가지: 0.01 → B: 0.99 → 잎 0.0099
  2. ~A 가지: 0.99 → B: 0.05 → 잎 0.0495
  3. P(B) = 0.0594, P(A|B) = 0.0099 / 0.0594

  1. 문제: 검사에서 양성이 나왔습니다. "99% 정확한 검사"니까 병일 확률이 99%일까요?
  2. 앞 방법의 한계: 직관은 "검사 정확도"만 보고 "원래 이 병이 얼마나 드문가"(사전확률)를 잊습니다.
  3. 이 방법의 해법: 베이즈 정리로 사전확률 × 가능도를 증거의 전체 확률로 나눠, 양성 중 진짜 환자의 몫을 계산합니다.

쉽게 말하면 화재경보가 울렸을 때, 경보기 성능뿐 아니라 "요리하다 연기가 난 경우가 얼마나 흔한가"도 함께 보는 것.

연구원이 묻고, 조교 하루가 풀어 봅니다

모아P(D|T)랑 P(T|D)는 글자만 바뀐 건데 왜 0.167이랑 0.99로 그렇게 달라요?

말로 먼저 P(T|D)는 "환자 중에서 양성의 비율", P(D|T)는 "양성 중에서 환자의 비율"이에요. 나누는 대상(분모의 사람들)이 다르니 값이 달라요.

학교 수학으로 보면 조건부확률의 분모 = 조건이 된 사건.

숫자로 한 번 해 보기
  1. P(T|D): 환자 10명 중 양성 9.9명 → 0.99
  2. P(D|T): 양성 59.4명 중 환자 9.9명 → 0.167
  3. 분모가 10명 vs 59.4명
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
P(T|D)피 티 기븐 디민감도: 환자 중 양성
P(D|T)피 디 기븐 티사후확률: 양성 중 환자
P(D)피 디유병률(사전확률)

조교 하루실험실에서 유병률만 바꿔 보세요. 검사 성능은 그대로인데 P(D|T)가 크게 움직입니다.

박사의 정리

베이즈 정리의 교훈은 "증거의 강도만 보지 말고 출발점도 보라"입니다. AI 경보 시스템을 평가할 때도 "이 경보가 맞을 확률"은 모델 성능과 사건의 드문 정도를 함께 넣어야 나와요.

이 실험의 한계 실험실은 검사를 한 번만 한다고 봅니다. 실제로는 양성이면 두 번째 검사를 하고, 그때는 첫 결과의 사후확률(16.7%)이 새 사전확률이 돼요.
AI 판단 코너주판봇의 "스팸 단어 '무료'가 있으면 스팸일 확률 = P(무료 | 스팸) = 0.8"

박사는 늘 두 가지를 묻습니다. "가정이 맞나? 숫자가 그럴듯한가?"

  1. 가정이 맞나? 주판봇이 계산한 것은 P(스팸 | 무료)인가요, P(무료 | 스팸)인가요?
  2. 숫자가 그럴듯한가? 전체 메일 중 스팸이 10%이고 정상 메일의 5%에도 "무료"가 있다면 답은 0.8과 얼마나 다를까요?
확인해 보기 (먼저 스스로 따져 본 뒤 펼치세요)

주판봇은 방향을 거꾸로 읽었어요. 0.8은 "스팸 중 '무료'가 들어 있는 비율"(가능도)입니다. 묻는 것은 반대 방향이라 베이즈 정리가 필요해요: P(스팸|무료) = 0.8 × 0.1 / (0.8 × 0.1 + 0.05 × 0.9) = 0.08 / 0.125 = 0.64. 높긴 하지만 0.8이 아닙니다. P(A|B)와 P(B|A)를 섞는 실수는 사람도 AI도 자주 해요.

코드 펼치기 (몰라도 됩니다 · 42줄)
# %% 1. 베이즈 정리 함수
import numpy as np
import matplotlib.pyplot as plt

def bayes(prior, sens, fpr):
    """P(병|양성) = P(양성|병)P(병) / P(양성)"""
    evidence = sens * prior + fpr * (1 - prior)     # 전확률: 양성이 나오는 모든 길
    return sens * prior / evidence

p = bayes(0.01, 0.99, 0.05)
print(f"P(병|양성) = 0.0099 / (0.0099 + 0.0495) = {p:.4f}  (약 {p*100:.1f}%)")

# %% 2. 가상 인구로 확인
rng = np.random.default_rng(7)
for N in [1000, 1_000_000]:
    sick = rng.random(N) < 0.01
    positive = np.where(sick, rng.random(N) < 0.99, rng.random(N) < 0.05)
    tp, fp = np.sum(sick & positive), np.sum(~sick & positive)
    fn, tn = np.sum(sick & ~positive), np.sum(~sick & ~positive)
    print(f"N={N:>9,}: 진양성 {tp}, 거짓양성 {fp}, 거짓음성 {fn}, 진음성 {tn} -> 양성 중 환자 비율 {tp/(tp+fp):.3f}")

# %% 3. 유병률에 따라 달라지는 사후확률
priors = np.linspace(0.001, 0.5, 300)
plt.plot(priors * 100, [bayes(q, 0.99, 0.05) for q in priors])
plt.axvline(1, color="gray", ls=":"); plt.xlabel("prevalence (%)"); plt.ylabel("P(disease | positive)")
plt.title("Same test, different base rates"); plt.grid(alpha=0.3); plt.show()

# %% 4. 베이즈 갱신: 사후확률이 다음 사전확률
belief = 0.01
for k in range(1, 4):
    belief = bayes(belief, 0.99, 0.05)
    print(f"양성 {k}번 뒤: P(병) = {belief:.3f}")

# %% 5. 비복원 추출: 빨강 5, 파랑 3
bag = np.array(["R"] * 5 + ["B"] * 3)
first_red = second_red_too = 0
for _ in range(100000):
    draw = rng.choice(bag, size=2, replace=False)
    if draw[0] == "R":
        first_red += 1
        second_red_too += draw[1] == "R"
print(f"P(둘째 빨강 | 첫째 빨강) ≈ {second_red_too/first_red:.3f} (이론 4/7 = {4/7:.3f})")

정리 — 증거로 믿음을 고친다

질문답 한 줄
조건부 확률은?P(A|B) = P(A∩B)/P(B). B로 좁힌 세계에서 A의 몫.
베이즈 정리는?P(A|B) = P(B|A)P(A)/P(B). 결과에서 원인으로 뒤집기.
네 조각의 이름은?사후(고친 믿음)·가능도·사전(처음 믿음)·증거.
의료 검사 예의 답은?양성이어도 실제 병일 확률 약 16.7%. 병이 드물기 때문.
ML에서는?나이브 베이즈, 스팸 필터, 진단, 추천, 불확실성 모델.

용어 대응 카드

조건부 확률이란 = 사건 B가 이미 일어났을 때 사건 A의 확률. P(A|B)로 쓰고 "B가 주어졌을 때 A"라고 읽는다.
공식과 뜻 = P(A|B) = P(A∩B)/P(B). 거꾸로 쓰면 곱셈 법칙 P(A∩B) = P(A|B)·P(B) = P(B|A)·P(A).
예 1: 공 뽑기 (비복원) = 빨강 5, 파랑 3에서 둘을 꺼낼 때 첫 공이 빨강이면 두 번째가 빨강일 확률 = 4/7 ≈ 0.571.
예 2: 문제 풀기 = 쉬운 문제 60%, 어려운 문제 30%를 맞히는 학생. 어려운 문제가 주어지면 맞힐 확률 = P(S|H) = 0.3.
베이즈 정리 = P(A|B) = P(B|A) × P(A) / P(B). 새 증거 B로 가설 A의 확률을 고친다.
예 3: 의료 검사 = 유병률 1%, 민감도 99%, 거짓 양성 5%면 양성일 때 실제 병일 확률 ≈ 16.7%.
확률 나무 = 갈림길마다 조건부 확률을 적은 나무. 가지를 따라 곱하면 곱사건, 가지들을 더하면 전체 확률.
ML 응용과 핵심 정리 = 나이브 베이즈(글 분류), 스팸 필터, 의료 진단, 추천 시스템, 확률 모델의 불확실성 다루기.
