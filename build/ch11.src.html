극한 Limits

입력이 어떤 점에 다가갈 때 함수가 다가가는 값. lim(x→a) f(x) = L.

말로 먼저 "x가 2에 아주아주 가까워지면 x² − 4는 어디로 가나?" 연속인 함수는 그냥 x = 2를 넣어 2² − 4 = 0이 돼요. 극한은 미분과 적분을 정의하는 바탕입니다(0으로 나누는 순간을 피해 "다가가기"로 정의).
숫자로 한 번 해 보기
  1. lim(x→2) (x² − 4) = 2² − 4 = 0
  2. x = 1.9 → −0.39, x = 1.99 → −0.0399, x = 1.999 → −0.004
  3. (x² − 4)/(x − 2)는 x = 2에서 0/0이지만 극한은 4 (약분하면 x + 2)

고등 "함수의 극한".

말로 먼저 두 점 x와 x + h를 잇는 직선(할선)의 기울기 [f(x+h) − f(x)]/h에서 h를 0으로 보내면 접선의 기울기가 됩니다. f(x) = x²이면 [(x+h)² − x²]/h = 2x + h → 2x.

  2. h = 0.01 → 2.01, h = 0.001 → 2.001
  3. 극한 → f′(1) = 2 = 2 × 1

미분 법칙 Rules of Differentiation

상수·거듭제곱·상수배·합/차·곱·몫·연쇄 법칙. 특히 연쇄 법칙 (f(g(x)))′ = f′(g(x))·g′(x).

말로 먼저 곱 법칙 (uv)′ = u′v + uv′, 몫 법칙 (u/v)′ = (u′v − uv′)/v². 연쇄 법칙은 "겉 함수를 미분하고 속 함수의 미분을 곱한다"예요. 신경망은 함수를 겹겹이 쌓은 합성함수라서 연쇄 법칙으로 미분합니다(역전파).
숫자로 한 번 해 보기
  1. (3x² + 5x)′ = 6x + 5 (상수배·합)
  2. ((3x + 1)⁵)′ = 5(3x + 1)⁴ × 3 (연쇄)
  3. (x² sin x)′ = 2x sin x + x² cos x (곱)

정적분 Definite Integral

두 점 a, b 사이 곡선 아래의 정확한 넓이. ∫ₐᵇ f(x)dx = F(b) − F(a).

말로 먼저 부정적분 F를 구해 끝값에서 시작값을 빼면 넓이가 나와요(미적분의 기본정리). y = x를 0부터 1까지 적분하면 밑변 1, 높이 1인 삼각형 넓이 1/2와 같습니다.
숫자로 한 번 해 보기
  1. ∫₀¹ x dx = [x²/2]₀¹ = 1/2 − 0 = 1/2
  2. 삼각형으로 확인: 1 × 1 ÷ 2 = 1/2 ✔
  3. ∫₀² x² dx = 8/3 ≈ 2.667

ML에서의 쓰임 Applications in Machine Learning

경사하강의 기울기, 확률 분포와 기댓값(적분), 손실 최적화·신경망·연속 데이터 모델링, 최솟값/최댓값 찾기.

말로 먼저 가장 중요한 것 하나: 미분이 0인 곳에서 함수가 평평해지고, 그곳이 최솟값 후보예요. 손실 함수 f(θ) = θ²는 θ = 0에서 미분이 0이고, 그곳이 손실이 가장 작은 곳입니다.
숫자로 한 번 해 보기
  1. f(θ) = (θ − 3)² → f′(θ) = 2(θ − 3)
  2. f′(θ) = 0 → θ = 3 (최솟값)
  3. θ = 5에서 f′ = 4 > 0 → θ를 줄여야 함
학교 수학으로 보면
고등 "미분의 활용: 극대·극소".
AI에서는
경사하강(13장)은 "미분이 0인 곳"을 방정식으로 풀지 않고, 기울기를 따라 조금씩 걸어가 찾습니다.

실험할선에서 접선으로 — h를 0에 보내기

왜 이 방법을 쓰나
  1. 문제: 손실 그래프에서 "지금 이 점에서" 가중치를 늘려야 할지 줄여야 할지 알고 싶습니다.
  2. 앞 방법의 한계: 두 점 사이 평균 기울기는 간격 h에 따라 답이 달라집니다(h = 1이면 3, h = 0.1이면 2.1).
  3. 이 방법의 해법: h를 0으로 보내는 극한으로 "한 점에서의 기울기" 하나를 정의합니다. 그것이 도함수예요.

쉽게 말하면 구간 평균 속도가 아니라 속도계가 보여 주는 "지금 속도".

연구원이 묻고, 조교 하루가 풀어 봅니다

모아h를 0으로 보내는 거면, 처음부터 h = 0을 넣으면 안 돼요?

말로 먼저 h = 0을 넣으면 [f(x) − f(x)]/0 = 0/0이 되어 계산할 수 없어요. 그래서 "0이 되지는 않지만 한없이 가까워지는" 극한으로 정의합니다.

학교 수학으로 보면 고등 "함수의 극한"과 "미분계수".

  2. h = 0.01 → 2.01
  3. h = 0.001 → 2.001 → 2에 다가감

박사의 정리

미분은 "아주 조금 움직이면 얼마나 변하나"를 재는 도구입니다. AI가 학습할 때 묻는 질문이 정확히 이것이에요. "이 가중치를 아주 조금 바꾸면 손실이 얼마나 변하나?" 그 답의 부호가 방향을, 크기가 가파름을 알려 줍니다.

이 실험의 한계 실험실은 매끄러운 함수만 다룹니다. ReLU처럼 꺾인 점이 있는 함수는 그 점에서 미분이 정의되지 않아, 실제 코드는 약속된 값(0 또는 1)을 씁니다.
AI 판단 코너주판봇의 "(x² sin x)′ = 2x · cos x"

박사는 늘 두 가지를 묻습니다. "가정이 맞나? 숫자가 그럴듯한가?"

  1. 가정이 맞나? 두 함수를 곱한 것의 미분이 "각각 미분해서 곱한 것"과 같나요?
  2. 숫자가 그럴듯한가? x = π/2를 넣어 두 답을 비교하고, 아주 작은 h로 계산한 기울기와도 맞춰 보세요.
확인해 보기 (먼저 스스로 따져 본 뒤 펼치세요)

틀렸습니다. 곱의 미분은 곱 법칙 (uv)′ = u′v + uv′이라 정답은 2x sin x + x² cos x예요. x = π/2(≈ 1.571)에서 주판봇의 답은 2 × 1.571 × 0 = 0이지만, 정답은 2 × 1.571 × 1 + 1.571² × 0 ≈ 3.14입니다. h = 0.0001로 수치 미분해도 약 3.14가 나와요. 손으로 낸 미분이든 AI가 낸 미분이든, 작은 h로 계산한 기울기와 맞춰 보는 것이 가장 쉬운 확인법이에요(경사 검사, gradient check).

코드 펼치기 (몰라도 됩니다 · 40줄)
# %% 1. 할선 기울기 -> 미분 (극한)
import numpy as np
import matplotlib.pyplot as plt
import sympy as sp

f = lambda x: x ** 2
print("    h     | 할선 기울기 [f(1+h)-f(1)]/h")
for h in [1, 0.1, 0.01, 0.001, 0.0001]:
    print(f"{h:>9} | {(f(1 + h) - f(1)) / h:.6f}")

# %% 2. sympy로 기호 미분
x = sp.symbols("x")
exprs = [x**3, sp.sin(x), sp.exp(x), sp.log(x), x**2 * sp.sin(x), (3*x + 1)**5, (x**2 + 1) / (x - 1)]
for e in exprs:
    d = sp.simplify(sp.diff(e, x))
    print(f"({e})' = {sp.factor(d) if e == (x**2 + 1) / (x - 1) else d}")

# %% 3. 수치 미분으로 검산 (gradient check)
def numeric_derivative(fn, x0, h=1e-5):
    return (fn(x0 + h) - fn(x0 - h)) / (2 * h)     # 가운데 차분: 더 정확
g = lambda t: t ** 2 * np.sin(t)
x0 = np.pi / 2
exact = float(sp.diff(x**2 * sp.sin(x), x).subs(x, sp.pi / 2))
print(f"x = pi/2: 기호 미분 {exact:.6f} / 수치 미분 {numeric_derivative(g, x0):.6f}")
print("주판봇의 답 2x*cos(x) =", round(2 * x0 * np.cos(x0), 6), "-> 틀림")

# %% 4. 할선과 접선 그림
xs = np.linspace(-0.5, 2.5, 200)
plt.plot(xs, f(xs), label="f(x) = x^2")
for h, c in [(1, "orange"), (0.5, "gold")]:
    s = (f(1 + h) - f(1)) / h
    plt.plot(xs, f(1) + s * (xs - 1), "--", color=c, label=f"secant h={h} (slope {s:.2f})")
plt.plot(xs, f(1) + 2 * (xs - 1), "r", label="tangent (slope 2)")
plt.scatter([1], [1], color="red", zorder=3); plt.ylim(-1, 6); plt.legend(); plt.grid(alpha=0.3); plt.show()

# %% 5. 적분: 기호 vs 리만 합
print("∫x^2 dx =", sp.integrate(x**2, x), "+ C")
print("∫_0^1 x dx =", sp.integrate(x, (x, 0, 1)))
n = 1000; dx = 1 / n; mids = (np.arange(n) + 0.5) * dx
print(f"리만 합(사각형 {n}개) = {np.sum(mids * dx):.6f}")

용어 대응 카드

미적분이란 = 변화와 변화율을 다루는 수학. 미분(변화율)과 적분(쌓인 양) 두 부분.
극한 = 입력이 어떤 점에 다가갈 때 함수가 다가가는 값. lim(x→a) f(x) = L.
도함수 (미분) = 변수에 대한 함수의 변화율. 그림으로는 한 점에서 접선의 기울기. f′(x) 또는 dy/dx.
자주 쓰는 도함수 = 상수 → 0, xⁿ → nxⁿ⁻¹, sin x → cos x, cos x → −sin x, eˣ → eˣ, ln x → 1/x (x > 0).
미분 법칙 = 상수·거듭제곱·상수배·합/차·곱·몫·연쇄 법칙. 특히 연쇄 법칙 (f(g(x)))′ = f′(g(x))·g′(x).
법칙 쓰기 예 = 곱: (x² sin x)′, 연쇄: ((3x+1)⁵)′ = 15(3x+1)⁴, 몫: ((x²+1)/(x−1))′.
적분 = 미분의 반대 과정. 곡선 아래 넓이를 구한다. ∫xⁿ dx = xⁿ⁺¹/(n+1) + C (n ≠ −1).
정적분 = 두 점 a, b 사이 곡선 아래의 정확한 넓이. ∫ₐᵇ f(x)dx = F(b) − F(a).
ML에서의 쓰임 = 경사하강의 기울기, 확률 분포와 기댓값(적분), 손실 최적화·신경망·연속 데이터 모델링, 최솟값/최댓값 찾기.
